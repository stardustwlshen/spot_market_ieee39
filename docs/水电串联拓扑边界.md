# 水电串联拓扑边界

当前水量方程把上游电站的全部发电流量与弃水，经过声明时滞后送入其下游。支持独立电站、任意长度串联梯级及多条独立串联梯级；每个启用电站至多有一个直接上游和一个直接下游。`qin` 是本站的外部增量来水，不应再次包含已由 `upstream` 引入的来水。

不支持分叉、汇流的水量分配或有损河道。分叉不能靠让多个电站引用同一 `upstream` 表达：这会让每个下游各收到全部出流。现已在输入与每次模型构建时拒绝该配置，不裁剪水量、不猜分流比例、不改变合法串联的方程。停用且已过滤的电站不占用下游名额。

此前反例：H2、H3同时引用H1，时滞0；三站初始库容各100万m³，外部来水为0，H1出流50m³/s，H2/H3出流为0，时段0.25小时。模型允许末态95.5、104.5、104.5，总库存由300增加为304.5万m³，而没有外部流入或流出。该输入现须明确失败。不同正时滞只推迟重复到水，不能消除复制。

同一入口检查保护日前、日内、实时及水电日电量下限续程。若未来要支持分叉或汇流，应先显式定义河道与分流系数/流量守恒，再同步修改主模型、续程、历史状态与验收逻辑；本次没有增加这些新假设。
