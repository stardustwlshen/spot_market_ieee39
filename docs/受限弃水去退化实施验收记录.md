# 受限弃水去退化实施验收记录

## 实施规则

原SCUC与固定整数经济SCED不改变。正式SCED完成后，在独立副本中固定原整数、报价段、出力、备用、网络及全部经济/短缺/跟踪松弛量，仅放行常规水电V/Qspill及日电量续程中的V/Qspill。续程Ph、稳定区整数、分区功率仍固定。二级只最小化当前正式窗口弃水，续程只证明水力连接可行，不称其弃水最小，也不把其计划当执行。

原主目标加等式J=J*，独立核验容差为max(1e-5元,1e-10×max(|J*|,1元))，不借用SCUC的1%间隙。物理可行误差使用1e-6原生单位；原目标等式不混入该物理阈值。SCUC原间隙原样保留，不把二级选择当作整数精确优化。

若正式窗口Qspill已逐项精确为0，则非负弃水目标已达理论全局下界0，直接用zero_lower_bound_certificate认证，二级求解耗时为0。它是同一选择规则的等价快捷路径，不是回退或容差清零。

## 对偶与事务安全

- 原主模型的约束、目标及对偶后缀不变。二级对偶不得生成价格或库存价值。
- 对可动水量变量，从原目标及约束线性系数与原row-dual重新计算reduced cost，检查变量界互补；双边不等式按dual正负分别选择lower/upper。原约束可行、主目标等值也必须通过。
- 证据范围是“水量坐标重新核验、其他经济坐标及原主对偶不变并继承原LP最优性”，不冒称独立重算全模型完整KKT。
- 复制前完成核验，只复制水量值，不复制二级约束、目标、固定标记或对偶。中途复制异常恢复原水量。
- 超时、不可行或证据失败均停止运行，不静默保留旧弃水作成功、不触发实时软化或日内回退。预算异常明确标记hydro_water_tiebreak。

## 阶段、定价及证据

日前、日内、实时均在生成正式快照前执行选择；后续参考与实际首时段状态都使用选定水量。辅助LP随后固定新的正式弃水，按照原已批准的辅助定价规则重算。保留主LP对偶不等于保证辅助价或未来调度不变。

hydro_water_selection_evidence.json逐窗保存原/新水量、主目标差、容差、原对偶摘要、水量坐标证据、失败策略、二级方法与耗时。summary和独立验收核对完整DA/ID/RT覆盖，并与正式水量快照交叉比对。窗口总和含重叠前瞻，明确不能用作实际全天弃水量。

新增LP显式共享原实时预算账本，并给后续辅助LP保留余额。新增求解时间与包含克隆、校验的总耗时分别记录，不偷偷扩大总预算。

## 旧A固定整数96时段复现实证

按旧A冻结输入与全部整数重建经济SCED：原目标约2469485.684222元；弃水1713.148967万m³。选择后弃水为0、末库容19713.148967万m³，27648个非水量变量逐项不变、主目标差0、原主LP节点价最大差0。受影响385条水力约束及变量界的原对偶可行/互补残差为0；原与新物理最大残差约3.97e-11。

这是同一窗口、相同固定整数的检验，不代表重跑完整日后实际调度或辅助结算价不变。真实额外运行时间见随附A_selection_result.json；单次性能受机器负载影响，不能作为整日耗时承诺。

## 回归重点

已覆盖：零退化水量选择、必须弃水/生态/硬目标不得清零、有价末库存不得花费成本容差；后缀放行能消除错误锁定而保持未来出力；辅助固定新正式弃水与不同侧边际成本；非最优、不可行、坏原始值、经济变量被改、预算耗尽及复制中途失败；真实阶段写盘和状态/参考传递；缺证据、改容差、改价格来源、篡改正式水量和成本均拒绝。

原后缀容量验收测试的造假夹具不再假定“必有正弃水”：现在通过配套调整后续库存保持水量守恒，再检查超出冻结报价容量，未放宽生产校验。

独立综合与最终专项测试计数、命令、源码摘要见交付测试日志。最终同版全套和完整日由集成再验，不继承旧版的通过标记。
