# 研究假设与实际运行边界

本项目是改造 IEEE39 上的单日离线电能量市场实验。以下说明来自当前程序实际执行路径，不把配置注释、测试样本或合成数据解释成真实电网的运行认证。

## 实时预测的信息时刻

- `rolling.run_rt_period` 构造窗口 `[t, t+H)`，传给 `forecast_view` 的发布时间是 `issue_t=t`。
- 默认 `first_period_actual=true`，窗口首个15分钟的负荷、风光直接取离线样本的实际值。这是理想化的实时平衡假设，不是提前30分钟可获得实际值。
- 未来窗口的预测取同一离线样本的 ID/RT 误差按提前量混合；生成器采用 `forecast=actual-error` 联合构造预测与真值。`multiscale_v2` 使用因果递推噪声，但仍是离线合成情景，不是只用历史观测训练和发布的在线预测器。
- `boundary_lead_min=30` 当前没有传入上述窗口的发布时间计算，不能据此声称执行了 T−30 读取边界、T−15 下发的真实时序。
- 当前数据没有逐版预测的 `issued_at`、观测截止时刻、数据迟延或执行段残差处置过程；默认调频实验关闭。因此预测准确率和调度结果只能说明这些合成输入下的实验，不证明现场可部署性。
- 若以后研究真实提前发布，应单独接入按发布时间索引的预测版本，并明确执行残差由何种平衡机制承担。不能简单改成预测值后仍把预测出力当实际执行、维持现有结算含义不变。

## 网络与安全范围

- 当前网络是无损 DC PTDF，支路系数为 `1/x`。持久化 CSV 未保存变比与相移；导出脚本忽略变比，变压器电抗用短路电压幅值换算，未分离电阻分量。
- 2026-11-04 用已安装的 `pandapower 3.5.6` 的 `case39`、`to_ppc`、`makePTDF`，在同一31号参考母线、同支路顺序下进行数值对照。参考算例有11个非1变比，所有相移为0；当前 CSV 与参考支路电抗最大差为 `2.9e-5 pu`，PTDF 最大绝对差为 `0.000301178985491`，位于 T12-11 对13号母线的系数。这里只是当前拓扑的实现对照，不是任意网络误差界或实际潮流安全证明。
- 本轮保留既有网络定义，不静默改变网络、线路容量或用户研究参数。若引入变比/相移，应明确版本迁移，并同步更改潮流、注入常数项、价格分解、输入冻结和历史解释。
- 线路压缩因子及全网倍率是研究场景参数。没有 AC 电压/无功/损耗校核、N−1安全约束或备用调用后的网络校核。`network_feasible` 仅指保存的正式调度潮流在该次冻结 DC 限额内。

## 完成、缺额和场景覆盖

- MIP 的1%是目标，不是每次均达到的保证。必须同时检查实际终止条件、 incumbent、best bound、实际 gap 和已执行时段数；有可行解的时限终止不能标成已证明最优。
- 切负荷、线路松弛、备用缺额、弃电、普通水电软跟踪偏差分别报告。电池SOC和抽蓄上库容的两小时硬锚不能因求解困难而自动放松。
- 正式调度量来自固定整数后的正式 SCED。辅助算价模型的量不执行，原始对偶与裁剪后的结算价不同。对账残差接近0只说明账务恒等式，不说明调度安全。
- 丰枯水、风光倍率和负荷倍率组合是合成敏感性设计，没有从历史联合分布估计概率或代表日权重。必要条件筛选通过、LP松弛可行、日前可行、部分RT成功、完整96段通过是不同证据级别。
- 普通回归测试中包含历史供电/旧软锚/旧备用配置，不能把全部测试通过当作当前默认全天运行证明。当前默认和选定角点须另做冻结输入的完整 DA+RT96。
