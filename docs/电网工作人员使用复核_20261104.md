## 已确认并局部修复

1. **连续切换结果会回弹，可能看错场景。** 选择“丰水基准 → 普通干季 → 干季低风光高负荷”时，第二次选择回到普通干季，页面因此没有展示不利场景的真实缺额。根因是无稳定 key 的选择器随着上一轮选择改变 index，重建控件。修复为稳定控件与独立持久选择状态，连续切换、普通重跑、离页返回、运行页显式要求打开新结果均保持正确。
2. **仅日前结果遇到抽蓄会崩溃。** 使用真实完整日中的独立日前存档回放，抽蓄区读取不存在的 ps['rt']，抛出 KeyError。现在只在确有实时摘要时显示实时抽蓄卡，日前页可完整读出。
3. **均价名称相同而统计口径不同。** 基准日已保存的日前负荷电量加权价为187.252元/MWh，原仅日前页顶却显示每15分钟节点加权价的算术均值183.294。现直接显示本次保存的187.3，不用算术均值回退。全天187.252/217.680的差30.428与逐时价差均值25.658本来就不同，现明确区分“负荷电量加权均价”和“逐时价差算术均值”，说明节点/时段权重及执行范围。缺记录、NaN/无穷、无权重或零负荷保持未知，不补成零或等权均价。
4. **含区外来电的合计却称不含来电。** 基准末段保存净供给3143.74MW已经包含TIE，但原诊断卡称“报价主体净出力”并说区外来电要另计。现根据保存行标明含来电、禁止重复相加；缺行不宣称全网完整，缺功率不报伪总量。
5. **历史实时表缺来电行时，出力堆叠偷偷补入日前来电。** 已去掉该补值，明确提示只统计保存主体。用真实结果派生的内存缺行副本验证，RT图不再出现伪造的来电执行曲线；该试验不是新物理运行。
6. **损坏结果阻断看其他结果。** 坏summary JSON、坏CSV、日前价格文件主/备均缺、必要字段缺失现在给业务错误和技术详情，保留顶部选择器，能切回正常结果。文件不会被修改、重置或用当前场景补齐。必要表也检查重复主体/节点时段及无效时段编号。
