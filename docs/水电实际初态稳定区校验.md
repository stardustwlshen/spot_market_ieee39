# 水电实际初态稳定区校验

每次构建滚动模型时，实际水电出力与在线台数必须属于现有稳定运行区可行域。此前只检查0≤P0≤在线台数×单机额定值，可能接受位于振动禁区的外部或损坏初态。

校验按在线台数反复计算单机稳定区区间的Minkowski和并合并重叠区间，得到精确聚合可达总出力域。各机可处于不同稳定区，不要求相同出力。例如单机允许[10,20]、[80,100] MW，2台在线时总出力允许[20,40]、[90,120]、[160,200] MW，100 MW可由10+90构成，不能因平均50 MW在单机禁区而误拒。

0台在线只允许0 MW；保持既有1e−6 MW数值容差，容差只用于最终成员判断，不随台数累加、不填平真实禁区。不截断、替换或修正实际出力。实际出力及台数映射须完整且只包含启用水电；拒绝布尔、字符串、非有限数、非整数在线台数和超额台数。

本次只是验证已有聚合稳定区约束的合法起点，不增加机组动态或新调度限制，也不改变报价、备用、价格、当前合法配置。默认丰/枯季初态均保留。已有合法模型推进出的状态应保持可接受；任意站间/机组间更细动态仍不由此证明。
