## 4. 显式H1日电量4400 MWh：通过的内容与失败边界

这是隔离验证配置，不修改默认或用户历史场景。H1下限为全季共用参数，最初9000预检被已有枯水上限5000正确拒绝，未进入求解；没有改上限或删除季节来凑通过。

- DA实际计划4400.000000000008 MWh；ID@0为4400.000000000012；ID@4为此前实际194.9+剩余4205.1=4400。
- 最终实际4399.999999 MWh，约1e-6差额在既有模型/审计数值容差内。全精度独立重算96个首段，后缀与滚动预测没有计入实际。
- 24轮ID中2轮成功、22轮明确不可行，后续按既定规则回DA参考，不把失败轮标成功。
- 首次tau8不可行有独立数学证据：此前第6、7段发电45MW，对应发电出库54而生态最低60，各弃水6m³/s，损失可发电水量2.5MWh。tau8实际已发252.4、库容15048.2832；ID硬末库容≥15000下最多还能发4145.1，却需4147.6。精确单轮重建仍不可行；仅在诊断克隆去下限或去末库容各自可行，没有用于替换真实结果。
- RT保持用户允许的软末库容，实际末库容14990.9239329，低于目标9.0760671万m³，以此满足硬日电量下限。这不保证下一ID仍符合另一套硬终态政策。
- 该档实际RT缺备用9段、282.9813617MWh，最大207.0820818MW；DA T2-30第74段越限5.4947619MW。RT没有切负荷、surplus或线路越限。**硬日电量与证据通过，不等于全市场无缺额/无松弛；总无松弛验收为False是预期风险揭示，不是被忽略的失败。**
