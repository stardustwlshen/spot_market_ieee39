# 全流程UI复核与优化清单

2026-11-06。依据用户已确认的逐日报价、四类特色误差、按日顺序真实接续要求，结合当前单日集成界面的真实浏览器核验。本文件是设计审查，不表示多日引擎或以下入口已实现，不改市场规则。与《多日场景启动入口与输入契约设计》v2合读。

## 一条主流程，单日也是同一流程

1. 任务范围与初态：选择基础配置、开始日期、连续天数；展开查看/修改真实初态。单日是N=1，不能保留另一套不一致的报价、冻结或求解路径。
2. 每日设置与报价：日期卡片内分别设置风、光、负荷、来水及预测情形，显示报价是否完成。报价可明确复制或生成，但每个日期要有独立、可查的有效报价包，不默认继承前日。
3. 核对并运行：紧凑汇总显示日期、情景、报价版本、初态来源和阻断项。点击开始才冻结；按日消费前日真实末态，缺少当日报价时等待，不跳日或回到原始初态。
4. 查看结果：固定任务/日期/阶段/时段上下文，接线图、主体总览、状态、结算和利润都跟随同一上下文。全任务汇总只合计有资格的已完成范围。

不重复复制现有135项高级设置。场景页保留主场景参数；高级入口只提供真实消费者字段；报价入口只管申报；设备入口只管物理和独立成本；初态入口只管有时间与来源的实际边界。互相提供定位链接，不制造同一字段的两个可写版本。

## 信息来源与更新边界

| 用户操作 | 应立即更新 | 应失效或等待 | 不得改写 |
|---|---|---|---|
| 修改尚未保存的参数 | 编辑草稿及差异 | 已保存输入图仍标明未提交 | 磁盘输入、历史结果 |
| 保存物理/场景输入 | 当前输入图、有效值与来源 | 依赖的曲线预览、验证及未冻结计划；旧运行标过期 | 旧运行拓扑、出力、价格与利润 |
| 修改某日报价 | 当日报价就绪状态、差异与校验 | 当日及后续受实际状态影响的计划；当日需重新确认 | 已执行日的报价和金额 |
| 修改误差场景/种子 | 对应生成版本与种子账本 | 后续受相关潜状态影响的预览；不能声称只影响该日 | 上传/手工锁定输入、历史曲线 |
| 修改任务初态 | 初态审计、来源与残余义务 | 整条后续执行链 | 已完成任务的真实检查点 |
| 从历史结果切到当前输入 | 当前场景的已保存输入图 | 图不得带着旧出清覆盖层 | 原结果快照 |
| 日期/阶段/时段切换 | 全部关联图表与单位 | 无保存值时显示未提供 | 不补零、不中途换成当前默认 |

正在执行的当日冻结后不可就地改写；修改需新分支/新版本。尚未执行的后续日允许按明确的任务状态编辑和确认报价，保存后重新验证依赖链。不得以“继续”按钮静默采纳新场景或新规则。

## 应随多日实施同时收敛的界面问题

### 必须阻止误用

- 任务、日期、运行版本和来源在结果顶部保持可见，切换后关联选择器一并切换；不能短暂把新标题与旧数值作为稳定结果显示。
- 历史单日C、比较B/D、两节点QA和未来连续多日分别标范围，测试场景不出现在“产品默认预设”数量中。
- “完成”“精度达标”“无物理缺额”“有结算”“末态目标满足”分别显示，不能收成一个绿色通过标志。
- 每日DA是计划，ID是参考不结算，RT仅首段是实际；辅助定价数量不执行。水电/抽蓄仍按站级功率和利润显示；新逐台水电承诺不等于有逐台功率/利润。
- 日利润来源是本日冻结的成本和实际执行现金核算；TIE无运营成本档案时不造0利润；部分日与完整日不能直接合成“全任务利润”。
- 原始边际价与限价后结算价分开，旧档无来源只标保存价格，不根据当前限价重算。

### 精简而不隐藏重要差异

- 主视图只留场景摘要、每日报价就绪、有效初态/版本与主要阻断。方法、公式、来源详情放一个可查入口。
- 主体总览默认给少量关键对照和一张图，完整96点表、阶段细节、原始字段折叠；不能让大表把阶段导航推到很远。
- 大图的节点/支路细节与主体总览互相定位，少做并行的独立下拉框；选择都绑定同一日期和运行。
- 报价技术参数更新后的历史提示只在需要用户选择或可能影响有效报价时常驻，其余已处理通知不反复占屏。
- 来源未知、结果过期、未保存编辑、未实施功能、失败/中断等状态用具体短句，不用长段解释掩盖操作入口。

## 联合验收清单

1. 单日N=1与原正式入口相同有效输入时，模型输出与结算口径一致，旧档仍只读可打开。
2. 两日按顺序：第一日正式末态成为第二日DA/ID/RT初态；不覆盖手工/真实剩余义务，跨日状态证据可查。
3. 第二日报价缺失、失效、未确认、与机组集合不一致均在该日启动前阻断；明确复制/生成后独立冻结，模型确实消费不同报价。
4. 日期、误差、种子、网络、机组、报价、成本和初态的各类变化均触发正确的失效范围；连续相关过程不在午夜重置。
5. 输入图更新、旧结果保持、旧结果标过期、重新求解恢复一致四步在原生浏览器完成，不只测文件指纹。
6. 首日/次日、DA/ID/RT、首末时段、机组切换时，拓扑/表格/利润来源一致；缺失与未执行不补零。
7. 中途取消、失败后重新打开、等待次日报价、重复点击开始、返回修改、恢复检查点都不能重复执行或双计现金。
8. 最终在同一版本跑全套、真实连续两日，并保留所有缺额、松弛、软末态和价格来源警告。未跑部分明确列出。
