方案版本：v2（含分类型报价限价与最终运行有效值审计）。

状态：等待 Page 先行记录规则配置暴露方案。此次不修改优化公式、不改变任何默认值，不写入正在最终回归的 final_repo。开发副本：advanced_parameters_20261106。

## 1. 操作与安全边界

入口为运行页的“高级参数”，按基础场景、预测、线路、求解、市场/滚动分组折叠。每个控件有短标签、单位和 help，必要的作用条件在控件附近简短提示，不恢复成大段界面说明。

编辑仅形成候选值；检查与取消均不保存。保存前对完整候选场景构建网络、预测、当前报价及 DA 输入，执行已有物理与报价校验，加本次编辑器的类型/范围/枚举/关联条件校验。无效参数不裁剪，不偷偷重建报价，不修改已上传曲线。输入变动造成报价不兼容则明确拒绝，用户先修复报价或另行明确重建。

保存使用场景输入锁、当前报价/成本锁、原文件字节备份、乐观指纹检查和可恢复原子事务。保存中故障回滚；另一页面修改后拒绝覆盖。运行中控件禁用；即使其他会话成功更新场景，当前运行仍使用独立冻结副本，不影响已运行时段。下一次运行冻结新参数；历史目录不写入。

## 2. 机组字段分级

### 2.1 已有控件且模型直接消费，补充说明并验证

- 通用：bus、enabled、资源类型对应容量。ID/资源类型对已有机组不修改，复制/新增使用唯一 ID。
- 火电：pmax/pmin（MW）、ramp（MW/min）、ut/dt（h）、init.online/p0/hours。影响出力、爬坡、启停连续性和初态。
- 水电：n_units、unit_pmax、zones（单机稳定运行区，MW）、ramp（单机 MW/min）、water_rate（m³/s/MW）、init_units_on/init_p_unit；seasons.wet/dry 的 qin/v0/qeco；库容型另消费 vmin/vmax/v_end/e_day、e_day_min、qout_max；upstream/lag_periods 是串联梯级与时滞。当前水期的参数本次入模，另一水期保存后需选择该水期才生效。
- 径流式水电：pondage 决定有效库容范围 [v0-pondage,v0]、日末 v0；原季节 vmin/vmax/v_end 与 e_day/e_day_min 不作为独立可调约束，应在该类型下只读并说明派生/不适用。
- 储能：pmax、ecap、eta_c/eta_d、soc0；soc_min/soc_max 是技术允许范围，但已有报价若收窄范围，模型采用申报范围，需明确有效值而不能声称放宽技术范围必然放宽模型。
- 抽蓄：n_units、unit_gen_max/min、unit_pump、variable_speed（仅开启时 unit_pump_min 生效）、e_gen/e_pump、v_total/vup_min/max/vdn_min/max/vup0、switch_gap、max_gen_starts/max_pump_starts、init_mode。上下库联合有效上下限、综合效率均为只读计算值。
- 风光：cap、profile；上传显式曲线列优先于合成曲线；报价 avail_pmax 可覆盖日前预测可用上限，因此参数作用要按实际覆盖链解释。

### 2.2 缺省报价、当前申报与成本不得混同

- 储能 soc_end_bid、抽蓄 vup_end_bid 是新建/明确重建报价的缺省申报。已有 current_quote 中 soc_end/vup_end 优先，改技术缺省不会暗改当前申报。短 help 明示“当前报价已存在时须在报价处修改，或明确重新生成本机组报价”。
- 火电 noload/startup 是技术档案缺省。当前报价 noload_cost、startup_cost_yuan/分状态 startup_cost 优先。默认 uniform_per_unit 模式不使用全部历史冷热态值；不会把全部旧字段装成正在执行的启动报价。
- 抽蓄 start_cost_gen/start_cost_pump 是模型直接消费的启动目标系数，独立成本档案仍用于事后利润，二者不能混称。
- 独立真实/自定义成本不被技术编辑覆写。现有明确模拟成本按既有逻辑仅为本机组更新。
- 保存后对本次修改列出：直接模型输入、当前模式下条件生效、仅供新/重建报价使用。对仅改缺省而当前申报未变，不能显示“已影响本次出清”。

### 2.3 不允许伪编辑的遗留/未实现项

- 水电 ut/dt：当前没有逐水轮机最小开停时间约束。界面只读并明确“当前模型未使用”，不新增公式来实现。
- 真实逐机水头/效率曲面、独立部分抽蓄台数初态、梯级分叉等当前未实现，不通过任意文本输入伪支持。
- 未认识的历史额外键保留，只读，不以无说明的可编辑文本框向用户假称生效。

## 3. base 参数编辑清单

| 分组 | 可编辑键 | 作用/限制 |
|---|---|---|
| 场景 | date、season | date 为运行日期标签，不能宣称改变物理初态；season 只 wet/dry，切换采用已有对应水文，保留当前报价 |
| 负荷/随机 | load_scale、seed | 正倍率、非负整数种子；上传覆盖列不被改写，保留并显示覆盖提示 |
| 预测 | forecast.sigma.{wind,pv,load}.{da,id,rt}、forecast.phi.{wind,pv,load} | 标准差非负，abs(phi)<1；作用于合成预测，模型选择沿用现有入口；实际/上传/报价覆盖链有条件说明 |
| 线路 | line_capacity_multiplier、line_scale.<现有支路ID> | 正倍率；有效限额=原始rate×逐线倍率×全网倍率，给出只读预览；不改拓扑、电抗、母线基准数据 |
| 求解 | solver.mip_rel_gap、time_limit_s、threads、log | gap∈[0,1]、正时间、正整数线程、布尔日志。预算/精度不保证可行或最优；HiGHS透传如覆盖同名项则拒绝误导性修改或明确屏蔽该字段 |

本轮不开放 periods/dt_h/rule_set/tie_line_mode/default_bid_model、solver.name/highs_extra/storage_binary/tighten/warm_start/commit_step_periods 的任意改写。前者与完整日/时间栅格/固定市场结构关联，后者部分改变数学机制或有透传风险；保留只读值和原因。已有安全专用入口仍可使用。n1_loss_mw 只有显式配置且 include_ctg 开启时有作用，可在规则组有条件开放，缺省不隐式新增。

## 5. 可检查的生效证据与验收

1. 字段覆盖测试：所有可编辑机组字段都有具体 help；未实现与未认识字段不可编辑；每个模式相关字段含生效条件。
2. 表单测试：输入→检查无写入→保存→重新打开持久化；取消后旧值恢复；无效输入/同场景并发修改/重复保存/运行中控件禁用。
3. 原子性测试：失败注入不会留下半份配置；恢复不会覆盖外部变化；备份保留原字节；历史场景/运行快照逐字节不变。
4. 基础输入测试：保存 load_scale/seed 后新生成负荷/风光确实变化，上传列仍逐值保留；season 改变有效水文；线路倍率确实改变模型 branch 限额；求解参数传入实际 solver options，不能被 highs_extra 悄悄覆盖。
5. 运行前展示最终有效值与来源：从磁盘重新加载base/modes而非旧session_state，显示DA/RT/ID求解预算、时间栅格、全局与逐类型限价。当前网页启动仅传运行模式/报价版本/短跑时段，不传旧求解配置；测试冻结后实际solver选项与所显示配置一致。报价SOC与启动/空载费来源明确；固定成本档案优先于模板，原手工值不变。dt_h本轮只读，不制造可保存但被启动参数覆盖的输入。
6. 模型消费测试：构造 DA case/ModelData/约束，检查各组已修改参数为模型使用值；对申报覆盖与停用字段明确验证条件，不能只检查 YAML。
7. 最小真实算例：按现有短算例进行保存后的 DA+RT 求解，核对冻结输入、约束/结果指标；失败/不达精度按实报告。已有9类新增及8段运行仅作基线证据，不替代新增控件验证。
8. 集成后受影响 focused suite，最终由集成者跑全回归。短试跑不作为96段完成/全可行的证明。
