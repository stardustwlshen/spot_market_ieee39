# 主要阶段结果展示

保持日前／日内·实时滚动／最终结果三块。日前和实时提供明确的 SCUC、正式 SCED、辅助定价结果入口；日内展示每轮成功、失败与回退，不以成功数决定是否存在日内板块。正式 SCED 的数量和所选定价来源分开标识。只有实时首段为执行，日内数量/价格均非结算。

当前真实存档提供日前/实时阶段快照、24轮日内计划/指示价及水电/抽蓄状态证据，但未保存日内各求解阶段。新增日内阶段证据持久化和进度事件，并保留缺失字段未知语义。失败轮只显示真实失败信息，不生成虚构出力。交接以实时逐资源保存的来源与版本为准。

只改只读快照、输出与展示，不改求解顺序、模型、引用选择、执行首段或结算数量。回归覆盖三块导航、旧档缺证据、失败轮、阶段定价角色、ID进度不增加执行段数、实际档案只读展示。
