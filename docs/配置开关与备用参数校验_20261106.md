# 配置开关与备用参数校验

本轮只拒绝无效配置，不修改合法配置下的需求公式、备用资格、物理域或价格规则。

原行为存在实测反例：将电池备用开关写成字符串 `"false"`，会按 Python 真值启用，微型算例给出72 MW上备用；真正布尔 `false` 时为0。事故备用开关同样把字符串 `"false"` 当启用，增加865 MW。负负荷比例也能被正事故项掩盖而形成仍非负的最终需求。

现在公开算例入口及每次模型构建均验证：

- 事故/储能/下备用、整数储能域、收紧、热启动、日内启用、实时首段实际量开关必须是真正布尔值，字符串和0/1不自动转换。
- 备用各需求系数和事故规模必须为有限非负数；新能源备用置信因子限于[0,1]，不得放大物理余量。
- 常规备用资源类型必须为不重复的受支持列表，不把单个字符串拆成字符集。
- 抽蓄工况决策步长必须为正整数，不截断小数或以非正数取消工况锁定。
- 未写出的历史可选键保留既有默认。储能备用关闭时，未使用的持续时长继续不影响模型。

合法数值及原有市场政策均保持不变；此检查不把简化备用解释为完整激活轨迹或事故后网络可交付性认证。
