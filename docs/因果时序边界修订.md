# 因果时序边界修订

本补充不改变既有预设数值，也不把实际信息提前交给预测器。

1. ObservationSeries 原始 starts/available_at 在 int64 转换之前验证有限整秒、非布尔和范围；小数秒直接拒绝，禁止先截断再检查。区间均值仍必须在段末或之后到达。
2. 声明的观测时延允许小数分钟，但设备时延和额外时延分别向上取整到整秒后相加。例如 0.01 分钟使用 1 秒；0.01+0.01 两个来源时延使用 2 秒。生成历史、观测前缀及预测器最早可用检查使用同一规则，负延迟拒绝。
3. 公开条件在缺测间隔内生效又结束时，滤波状态按已发布条件的 valid_start/end 分段传播，不能只用观测终点的基线。预测发布也复用该传播方法。没有公开事件的既有路径保留原数值计算。

独立反例：公开风容量因子指导在第 1–9 小时为 .9，第 10.125 小时才有容量因子 .5 观测；delayed 更新后 level 应为 .7787645125913283。修复值 .7787645125913282，误差 1.11e−16，trend 同独立 ODE；不再将整段指导吞掉。

另有独立 legacy 兼容修订：仅 v3 生成严格剩余日 qin_series，旧常数模式保留标量，允许其原有独立绝对时钟窗口。未放宽 v3 缺段或超日边界。
