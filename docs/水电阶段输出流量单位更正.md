# 水电阶段输出流量单位更正

本次发现阶段档案旧字段 `Qout_1e4m3_h`、日内参考流量展示标签“万m³/h”与实际存储值不一致。该值一直为 `water_rate × P + Qspill`，单位是 m³/s，与主水量方程、正式水电结果表和备用流量检查一致。错误只在字段名和展示单位，不在物理量或求解方程。

新阶段档案使用 `Qout_m3s`；日内参考表改为 m³/s。已有历史档案保持原字节，不换算或重写数值，界面将原字段显示为“总下泄流量 m³/s（历史字段名误写）”。库容仍为万m³，不混用流量与库存。

新增回归覆盖15/30/60分钟出库值不乘时长或0.36、日内原值不变，以及新旧档案单位标签。此更正不改变出清、定价或结算。
