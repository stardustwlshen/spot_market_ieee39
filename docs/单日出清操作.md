# 单日出清操作

## 最短路径

1. 打开主页，选择场景。丰枯水、风电、光伏和负荷可直接选择；负荷、风电、光伏预测误差可分别选择，默认沿用当前条件，不要求修改。
2. 点击“下一步”。沿用条件不写文件；调整条件时，下一步才应用为独立场景副本，原场景保留。新能源日前申报可用量若需同步，会在按钮前明确提示；价格与分段量保持不变。
3. 按需查看机组和报价，也可直接切换“4 运行”。点击“开始单日出清”后自动进入进度与结果。

不要求逐台重填机组、确认每项初态、重生成报价，也不要求进入高级设置。现有参数校验或报价校验失败时必须先修复，不能把无效输入当作可用默认值。

## 按需修改

- 场景：常用四项直接显示，倍率相对原始基准，不叠乘。三类预测误差情景也在场景页独立选择。特殊基准维护留在完整工作台，不是单日流程步骤；预测模型、误差幅度、持续性和种子在运行页“高级设置”。旧场景不自动迁移。
- 机组：默认只看容量与日初状态。编辑器中先检查，再保存；取消不保存。编辑未结束时先保存或取消，再切换工作区。
- 报价：直接选择机组，查看或修改该机组报价；全网报价概览按需展开。只浏览不保存，实际手工修改自动保存；预览生成的报价须显式采用。保存失败或外部报价冲突时保留当前编辑并提示，不能按未保存的改动启动。
- 新能源曲线：在机组页按需展开系统图与输入曲线，选择风电/光伏、合计或分机组及要查看的输入口径。悬停可同时查看同一时刻的所选曲线，全部时段数据表按需展开。缺失值不补零，也不显示不完整的合计。实际可用功率是场景输入，不是出清后的发电量；日内/实时预测基线不是每个滚动窗口的最终预测。
- 高级设置：默认完整单日。仅日前、截短实时、日内策略、终端目标、求解时限等均为可选。低频设置不构成必经步骤。运行页按所选范围显示实际将执行的阶段；仅日前不显示实时与结算，短时试跑明确标注为前缀。
- 结果：显示运行进度、失败和取消状态、已执行前缀及完整结果入口。当前场景配置损坏不会阻断已保存运行的查看。

## 输入与输出口径

### 预测误差情景

三类资源均可选择保留现有预测、常规持续误差、持续高估、持续低估、跟踪滞后或较强波动。选择本身只做只读预览，点击“下一步”才另存副本。误差选择只重生成允许调整的预测列，不更改实际曲线；丰枯水或风光负荷倍率属于另外的场景调整。

这些是未用历史数据标定的离线联合研究情景，使用完整的当日实际轨迹构建预测偏差，不是可投产的因果预测器，也不代表实测概率分布。误差统一为“预测减实际”：正值为高估。负荷误差按同时段负荷水平缩放；风电误差按装机容量缩放并包含同类场站共同变化；光伏按声明的日照包络缩放、夜间为零，硬上限仍为装机容量。默认日照假设为 6.5–19.5 时，按时段中点判断；日照窗口可以在 `forecast.error_scenarios.pv_daylight` 中设置，但不会据此改写上传曲线。

随机部分为平稳初始化的慢、较快两个时间相关过程，不按每一天的样本均值或方差事后归一化。资源和阶段按稳定种子标签生成，机组顺序变化不影响已有资源。同一输入、算法版本与种子可复现。日前、日内、实时误差共享部分变化并含各自修正，幅度基准来自现有高级配置，不保证每个样本日逐阶段一定更准。持续偏差、波动倍数、滞后长度及共同变化比例都是明确的研究假设，不是历史统计估计。

上传实际和预测列优先保留；物理边界冲突明确报错，不偷偷修正上传值。新生成副本记录列来源与文件摘要，只有来源可核验的系统预测列允许重生成。旧副本缺少来源证据，或覆盖文件被手动修改后，保守保留已有列并在页面提示误差未应用的列。日前出清的报价申报可用量仍优先于预测，单独改变误差选择不修改报价；天气倍率涉及申报可用量同步时仍需页面明确提示后的下一步操作。

运行冻结的预测数据和生成说明包含所选情景、参数假设及列来源。实际出清继续使用日前预测、日内/实时滚动预测与原有插值规则；实时首时段是否使用实际值由原配置决定。界面和阶段传递测试不能替代完整默认规模的数值验收。

日初状态来自当前场景配置，未核验为设备实测，不自动接续前一天。模拟成本报价、缺省补齐及旧报价来源保持可见。已有当前报价损坏时不自动换成默认报价。

启动冻结当前配置、机组状态与工作报价。运行期间禁用编辑和重复启动。日前是计划，日内启用时仅作滚动参考、不单独结算；实时每个窗口只执行首段并传递实际执行状态。只有实际完成全天的结果才属于完整日，短时试跑或取消前缀不能据此声称完整日结算。

完整报价工作台保留在“更多工具”中；结果选择与场景对比只显示独立单日运行，历史归档不改写、不删除。此界面调整未改变市场模型或默认参数，界面与缩小算例测试不能替代完整 IEEE39 默认规模的96段数值验收。
