# 连续出清快速上手

从首页「出清任务」开始。单日与多日共用这个入口；「报价模拟」仍可编辑基础场景、机组、报价和高级参数。

## 1. 选基础场景，建任务

- 要使用本版新配置，在「新建模拟」中选择「使用新版默认方案（保留已有方案）」，另取名称后创建。先核对储能容量、水电逐台状态等摘要。
- 已保存的「默认」或其他场景保留原有输入，不会自动升级；新建不会覆盖旧报价和结果。
- 先选择基础方案、开始日期、模拟天数和名称，再点击「创建模拟」。预测方式、时区和随机种子在「高级设置」中。通常选「四资源因果预测（研究场景）」；「固定已知实际曲线（联调）」假设未来曲线全已知，不用于评价预测能力。

## 2. 逐天设置场景和初态

在「1 每日场景」按日期选择风电、光伏、负荷、天然来水各自的实际过程和预测误差情形，四类预测情形放在「预测情况」里，数值参数放在「详细调整」里，展开即可查看说明和修改。随机选择只填未手改的字段；固定种子便于复现，不等于四类资源都用独立白噪声。

在「2 起始状态」：

- 新研究可核对基础配置后「确认研究起点」，再修改火电状态/出力/已持续时间、储能能量、抽蓄水量及切换前史、水电库容和逐台状态。先校验再保存，不把研究前史当实测。
- 已有完整实际日末检查点可校验导入。时间须相邻，设备、规则和网络须相容；实际接续状态只读。
- 若要改实际导入状态，使用「复制为可编辑研究初态（新任务分支）」。这会明确断开原实际接续链，保留原记录，并要求重新确认报价。
- 次日初态来自前一日实际执行末态，不逐日重新初始化。开始运行后不能改写已冻结初态。

## 3. 每天分别报价并确认

在「3 每日报价」先核对日期，再为该日生成报价或明确复制基础场景/另一日的报价。可以逐主体修改分段和其他申报参数；复制、生成、编辑后都要点击「确认该日全部机组报价」。每个日期保留自己的版本和来源，不默默沿用前一天。

因果模式中，已有手工风光可用量不会被覆盖；需要采用当天预测时，明确点击「用当日已发布预测填写风光可用量」，再确认该日报价。未报价或未确认会显示为待处理，不能作为已提交报价运行。

## 4. 预览、验证和连续运行

在「4 检查与运行」核对实际与发布预测的预览、来源和准入检查。可选择全部日期就绪后运行，或只运行已就绪前缀、遇未报价日暂停。点击「检查输入」，通过后再「开始连续模拟」。输入改动后要重新验证。

本程序采用**先完成前日实际执行，再计算次日日前**的顺序研究流程，不是 D−1 时点就提交次日计划的真实市场时序。日内计划仅供后续参考，不另做日内现金结算；实时滚动窗口只执行首段。

取消在当前完整日结束后生效。恢复以已完整提交的日界为准，先核对任务状态和进程身份；当日失败、未形成提交时，不自动将部分结果当完整日，也不承诺任意时段断点续算。不要手删已提交目录或同时重复启动。

## 5. 按日查结果，再看跨日汇总

「5 查看结果」显示已完成日期、净电能结算及可核算的成本/利润。选日期后点击「打开该日全部阶段、拓扑与主体利润」：

- 查看日前计划、日内参考、实时实际执行及最终对比。
- 主体总览并排查看各阶段出力与结算。水电、抽蓄继续以电站为主体，不凭逐台启停状态编造单台出力或利润。
- 接线图叠加该日、该阶段、该时段的保存结果；旧档无冻结网络则明确不可核验，不拿当前场景补图。
- 「预测与已执行实际输入」按资源和原预测发布阶段查看曲线、MAE/RMSE及偏差。风光指可用功率，不是机组发电出力；实时误差比较原发布预测，不把首段完美测量伪装成零预测误差。
- 每日来源、报价版本、状态与结果绑定同一快照。基础场景后来变化不会覆盖旧任务；需要采用变化时另建修订任务，重新核对初态和每天报价。

新现货利润只扣燃料发电、明确不含运维的在线费及实际启停费用；不计运维、折旧、寿命折损和优化罚值。抽水/充电购电已经计入带符号电能结算，不重复扣除。编辑成本在「报价模拟 → 编辑现货核算成本」，与报价分开保存；修改不回写历史结果。缺成本显示未提供，不填零；跨日成本口径不一致时不合并成本/利润，历史口径明确保留。

末日如有 pending（尚未履行的开停或切换义务），页面会警示剩余时长；计算结束不代表这些义务消失，需要后续实际接续履行。完成、精度达标、无松弛和物理检查通过是不同结论，请保留并查看各日告警。
