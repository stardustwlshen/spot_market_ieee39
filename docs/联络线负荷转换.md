# 区外来电恢复与历史转换说明

2026-11-04 根据用户纠正，区外来电应当是供给，取消此前“来电转区内负荷”设定。仓库新默认恢复 `tie_line_mode: supply`，区外计划仍在原接入节点注入；没有减少基础负荷、扩建电源、提高线路限额或放松库存约束。

## 已有场景如何恢复

- 缺少 `tie_line_mode` 或已经是 `supply` 的场景本来就按来电运行，无需改写。
- 明确 `fixed_load` 的场景不随升级静默改动。运行页显示警告并阻止误启动，点击“备份并恢复本场景区外来电（下次运行）”即可对当前场景应用，不必另建场景。
- 命令行先 `python scripts/restore_tie_supply.py --scenario 场景名` 只读预览，再加 `--apply` 执行。
- 操作先在独立临时副本验证未来模型输入，备份原配置与受影响覆盖曲线到该场景 `input_backups/tie_supply_restore_<UTC>/`，然后切换为供电。连续重复恢复不会重复修改。
- 仅取消独立的 `TIE_actual/da/id/rt` 需求覆盖，保留基础 `load_*`、风光、机组、线路、原报价和当前报价；供给使用原 `TIE_sched` 生成机制及当前联络线设备配置。
- 若此前已有典型组合，原 `typical_scenario.json` 和基准曲线一并归档，取消旧需求基准的活动身份。恢复后的当前基础负荷/风光曲线是新组合起点，避免旧基准隐式把需求再次加回。
- 历史 `runs/`、冻结配置、出清量价和结算从不修改；旧结果仍如实显示其原输入。源输入变化会拒绝过期恢复。

供给改成相同大小需求会使净负荷增加两倍TIE。原计划约825–1045MW、22,880MWh/日，错误转换增加45,760MWh/日净供需压力。这是此前严重不足的重要边界原因，不应靠临时增容掩盖。恢复供电只是修正边界；常规组合仍须核验全天DA/RT、线路、备用和库存约束。

## 历史转换研究的技术留档（不再是当前默认）

以下是原转换能力的兼容说明。`fixed_load` 仍可用于重放历史证据，普通读取与求解不会偷偷改变冻结历史；它不表示当前用户继续要求这种设定。

历史转换配置明确设置 `tie_line_mode: fixed_load`、`tie_load_allocation: base_load_share`。原 TIE 不再向系统注入，也不报价、不参与需求响应、不作为供给主体结算。固定需求如发生供电不足，仍受原模型失负荷变量及罚项核查，不会隐藏切负荷。

## 曲线与节点分配

保留原始 `TIE_sched` 来源列，并在新生成输入中独立列出 `TIE_actual`、`TIE_da`、`TIE_id`、`TIE_rt`。初始四列均逐段等于原计划，不注入额外预测误差。四列可分别显式覆盖，实际列覆盖不会偷偷更改固定负荷的预测列；不以原来电功率上限裁剪负荷。旧曲线只有 sched 时四阶段均使用该计划；若提供部分阶段列而缺其余阶段则报错，不混合猜测。

历史转换设置中，每段新增量分配至原有负荷节点，固定权重 = 冻结 `data/case39/buses.csv` 节点基准负荷 / 基准负荷总和。原 `load_*` 曲线不改写，新增部分独立分摊后相加；不再全部集中在原节点39。权重不依赖时变基础负荷。每阶段每段所有节点的新增量之和严格等于该阶段 TIE 曲线（浮点数容差内）。

日前用 da；滚动预测用与原负荷一致的 id/rt 提前量插值，实时首段用 actual。备用公式不改动，但负荷项输入为包括新增部分的总负荷。典型高/低负荷情景须将原 load 四列和 TIE 四列各乘一次同一倍率，不能重复缩放或把新增量重复写入 load。

默认原曲线 825–1,045 MW，22,880 MWh/日。与历史区外来电相比，一份供给消失、一份需求新增，净供需压力增加 1,650–2,090 MW，45,760 MWh/日。这不保证原发电配置可无切负荷、无备用缺额运行；没有增电源、减原负荷或改锚点来掩盖困难。

## 结果与历史兼容

日前及实时逐节点价格表保存总需求与 `fixed_load_mw`；系统总负荷包含新增量。日前摘要的 `fixed_load_conversion` 保存分配权重、冻结权重来源、源ID/原节点、完整四阶段曲线与实际采用列类型。拓扑不再把原TIE标为发电资源，基准负荷节点展示分配权重；节点需求以保存记录为准，不能把缺失的新场景记录当零或猜测。

结算新增需求合并到节点 `L<n>` 的用电付款，扣除该节点实际失负荷；不出现 TIE 供给结算主体。因为缺电量是节点级，不虚构原始与新增两部分各自的供电比例。

缺少 `tie_line_mode` 的旧配置保持供电语义。旧转换入口已从页面移除；当前恢复操作见文首。
