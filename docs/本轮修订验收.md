## 2. 本轮改动

1. 煤/慢机从日前锁启停，快速机按配置继承日内；轨迹、价值、水电台数与出库使用经验证的同一来源包。缺失/无效逐资源回日前，不借旧轮数据冒称新轮。显式关闭继承、source=day_ahead或free仍保留GT自由语义。
2. 中间SCED库存价值保留正负，日末延续价值0，终态目标对偶另存。正值表示留能边际有益，不把负值取绝对值。
3. 仅RT采用有限末态偏差成本：电池/抽蓄双侧，水电只罚不足；日前及日内仍保留原目标。1000元/可放电MWh是可配置研究假设，非结算价。物理动态、整数、启动预算等不因软目标改变。
4. 电池/抽蓄剩余日后缀保留资产级离散物理续程并计软末态成本，不增加小时锚；只执行当前首段，不执行/结算后缀，不保证未来全网/备用联合可行。
5. 水电非日末窗口按选定DA/ID出库参考估计日末短缺并计有限成本，消除仅到22:00才看见短缺的盲点。它是参考续程估计，不是最大回蓄或完整经济尾值证明。历史场景缺 `hydro_lookahead` 键保持off，缺新terminal_policy保持hard，未自动迁移。
6. 仅ID明确物理不可行记失败并回日前参考；其他错误不吞掉。RT仅硬参考带明确不可行才试紧急软化，所有阶段共用预算。计划末态偏差不是应急失败回退。
7. 验收读真实CSV并校验缺证据、非有限值、来源、状态带和价格；辅助定价移除仅作用于克隆且不会被目标重建带回。页面分开预测、已执行末态及市场结算；批跑不Git恢复输入、不覆盖旧输出。

### 枯水日内开启的备用差异

最终版20:45(t83)缺额为43.4004151MW。20:00日内对该段预测净负荷比实际低72.9001692MW；在其已定GT关闭、PS闲置和水电台数组合下，预测备用余量22.9409909MW，而实际备用需求反而比预测低6.5587631MW，三项重建缺口：72.9001692−6.5587631−22.9409909=43.4004151。此时各可用资源的功率备用能力已用满，不是电池备用能量不足；两组当刻都没有GT/CCGT在线，不能套用旧严格版本的GT启停差异解释。日内关当刻PS发150MW，可提供最多150MW上备用，实际采购86.7334MW。

这是当前执行点的容量/预测误差解释，不是对全日反事实最优的证明。日末抽蓄有300MW定速离散步长：一台一个15分钟对应57.142857可放电MWh。枯水关日内最后一段若额外抽300MW，在既定启停/水电台数下会至少缺13.624777MW备用，备用成本下界340619.43元，高于可少付的57142.86元终态成本；不能将该偏差归为遗漏末态成本。
