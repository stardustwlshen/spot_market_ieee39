# 实时窗口末价值法与日内交接

本文说明当前修订实现的价值口径与交接规则。所有未注来源的数值均标「假设值」。实施依据及验收边界见《日内实时交接修订方案》、《实时日末软目标修订》和最新《水电软终态前瞻补充》；既有场景不会随代码更新自动换规则。

## 1 研究设定（A 项，保留并说明，不宣称任何省现行规则）

| 设定 | 取值 | 来源 / 性质 |
|---|---|---|
| 正式罚因子 | 平衡 1e6 > 备用 1e5 > 线路 1e4 元/MWh | 假设值（研究设定，Wls指定）；线路低于备用意味着缺备用时优先压线路 |

## 2 日前（B 项）

- 储能：申报期末 SOC 则 `E_{T−1} = E_end`，未申报 `E_{T−1} = E_0`（`scuc.py` `c_eend`）。
- 抽蓄：同上，`Vu_{T−1} = Vu_end` 或 `Vu_0`（`c_pvend`）。
- 水电：`V_{T−1} ≥ v_end`（`c_vend`）。
- 辅助算价克隆日前模型，上述约束不被去激活（`auxiliary_pricing.preserve`）。

## 3 状态价值（C/D 项）

日前或日内最终调度 SCED（固定整数后的 LP，不取辅助算价模型）对偶，`m.dual[c] = ∂Obj/∂rhs`；库存递推写成 `X_t − X_{t−1} − flow_t = 0`，因此

    v_t = −dual(c_X[t+1])         (t < T−1)
    v_{T−1} = 0                   （未设跨日残值）

终态目标约束 `c_eend / c_pvend / c_vend` 的对偶单列为 `terminal_target_dual`，衡量抬高终态要求的成本，不能当作跨日残值。日内以日末上下带表达的等式取两条约束对偶之和；缺失时标为不可用，不伪造 0。

`scuc.state_values()` 提取上述量。有限差分校验：`tests/test_value_based_rt.py::test_state_value_dual_sign_matches_finite_difference`（退化点允许落在左右导数之间）。

单位：储能 元/MWh（存量）；抽蓄 元/万m³，折 `w/e_gen` 元/MWh；水电 元/万m³，折 `w×0.36×耗水率` 元/MWh（1万m³ = 1/(0.36·耗水率) MWh）。

### 3.1 符号核对（价值曲线全负问题，有限差分）

约束代码写法（`src/smm/scuc.py`，三类方向一致，左边都是本时段末存量）：

    c_soc  : E[s,t]  == E[s,t−1]  + (η_c·Pc − Pd/η_d)·dt
    c_pres : Vu[p,t] == Vu[p,t−1] + (Pp/e_pump − Pg/e_gen)·dt                 （万m³）
    c_water: V[h,t]  == V[h,t−1]  + (q_in + 上游 − q_gen − q_spill)·dt·0.36    （万m³）
    c_eend : E[s,T−1] == 目标；c_pvend : Vu[p,T−1] == 目标；c_vend : V[h,T−1] ≥ v_end

Pyomo appsi-HiGHS 极小化，`m.dual = ∂Obj/∂(常数项)`。有限差分做法：把 `c_X[t+1]` 改成 `X[t+1] == X[t] + flow + ε`（时段 t 末免费多 ε），
重解固定整数 SCED，价值 = −ΔObj/ε，左右各一次。同时把目标拆成“系统其余成本”和“储能/抽蓄自身报价项”（放电/发电报价、充电/抽水买价取负、抽蓄启动费），
单独给出系统其余成本的 −Δ/ε。脚本 `scripts/fd_value_sign.py <wet|dry> 20,40,60,80`，结果写 `outputs/fd_sign_{wet,dry}.json`；回归测试 `tests/test_value_sign.py`。

以下数值来自上传版本附带的历史样本，保留作为中间时段符号说明，不充当当前修订版全天验收。

| 场景 | 主体 | t | v（程序） | −ΔObj/ε 右/左 | 系统其余成本 −Δ/ε | 折 元/MWh：v / 系统 |
|---|---|---|---|---|---|---|
| 丰水 | ES1 | 40 | −178.95 | −178.95 / −178.95 | +136.84 | −178.9 / +136.8（=130/0.95，少充一次） |
| 丰水 | ES1 | 80 | −114.00 | −114.00 / −114.00 | +285.00 | −114.0 / +285.0（=0.95×300，多放一次） |
| 丰水 | ES3 | 60 | −142.50 | −178.95 / −142.50 | +136.84 | 退化点，v 在左右导数之间 |
| 丰水 | PS1 | 20/40/60/80 | −3744 元/万m³ | −3744 / −3744 | +576 | −390 / +60 |
| 丰水 | H1 | 20–80 | 0 | 0 / 0 | 0 | 0（丰水 v_end 不紧） |
| 枯水 | ES1 | 20–80 | −75.73 | −75.73 / −75.73 | +323.27 | −75.7 / +323.3 |
| 枯水 | H1 | 20–80 | +370.37 元/万m³ | +370.37 / +370.37 | +370.37 | +160 / +160 |
| 枯水 | PS1 | 20–80 | 0 | 不可行 | — | 日前全天停机，整数固定后库容不能动，对偶 0 无信息 |

结论：

1. 三类约束方向一致，`v = −dual(c_X[t+1])` 与有限差分完全一致（ES/PS/H、丰/枯、多时段），没有符号或约定错误；正 v = 多存 1 单位使目标下降。
2. 储能/抽蓄为负、水电为正，原因不是方向不同，而是**口径**：目标是报价目标，含储能/抽蓄自身报价。分解为
   `v = 系统其余成本节省 − 自身报价边际`。在这些样本的边际充放条件下，系统其余成本节省为 η_d·LMP 或 LMP/η_c，样本值为正（+136.8、+285、+323.3）。这不是普遍定理，负节点价及其他约束可能改变符号；
   本算例储能充电买价 cc = 300/280/260、放电报价 cd = 420/450/480 都高于大多数时段节点电价，所以 v = (LMP − cc)/η_c 或 η_d·(LMP − cd) 为负：
   多 1 MWh 存量会挤掉一次“买价 300、电价 130”的充电（−170/0.95 = −178.9），或迫使一次“报价 420、电价 300”的放电（0.95×(300−420) = −114）。
   这些水电样本没有买方报价，取得非负值；不因此给一般水价值施加非负限制。
3. 历史样本 PS1 中间时段常数 −390：上库库容全天不触边界（200–224 万m³，界 60–450），价值等于日末等式 `c_pvend` 的对偶（−3744 元/万m³）向前传递。
   定速抽水 300 MW 只能整台开停，SCED 中唯一可调的是 17:00–18:00 的发电；该时段 2 号节点（抽蓄送出节点）电价 60，边际发电段报价 450：
   多 1 万m³ = 多发 9.6 MWh，目标增 (450 − 60)×9.6 = 3744 元，折 −390 元/MWh。与报价段 450 和节点价 60 相关；万m³→MWh 换算（÷e_gen = 9.6）无误。
   390 与 bid_cost_basis 的 PS1 reservation=390 数值相同属巧合。
4. 实时用法自洽：窗口目标同样含自身报价，窗口外的日前延续目标也含自身报价，所以 −v·X_τ 用报价口径的 v 才是一阶一致的；
   改成系统口径（正值）会让窗口内充电同时得到买价“效用”和末端正价值，重复计算。方向测试在同一 RT 可行集内逐资产比较负、零、正价值，其他目标系数与约束保持不变；
   E 使用 ±2000 元/MWh，Vu 按 e_gen 换算为原生库容单位（本算例为 ±19200 元/万m³）。验证 −v·X_τ 系数、严格求解与约束残差、库存单调性，以及超过 1 MWh 的实际响应。
   不把不同可行集的日前库存当作零价值反事实，也不要求离散抽水贴到连续上下带（`test_rt_window_end_direction_with_extreme_value`）。
5. 实时窗口末实际偏差（rt_value_windows.csv）：丰水储能多贴下带（ES1 60/96 窗口，平均 ΔE −1.0 MWh），枯水多贴上带（ES1 93/96，平均 +3.4 MWh），
   v 在两季都为负——偏差方向由实时与日前的电价差决定，不是“v 为负就放空”。这些历史严格末态样本的日末窗口 ΔE = 0，不代表新软目标结论。

中间时段程序不截断价值，按带符号原值进入目标并在页面和 CSV 中如实展示。覆盖日末的窗口不再使用终态下限影子成本作额外奖励：水电仅有最低日末库容，额外奖励会改变物理调度；储能/抽蓄等式软化后也有同样风险。对应微型 LP 反例与专属测试见修订方案和 `test_terminal_value_semantics.py`。`validate_runs.py` 的“价值曲线非负”改为“价值曲线=−对偶(符号自洽)”，负值点数仅作展示。

## 4 实时窗口与软日末目标

窗口 `[t,t1)`，仅窗口末 τ=t1−1 加有符号价值项 `−v·X`。新默认实时价值法的 `terminal_policy.mode=soft`；缺少此新配置的历史场景保留hard，不自动迁移。日前和日内的硬终态不变。

非日末窗口保留选定参考上下2%的带并与物理界相交；soft不再叠加强制回到同一日末库存的功率包络。覆盖日末时，E/Vu以日前日末库存为双侧软目标，水电仅罚低于原v_end，不罚超额留水；不另叠加2%硬带。所有资源日末延续价值仍为0。

计划末态成本为 `ρ × r × (偏差上量+偏差下量)`：ρ默认1000元/可放电MWh（明确研究假设），r分别为电池ηd、抽蓄e_gen、水电1/(0.36×water_rate)，存量不再乘dt。它不是实际结算罚款，不承诺某个容差。明确hard政策仍保留此前严格终态及连续可达包络作为对照。

### 4.1 水电参考续程软前瞻

显式配置 `value_method.hydro_lookahead: reference_continuation` 为新默认。历史场景缺键或显式off不添加此项，不自动迁移。只在RT价值法soft且窗口未覆盖日末时，按该站已选定的DA/ID未来出库参考计算剩余净回蓄R_ref，阈值L=v_end−R_ref；对窗口末V低于L的量使用同一有限偏差成本。上游滞后来水的已执行部分取实际历史，其余取所选参考，绝不使用未来实际值。

这是“延续选定参考出库”的日末短缺估计，不是完整未来出清、最大回蓄或梯级可行证明。阈值不强制满足、不裁切到物理边界，仍允许付出有限成本偏离。进入覆盖日末的窗口后只保留原单侧日末软目标，不重复计罚。当前水量动态、台数、生态流量等物理约束不变。

`rt_hydro_terminal_lookahead.csv`及完整精度JSON逐窗口保存参考来源、净回蓄、阈值、预计日末、短缺及优化成本；预测成本不能跨滚动窗口相加，不是实际结算。辅助preserve保留，显式remove仅在定价克隆移除该项及成本，正式调度不变。详见[证据与方案](水电软终态前瞻补充.md)。

## 5 交接、物理续程与受控软化

剩余日整数资产后缀只连接24:00，不加额外整点锚。当前与后缀共用实际剩余启动预算，保留电池/抽蓄物理动态、整数台数、最低功率、定速泵与跨窗转换间隔。soft后缀为有限末态偏差成本，hard为精确终态证明；未来电量本身无报价成本，也不执行或结算。后缀不是完整经济预测，更不保证未来网络、水电、火电或备用联合可行。

默认固定整数SCED和辅助克隆保留同一政策。显式辅助remove仅在克隆中删除参考目标及相关成本，经济延续价值和当前物理约束不随之删除。实际模型不变。

`handoff_source: intraday`是来源选择，是否运行日内由`intraday.enabled`控制。煤/慢机始终读日前启停，快速机默认继承最新有效日内；确证ID物理不可行时该轮记录失败，废弃旧ID参考，整组回日前，后续日内轮正常重试。实际库存和累计启动不重置。显式`day_ahead`、关闭commitment或free仍保留历史GT实时自由语义。

各资源的ID状态、价值及水电台数/出库成包验证，无效数据逐项回DA，不沿用旧ID价值却冒称新轮。日前必需证据无效停止。成功、失败ID轮次及实际来源分别导出，辅助算价故障、取消、超时或软件异常不能作为物理不可行回退。

仅SCUC/正式SCED明确不可行且仍有硬参考带时才重试紧急软化，原`fallback_penalty=1e5`原生单位罚价只属于此应急路径；计划日末soft从首次求解即可偏差，不标为应急回退。当前带软化不撤掉所选hard/soft资产后缀；硬/软/定价共用预算。计划末态偏差、紧急带偏差与市场物理缺额分开报告。

详见[软目标修订](实时日末软目标修订.md)与[严格末态历史问题](枯水日内可达性补充.md)。

## 6 可选锚点（旧模式开关）

`realtime.storage.mode: sced_anchor` + `anchor: two_hour_eq | hourly_eq | window_end_pct`；`mode: fixed_da`。旧two_hour_eq仍使用其硬目标后缀，不被新价值法软目标自动修改。水电旧模式 `hydro: window_end_da | fixed_da | sced`。

## 7 备用能量（F 项）

储能/抽蓄上备用持续能量按**时段末库存** E[t] / Vu[t]：`r_up·T_dur/η_d ≤ E[t] − E_min`（`c_rsup_soc`、`c_rpup_volume`），T_dur = 0.25 h（假设值）。结果表 `reserve_formulation = period_end_stock`。
