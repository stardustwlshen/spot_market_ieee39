# 储能LP对照与火电启停互斥修订

## 复现于原main abd1cb7

1. 火电允许最小停机时间为0时，`u[t]-u[t-1]=v[t]-w[t]` 本身不能排除同时启动与停机。在 `tighten=false`（实时使用的配置）下，在线机组可取 `u=v=w=1`，从而把启动/停机爬坡额度错误叠加到普通在线爬坡上。一个15分钟微型算例中，初始50 MW、爬坡1 MW/min、最小出力50 MW的廉价机组，原模型从50增到100 MW；添加启停互斥后最多65 MW。负荷100 MW，原目标250元，修正后6287.5元。向下爬坡也可被同样绕过。
2. `storage_binary=false` 明确是LP松弛对照开关。合法负价例（热电−50、储能放电−10/充电−20元/MWh，充/放效率0.8/0.9，日末回初值）可产生同段 `Pc=58.1395349`、`Pd=41.8604651` MW，分数状态分别为0.5813953和0.4186047。原固定整数步骤把两个正功率对应状态都改为1，立即违反充放模式之和≤1，使原本可行的松弛解在正式SCED阶段被报为不可行。

## 修正原则

- 火电始终显式满足 `v+w<=1`，不依赖最小开停持续时间、启动费或可选收紧约束偶然保证互斥。
- 默认 `storage_binary=true` 的整数模式不改变。明确LP对照的充放连续状态在SCUC后按原分数值固定，再解LP；不得把它们假装成0/1工况。
- 模型构建时保存实际使用的储能域标记。后来改配置不能把已建立的整数模式伪装成允许分数的模式。
- 辅助定价仅对明确LP对照中的 `u_ch/u_dis` 接受已固定且位于[0,1]的分数；火电、水电、抽蓄及所有真实整数仍须固定且整数。克隆不得改变这些状态。
- 求解信息和辅助算价诊断显式记录 `storage_relaxation_comparison`。辅助诊断的 `dispatch_model_scope` 将此类结果标为松弛对照，而非物理调度。实际同段充放次数继续如实报告，不清零、不改成互斥。

## 范围

LP松弛允许非物理同时充放，用于比较下界/模型简化，不构成可执行储能调度、真实备用资格或物理可行认证。本修正覆盖日前与独立窗口/辅助定价已有对照流程；不取消价值法资产整数续程对 `storage_binary=true` 的既有要求，也不新增完整实时LP策略。

所有例子为隔离构造测试，不修改默认价格、负荷、设备参数或历史场景。原默认储能整数互斥继续保留。

完整 `run_full` / `run_rolling` 不把该LP对照结果送入实际执行链：在日前求解/滚动快照之前明确拒绝 `storage_binary=false`。日前和独立优化对照仍可使用；不会静默把开关改为true。
