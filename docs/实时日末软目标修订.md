# 实时日末软目标修订

状态：按用户最新要求先记录方案，待同一 Page 同步后实施。此前严格末态版本的1837通过、30跳过与四组全天结果保留为历史基线，不能作为本次新政策验收。

## 1. 适用边界与依据

用户明确“对于实时，可以不强行要求末库容或者soc 必须严格一致”。本次仅更改当前价值法实时政策，日前及日内仍遵守既定终态申报/下限；物理容量、充放互斥、整数台数、启动预算、转换间隔、水量动态、生态流量、线路、平衡及备用规则不因末态政策而改变。既有备用等显式缺额变量仍如实计罚和披露，不把它们描述成无条件硬保证。

已有枯水PS1离散死角说明，严格回到同一点可能需要额外抽水启动；允许偏差应直接在模型中表达，不能只改页面名称或在不可行后赋予近似无限大罚价。日末目标对偶不等于跨日残值，日末延续价值保持0。

## 2. 实时软目标与量纲

1. 新默认配置为 `realtime.value_method.terminal_policy = {mode: soft, penalty_yuan_per_discharge_mwh: 1000}`。1000元/可放电MWh沿用项目已有水电软跟踪研究量级，只是可配置建模假设，不是市场规则或经济最优参数，不承诺偏差必在某个百分比内。缺少此新配置的历史场景保持原hard政策，绝不批量改写自存场景。可显式选择hard复现实测基线。
2. 电池与抽蓄以日前日末目标为参考，对正负偏差都使用有限线性成本；水电仍以原日末下限为参考，仅对不足计成本，不罚高于该下限的留水。物理上下界独立存在，不可被偏差变量放松。
3. 统一罚价单位为元/可放电MWh。电池原生MWh乘放电效率ηd，抽蓄万m³乘e_gen，水电万m³乘1/(0.36×water_rate)；日末存量不再乘时段dt。导出原生偏差、等价能量、系数和模型罚金；罚金是优化目标项，不是实际市场结算付款。
4. 软目标从第一次求解起即为软约束，不先要求硬相等再因不可行才软化。中间窗口仍使用选定DA/ID价值与±2%参考带，但取消为严格回归日末而收缩的硬功率可达包络。日末窗口不再额外保留±2%硬带，不凭空添加容差。
5. 非日末SCED价值保持有符号，日末延续价值为0。软目标成本与中间价值项含义分别导出，不能把终态下限影子价当外生跨日收益。

## 3. 整数后缀的变化

当前价值法的资产后缀仍保留完整电池/抽蓄动态、互斥、整数台数、最小发电、定速泵、跨窗转换间隔和当前加后缀共享剩余启动预算，但软模式移除“必须精确回到日前终态”的等式，改为同一有限罚价的日末偏差变量。既有hard策略及历史two_hour_eq保持原语义。

后缀只说明资产级物理续程及给定偏差罚价下该续程的末态偏差，不能宣称精确回归可达或未来全网联合可行。未来电量无报价成本，也不执行、不结算、不改变实际库存；仅末态偏差有目标成本。SCED仍固定后缀全部整数，辅助定价默认保留同一软目标，显式remove仅作用于独立定价克隆。若当前参考带需要既有受控软化，后缀的软目标成本与物理约束保持不变。

## 4. 日内无结果时的明确回退

允许实时偏离后，原日内硬终态可能在下一轮不可达。只对求解器明确报告ID的SCUC或正式SCED物理不可行记录失败，弃用该轮和旧轮参考，将状态轨迹、价值、水电区间台数与需继承的快速火电启停回退日前。煤机始终按日前锁定，实际库存与累计启动数不重置；后续每个计划日内时刻仍正常重试。

这不是把日内改成软终态，也不将失败轮记为成功。导出失败时段、phase、求解状态、原因和后续逐资源真实来源。辅助定价故障、时限/预算耗尽、取消、软件异常不能走此回退；仍明确中止并保存错误。没有可用日前基准也必须停止。原本明确关闭启停继承或选择free的配置仍保持快速机组自由，不能借回退暗改关闭语义。

## 5. 验证与呈现

- 微模型分别验证：原精确PS1目标不可达而有限偏差可行；物理上下界仍硬；整数与启动预算不松弛；电池/抽蓄双侧、水电单侧；统一能量换算且无重复dt；正负价、末值0与软罚没有伪造残值。
- 覆盖带内/带外、日末进入窗口、辅助保留/移除、硬到软带重试及所有异常分类；确认旧hard和两小时锚点模式未静默变化。
- 故障注入验证ID物理不可行回退，之后成功恢复；旧ID值不得沿用，快速机组按实际配置和回退来源锁定；非允许错误不被吞掉。
- 输出区分“软目标政策合规”“日末偏差为0”“物理与市场缺额”“紧急带软化”，不能用任一项替代其他项。UI明确计划末态偏差不是不可行应急回退，来源和时段完整显示。
- 同一最终代码重跑丰水/枯水×日内开/关四组96段、全量测试与页面验收。报告每主体实际日末原生/能量偏差、优化罚金、备用缺额、成功/失败日内轮数、耗时及gap，不复用旧严格末态结论。
- 以1000为默认研究假设，另对枯水日内开启做100、300元/可放电MWh的参数灵敏度，和1000结果并列，说明经济性、备用与末态偏差的权衡，不据单一样例宣称普遍最优。
