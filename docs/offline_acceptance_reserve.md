# 离线验收中的备用缺额与证据口径

设计先行，2026-11-05。源码基线 HEAD c17fed050af93dd7b211ea190d54c941e592398f；
validate_runs.py SHA256 08f4ea392af45ce394757de54d74836d8454d746b67a7d97259037ce68508c87。

独立区分：运行完成、证据完整、算术/约束复核、终态政策合规、零备用缺额、零非计划松弛、严格验收。
备用供给加缺额满足需求的公式正确，不代表缺额为零。正确记录并回退的ID失败也不是算术错误。
计划软终态偏差单独报告；政策允许的偏差不因此标为物理边界违法，也不阻止“非计划松弛为0”。

严格无非计划松弛验收必须包含正式DA、实际RT和所有有完整来源的RT规划窗口上/下备用缺额。
从完整精度reserve_window_evidence.json读取DA全日和RT逐窗system，检查完整时标、有限非负值、
冻结down_enabled（缺省false），并与rt_system.csv首段和窗口最大值、DA summary最大值交叉核对。
缺字段、缺窗、NaN、负缺额或冲突均失败关闭；不能从summary绿灯推导缺额为零。
禁用下备用仍要求明确的零值证据，不能把缺列当作零。保留独立reserve audit以验证公式和资源约束。

DA的MWh是全日计划积分，RT实际MWh只积分每窗relative_period=0，绝不重复积分重叠未来窗。
未来规划段仅报告最大MW和零缺额判定，不能冒充已执行能量。零容差1e-6 MW，CSV交叉核对绝对容差
5.1e-5 MW（已知四位小数序列化）；真正的零判定使用完整精度，不使用舍入后的CSV。
当前备用证据接口没有成功ID备用窗口，不宣称已核验该部分，也不从ID成功状态伪造缺额数据。

回归保留原文件断言，仅补fixture真实必要字段。独立新增上下备用、DA/RT未来缺额、坏缺证据、禁用
下备用、首段积分和真实dry_id_on只读测试。真实反例应保持完成/备用公式复核通过但零备用缺额、
零非计划松弛及严格验收失败；ID22成功2失败不应被混成数学复核失败。
