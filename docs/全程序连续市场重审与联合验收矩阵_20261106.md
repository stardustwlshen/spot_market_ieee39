# 全程序连续市场重审与联合验收矩阵

2026-11-06。依据用户“并且按照这个思路，对整个程序进行反思优化”，以按日顺序出清、每天独立报价、风光负荷自然来水的资源特征及因果预测、全系统实际状态接续作为统一主线。此矩阵是新增范围的验收计划，不把既有单日通过数当作连续多日已经完成。

## 已定范围

每天使用前一天真实末状态计算当日DA；这不是现实D−1提前计划。每次求解仍为单条确定性轨迹，不新增随机规划。现行日末硬/软目标保留，首版前瞻到日末截断，最小开停义务和物理状态跨午夜传递；不宣称联合多日经济最优。最后一日仍有义务时标记待验证的后续承诺，不能为清空义务禁止午夜启停。

单日新入口为N=1的相同契约；旧单日归档、手工输入和旧误差模型保留其明确版本。现有旧场景缺逐台水电年龄时，不自动补成实际续跑。新版研究默认初态可明确声明、查看和修改；修改导入实际末态必须创建断链的研究起点。

## 必须完成的真实运行链

1. 小模型两个完整24小时：含火电跨日启停、逐台水电午夜义务、电池非默认SOC、抽蓄非默认末库/工况间隔、梯级滞时到水；每日重新报价。独立读取全精度记录重放状态与财务，而非仅调用生产审计器自证。
2. 同一两日条件分别验证ID开启与关闭、缺第二日报价阻断及显式补报价后的日界继续、取消后重复启动不重写已完成日。日中任意段恢复若未实现，准确拒绝而非假接续。
3. 因果模型配套统计和变形测试：按固定种子矩阵报告自相关、组内/组外关系、日夜边界、水文峰时、提前期误差与累计体积误差；修改未来不影响过去已发布信息。简单曲线生成测试不能代替调度接线。
4. 默认IEEE39同版至少连续两个完整日，输出每天DA、ID、96段实际RT、分日利润、状态桥和最后pending。保留MIP gap、缺额、松弛和软末态，不能换种子/改场景来制造全绿。
5. 单日N=1在相同有效输入和同一模型版本下作兼容比较；求解器非唯一整数解及允许gap可能造成不同选解，比较结构、约束、目标界及核算，不把逐点不同直接判为功能退化或改进。
