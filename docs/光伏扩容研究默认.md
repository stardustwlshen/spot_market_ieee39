# 光伏扩容研究默认

本项只更新仓库新默认和从新默认创建的样例。现有用户场景、上传曲线、当前报价、旧报价版本与冻结结果不自动改写；从旧场景复制仍保留原装机。新默认同时使用区外来电供给和multiscale_v2曲线。

## 规模与接入选择

保留PV1在母线33的652MW，新增PV2在母线4、PV3在母线8，各750MW聚合光伏。光伏合计2152MW（原652MW，增加1500MW，约3.30倍），风电仍1604MW；火电3223MW、水电508MW、储能与联络线、需求及所有线路限额不变。

目标是把风光占本地发电装机份额从2256/(3223+508+2256)=37.68%提高到3756/(3223+508+3756)=50.17%。分母不含电池、抽蓄或区外来电，不能把该数字叫作供能份额。这是透明的研究设计目标，不是某地区规划或设备实测参数。

4/8号节点原基准负荷分别500/522MW，分别通过3/5/14与5/7/9多路径接入，可就近供负荷并向周边送出。没有新建支路、抬线路限额或假设所有电量必须消纳。节点配置只是一种原网架聚合资源假设，未经AC、电压/无功、故障稳定性与N-1潮流认证。

## 同曲线网络对照

已比较原652MW、增加1000MW、增加1500MW、增加2000MW三个规模；1500MW增量比较两新增场站都接33、4+27、8+27、4+8四种布局。各布局PV2/PV3采用完全相同的容量、时序、报价，只有节点不同；每种检查基准和“丰水×新能源1.2×负荷0.9”，共14项。

全部使用正式网络/机组/水库/电池/抽蓄/备用约束，将切负荷、过剩、线路越限及备用松弛固定0，只放松整数。目标仍为原报价成本。14项LP均optimal，只用于候选比较，不代表整数计划或实时验收。

- 增加1500MW全部接33：基准日前LP弃光2719.625MWh；分布4+8为0。这避免把新增光伏强行挤入原PV/水电的受限送出通道。
- 基准布局4+27、8+27、4+8均无LP弃光；4+8在两个测试边界中报价目标较低，且两点都是多通道大负荷节点。因此选4+8，不宣称它是全网规划最优解。
- 大丰水/低负荷边界下，4+8仍有LP弃光3389.329MWh、弃风6077.629MWh；这是消纳压力，必须如实呈现，不能靠强制满发或放宽线路消除。
- 增加1000MW时装机风光占比46.60%，尚未达到本研究50%目标；增加2000MW达53.29%，但大新能源/低负荷LP弃光升至5889.187MWh。选择1500MW作为高比例新默认，保留更高容量为后续压力研究而不盲目加码。

详细14项数据见 `docs/evidence/high_pv_layout_20261104/layout_comparison.csv`。复核脚本为 `python scripts/compare_pv_layouts.py --output outputs/pv_layout_check`；精确重放历史对照时用 `--root` 指向对应冻结输入，之后的备用/其他参数更新不能混为同一基线。此候选对照沿用原备用公式，不含后续调度裕度改动；全日正式结果必须另注明采用的最终配置。

## 装机、可用电量与实际发电的区别

固定同一multiscale_v2种子与负荷基准：原风光实际可用电量23186.615MWh（其中PV3652.988MWh），新场景31799.666MWh（其中PV12266.038MWh）。相对88419.879MWh基础负荷，风光可用电量占比由26.22%增至35.96%，新光伏可用电量占比13.87%。这些是模拟实际可用输入，仍不是扣除弃电后的实际供能。

正式DA/96段RT验收须另报实际执行风电、光伏发电量占原始需求的比例、弃风/弃光MWh及弃电率，不能直接用装机份额或可用输入替代。风光聚合曲线与预测误差仍是合成模型，PV站点扰动当前采用独立假设，可能低估区域共云事件；未宣称统计代表性或50%供能。

## 报价、成本和历史保护

- 新报价v3保留v2全部既有主体报价不变，仅增加PV2/PV3，分段完整覆盖各自0–750MW；旧v1/v2文件字节不改。
- 新增PV沿用明确的光伏研究成本5元/MWh，固定成本档案与报价成本依据同时补齐；成本不是报价、也不随容量成倍提高单位电量成本。
- actual/DA/ID/RT四阶段均按各自装机限幅，夜间PV为0；通用资源表、节点拓扑、弃光统计通过type=pv包含所有三个光伏主体。
- 不存在给旧场景偷偷加PV2/PV3的迁移。需要扩容的旧场景应先复制成新研究样例、核对容量/网络/报价/成本后明确采用。

新容量另完成丰/枯水×新能源3档×负荷3档的18组合严格零松弛LP，18/18 optimal，源输入未改变；记录见 `high_pv_18_lp.csv`。仍不是全部组合的整数/96段RT验收。204项报价、成本、历史场景保护、曲线限幅与夜间零出力、场景组合、拓扑相关测试通过。
