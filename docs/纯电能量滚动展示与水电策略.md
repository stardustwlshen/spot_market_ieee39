# 纯电能量滚动展示与水电硬目标

当前仅运行现货电能量：日前SCUC固定整数后做同目标、同物理约束SCED，实时每15分钟滚动、通常前瞻2小时，不新增独立日内市场、调频、容量或额外重定价。

## 运行与报价

运行前选择真实主体ID编辑报价，或者显式选择主体和seed生成可复现分类型报价；手工报价不会被模拟覆盖。按保存后的完整报价校验，冻结配置、输入和报价后启动。运行中展示已执行首段与独立前瞻计划；未执行计划不能当作实际状态或收入。

重复点击不得启动第二个后台求解。取消仅在求解完成边界生效，不强杀正在写数据的求解器。失败或取消保留诊断与已执行前缀，状态不显示完成，不生成完整日结算。重新运行使用新的冻结输入和独立目录，不能覆盖先前失败证据。

## 常规水电研究策略

`MKT.realtime.hydro: window_end_da`：窗口起点使用实际已执行库容和功率；稳定区台数δ沿用日前，但有功功率重新优化。窗口末库容严格匹配日前同一绝对时刻，末日不足2小时则截断到剩余时段。目标等式没有松弛变量或追踪罚因子；若在物理边界、运行区台数或爬坡下不可达，必须报告不可行，不暗改为软约束继续结算。

日前和实时增加的水电爬坡是**电站聚合端点包络**，不是逐台动态、水力过渡过程、机组轨迹或最小开停时间的完整证明。默认每台40 MW/min为研究参数，不宣称是四川规则原样，也不宣称适用于实际电站。

## 读图与单位

- 已执行水电当前库容：万m³；已执行/起点功率：MW。
- 窗口末目标库容与求解计划末库容：万m³，属于前瞻窗口末，不是当前已执行库容。
- 末库容偏差必须按同一站、同一窗口末时刻比较，不能跨窗口累计。
- SCUC预计划与正式SCED的连续功率允许退化或近优方案差异；整数继承与量价同源必须单独验证。
- 原始LMP与裁剪结算价分别展示；能量结算是转移支付，不等于利润。

旧`fixed_da`算例作为历史对照保留。历史零水电偏差或旧阶段快照缺失，不可解释为新策略的验证结果；未保存的数据标N/A，不反推或伪造。
