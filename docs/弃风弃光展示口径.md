# 弃风弃光展示口径

## 入口

- 结果 → 运行总览：日前弃风、日前弃光、实时弃风、实时弃光电量。
- 结果 → 出力计划与实际 → 弃风弃光：风/光分项及场站汇总、可用电量、正式出清电量、弃电率、分时功率曲线、场站筛选和下载。
- 日前/实时各自标明统计时段，实时只有已执行前缀时不标为全天。两阶段弃电量不可相加。

## 定义与来源

仅使用同次运行保存的 `da_unit_awards.csv`、`rt_units.csv` 中的物理量，按 `type=wind/pv` 分组。

- 弃电功率 = `avail_mw - P_mw`；现存 `curtail_mw` 必须与该差额一致。
- 弃电量 = 各时段弃电功率之和 × `scenario_snapshot/config/base.yaml` 的 `dt_h`。
- 弃电率 = 同范围弃电量 ÷ 可用电量，不是逐时段弃电率的算术平均。可用电量为零时弃电率未定义。
- 日前可用量：申报可用预测优先；未申报时采用日前预测。已保存的 `avail_mw` 是最终出清边界，不用当前场景预测重算。
- 实时可用量：每个滚动窗口首个已执行时段；`first_period_actual: true` 是模拟实际曲线，`false` 是超短期预测。仅根据本次冻结配置判断，未记录时明确口径未知。“模拟实际”不代表电站实测值。
- 不使用辅助定价模型数量，也不重复累计未来窗口。弃电不是日前/实时预测或出力之差，不含水电弃水。

## 缺数与旧结果

- 未配置某类资源与该类资源缺少结果分开显示。
- 冻结资源清单和保存的 DA/RT 资源共同识别应有场站；缺少场站/时段、重复记录、非有限数值、明显负差额或字段不一致时，该分项总量不报零，曲线留缺口。
- 缺少时段长度时电量显示“未记录”，保留可核查的功率和同范围弃电率，不借用当前配置的 15 分钟假设。
- 旧表若完整缺少 `curtail_mw` 一列，可由同表保存的可用量减出清量恢复；若只有部分已保存弃电单元缺失，不掩盖缺项。
- 保存 CSV 的四位小数可造成微小差额；只容许 0.0002 MW 以内的舍入容差，不把明显负弃电截成零。

这是只读展示，不修改求解模型、报价、输入参数或已保存结果。
