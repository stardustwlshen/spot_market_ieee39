# 结算显示完整性补充修订

目标：读取已保存结果时，结算表不因重复行、非数值或不同聚合层级不一致而显示可用金额或“通过”；损坏的可选利润表、文件索引不使物理结果整页崩溃。不会重算市场、修补原档案或改变结算规则。

- 对逐时结算、逐主体、逐类型表校验已有业务数值、唯一键及类型一致性；对保存齐全的金额列核对“明细汇总→主体→类型”，采用1元绝对容差覆盖CSV四位小数累计舍入。数量汇总采用0.01MWh容差。
- 缺少旧版本可选列时保持未验证，不补零；已知损坏通过现有结果读取失败提示保留切换入口。
- 独立成本/利润表在该面板内校验、隔离，展示可读错误并保留原文件，不修改冻结结果。
- 文件索引先检查顶层对象与条目列表。索引不可读时只关闭文件浏览，不中断已保存物理量价和结算。
- 测试使用独立小样本及真实求解归档的内存损坏变体；另核对本轮真实96段结果。浏览器像素与下载落盘不冒充完成。
