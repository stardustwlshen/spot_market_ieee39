# 最终诊断与复现文件

## 先读

1. `枯水低新能源高负荷备用诊断.md`：原失效机制、100/250MW、相同原模型parallel单项对照及精确正式计划恢复。
2. `动态日前预留研究说明.md`：不使用评价实际数据的固定B规则、两个完整运行、残余不足、成本与概率解释边界。
3. `README_复现说明.md`：环境、参数化命令、失败历史与可信checkpoint使用说明。
4. `analysis_script_manifest.json`：上述报告与12个复现脚本、紧凑指标的SHA256；不是冻结运行归档的替代索引。

## 紧凑指标

- `counterfactual_comparison.json/.csv`：原默认及100/250MW完整96段。
- `parallel_strategy_comparison.json`、`parallel_RT96_comparison.json`：原模型同问题求解策略和恢复后RT。
- `dynamic_reserve_comparison.json`：B不利组合与普通日控制、成本和限定。
- `dynamic_B_posthoc_diagnosis/shortage_decomposition.csv`：B剩余4段的全精度功率/库存分解。
- `dynamic_B_dry_lowre_highload_input_audit.json`、`dynamic_B_dry_nominal_input_audit.json`：冻结快照、报价、序列化及DA增量/不变RT需求核对。

## 完整运行

- `da_buffer100/`、`da_buffer250/`：原先封档，未改写。
- `parallel_on_DA/`：唯一parallel=on原模型DA；`parallel_on_DA_sced_replay/`与`parallel_on_DA_recovered_RT96/`：无新SCUC的正式计划恢复及真正新96RT。
- `dynamic_DA_proposal/`、`dynamic_DA_nominal_proposal/`：分别冻结的DA-only信息、规范、种子误差矩阵、96数组和检查。
- `dynamic_B_dry_lowre_highload/`、`dynamic_B_dry_nominal/`：两次B完整运行；准确紧凑结果与全精度增量审计在各自`postprocessing_recovery/`。
