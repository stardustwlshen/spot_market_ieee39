# 严格复核：火电启动和停机事件互斥

## 原问题

现有逻辑仅含 u[t]-u[t-1]=v[t]-w[t]，不能单独排除 v=w=1。当最小停机时间设为 0（现有有效技术输入）且滚动关闭 tightening 时，机组可同段声明启动和停机而保持在线，利用启动/停机爬坡放宽从实际起点跳变。真实 HiGHS 单段反例中，初始在线出力 50MW、正常15分钟爬坡15MW，机组虚构两事件后达到100MW；正确上限为65MW。问题不仅是计费标签，也改变物理可行域与结果。

## 修订

在所有 DA/ID/RT 模型的启停守恒约束旁显式加入 v[g,t]+w[g,t]≤1。继续允许既有非负最小持续时间参数，不用拒绝合法零值掩盖模型漏洞；不调整报价、成本、爬坡率、缺额罚或默认场景。辅助定价模型克隆仍保留原整数，自动继承这一逻辑。该约束落实已有事件语义，不引入新市场规则。

## 验证

独立反例覆盖上/下爬坡、统一/冷热态启动成本、ut=0或1且dt=0、tighten=False，原树8项失败。集成后重新求解这些反例，核对事件互斥与正确爬坡上限，再做既有机组组合/备用/结算及全套回归。普通默认正持续时间场景是否改变只凭同版运行证据判断，不预先声称完全等同。
