# 水电上备用出库流量验收记录

## 已实施内容

共享调度模型增加`water_rate × (站内基准发电＋站内上备用) ≤ qout_max`，仅在参与水电备用且配置上限时生效。不乘时间，不新增额定值。允许以减少可控弃水证明当下总出库流量分配存在；生态要求仍为总下泄下限。15分钟时段末增量库存约束保持全额耗水，不抵扣减弃水收益，不执行完整激活轨迹。

新备用证据版本为3，包含基准出库、理论激活发电/弃水/总出库、出库上限及生态下限余量。版本2历史证据仍可核验库存，但不认证新增激活出库。原无版本容量证据继续明确未核验新增水量及出库规则。新summary及逐窗记录缺字段或降级会被拒绝；出库和生态参数与冻结输入逐项比对。

未配置出库上限时状态为“未配置”，余量保持空值、核验状态为未适用，不把它显示为无限能力或零余量。界面明确理论激活流量不是执行量。

## 相同输入真实对照

| 情景 | 新增出库筛查前 | 新增出库筛查后 |
|---|---|---|
| 基准20MW、水耗率1、总出库上限20m³/s、库存足够 | 上备用80MW，激活发电流量100m³/s越界 | 上备用0MW，总出库20m³/s |
| 基准20MW、弃水60m³/s、生态下限和出库上限均80m³/s | 上备用80MW，激活总出库100m³/s越界 | 上备用60MW，理论激活弃水0，总出库仍80m³/s |
| 基准20MW、水耗率2、出库上限80m³/s | 上备用80MW，激活发电流量200m³/s越界 | 上备用20MW，激活发电流量80m³/s |
| 负荷90MW、要求上备用50MW、出库上限60m³/s、库存充足 | 水电50MW、当地火电0MW、节点价10/10元每MWh | 水电10MW、当地火电30MW、节点价10/700元每MWh |

对照只切换出库筛查代码，原水量约束已经在两个版本中启用。最后一例正式及辅助定价LP分别对两节点做0.001MW有限差分，除以0.25h，与节点价的允许误差为0.0001元/MWh。

## 测试及范围

最终综合回归261项通过，包含出库61项专属测试、水量及储能备用、辅助定价、逐窗证据、独立验收和界面。另有前序61项与80项测试，均已包含于综合范围，不重复累计。

覆盖多机站级聚合、非1耗水率、调度间隔和持续时间不混入瞬时流量、可减弃水与生态下限、基准出库不可行反例、无上限和禁用参与、水量独立收紧、版本与冻结输入防篡改。真实短日写盘回读覆盖日前、日内、实时及各阶段正式/辅助备用证据。

目前默认启用水电的qout_max为空，本条不改变该默认场景物理解；最终完整日、最终源码全套及归档版本仍由集成验收另行验证，不能由这里的小系统测试替代。

未新增独立不可减旁路生态流量或闸门响应参数。若工程需要这类限制，须补充数据后扩展。出库和库存筛查通过不等于完整爬坡、稳定区跨越、未来轨迹、梯级联合激活及网络备用可交付认证。
