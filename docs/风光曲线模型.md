# 风光输入：实际波动与多尺度预测误差

## 使用与兼容性

打开“单机报价模拟”，在运行按钮上方展开 **风光波动与预测误差：预览并采用新版**：

1. 选择“新版：实际波动与多尺度相关误差”。
2. 点击“预览风光曲线变更”，查看当前/预览实际与日前可用功率及误差、15分钟变化统计。
3. 勾选“我确认改变该场景未来运行的合成风光输入”，点击“采用预览曲线模型”。
4. 重新运行。已有结果仍显示原冻结输入下的出清结果，不会被重新绘制成新版。

版本只写入该场景的 `config/base.yaml`：

```yaml
forecast:
  model: multiscale_v2
```

**省略 model、或显式 `legacy_v1`，均逐值保留旧生成方式。仓库模板也仍为旧版，升级代码不会偷偷迁移已有场景。**
界面一直显示当前版本，用户明确采用后才改变未来输入；也可按相同预览流程显式切回旧版。旧场景自定义的 sigma/phi 不会被重置。

- 已有 `runs/`、结算、历史图表、报价档案不改写。
- `data/profile_overrides.csv` 逐字节不改写，其中显式列逐值优先。只上传 actual 而没有上传预测列时，原有“保持生成误差推导缺失预测”的规则仍适用，因此未上传预测会随模型变更。
- 报价里的 `avail_pmax` 不改写，仍可优先覆盖**日前**可用功率；预览会提示，输入预览不冒充该报价下的正式出清结果。
- 负荷与联络线生成不变；新能源出清、网络、弃风弃光及实时首段执行规则不变。
- 浏览和预览只读。采用前再次验证配置及上传文件指纹；文件已变更则拒绝，要求重新预览。配置原子替换，失败保留原内容。

## 为什么旧版会出现“日前锯齿、实时光滑”

旧版风电实际曲线是24点标幺模板的线性插值，不随随机种子变化；日前预测在其上叠加 AR(1) 误差。默认实时窗口首段直接用实际可用功率，因此无弃风时，实时出清几乎复刻光滑模板。图表本身没有做平滑。

新版从**生成输入**改起，不对出清结果或结果图做后处理。允许真实侧有15分钟随机波动，同时让预测误差更多表现为持续偏差、缓慢漂移，而非不断反向跳变。波动仍存在，不能保证任意参数或任意种子都完全光滑。

## 新版数学约定与研究假设

### 模拟实际可用功率

风电、光伏保留原日形状，叠加独立于预测误差参数的慢、快随机分量，再截断到 `[0, 装机容量]`。

| 资源 | 慢分量标准差/装机 | 快分量标准差/装机 | 慢过程极点 | 快AR(1)系数 |
|---|---:|---:|---:|---:|
| 风电 | 4.5% | 1.8% | 0.90 | 0.65 |
| 光伏 | 4.0% | 1.6% | 0.85 | 0.55 |

这些都是**版本化研究假设，未以真实电场样本标定**。光伏扰动乘日照门函数，夜间实际值及全部预测严格为零。风场共享与本地随机分量组合，设定风场间相关系数0.6；光伏站间暂按独立处理。

相同 seed、模型和输入可重现。改变预测 sigma/phi 不改变对应模拟 actual；改变 seed 才产生新的 actual 情景。独立随机子流使新能源资源重排不改变该资源的曲线。

### 预测误差

单位方差慢、中尺度过程都前向递推：

```text
x[t] = 2φ x[t−1] − φ² x[t−2] + s ξ[t]
s² = (1−φ²)³ / (1+φ²)
Corr(x[t], x[t−1]) = 2φ / (1+φ²)
E = sqrt(0.85) × x_slow + sqrt(0.15) × x_medium
slow 的极点 = φ；medium 的极点 = φ⁴。
F_stage = clip(A − sigma_stage × 装机 × 日照门函数 × E, 0, 装机)
```

风电门函数为1。初值取解析平稳分布；没有居中移动平均、样条拟合、按整天样本归一化、减去该日均值、或为了凑准确率缩放已生成序列。sigma 是**截断前总体标准差**，单日 nRMSE 会波动，物理截断及光伏夜间会影响观测指标。

默认 sigma 沿用旧版：风电15%/6.5%/3%，光伏12.5%/5%/2.5%，对应日前/日内/超短期。新版要求 `sigma_da >= sigma_id >= sigma_rt >= 0`，且风光 `0 <= phi < 1`，非法值明确拒绝，不偷偷校正。

新版阶段间共用同一误差路径、仅按幅度缩小，因此**截断前阶段误差相关系数为1**，截断后仍保证逐点绝对误差非增。这是明确的理想化“嵌套误差”假设，不表示真实预测修订也是完全相关。旧版短阶段另加0.3倍独立噪声，新版不保留该项，不能声称各阶段误差分布与旧版完全相同。

`phi` 在旧版是AR(1)系数，在新版是二阶过程极点，数值虽保留、统计含义不同。设为0会退化为白噪声，不再保证曲线少锯齿；无需限制正常极端实验，但必须解释参数改变。

## 信息可得性与解释边界

**这仍是 F=A−e 的离线联合情景生成器，不是可以上线使用的预测器。** 它用模拟未来actual与误差构造预测；前向随机过程没有利用未来样本做平滑，不代表整个联合情景具有真实预测算法的信息约束。不能用这里的“预测准确率”宣称真实算法效果，也不能把实际曲线称为实测。

真实预测研究应换用按发布时间对齐的历史预测与15分钟实测可用功率，或建立只使用发布时刻可获得信息的预测模型。当前每个实时窗口首段用actual的理想化假设继续保留，后续执行残差/AGC未因此被补上。单日平稳初始化不等于跨日天气连续性。

正式结果图画的是**出清功率**，还受报价、网络及系统约束影响；输入变得连续也不意味着出清曲线必然连续，或弃风可以消失。

## 128种子复现实验

默认1040MW W1，seed从20260715到20260842，共128个。只比较生成输入，**不含上传覆盖、申报覆盖、市场求解或结算**。nRMSE均以装机归一；“汇总”先汇总所有样本平方误差再开方，不等同于逐日RMSE的平均。

| 资源 | 阶段 | 旧版汇总nRMSE | 新版汇总nRMSE | 旧版平均15min变化 MW | 新版平均15min变化 MW |
|---|---|---:|---:|---:|---:|
| W1 | 日前 | 14.879% | 14.272% | 36.034 | 18.439 |
| W1 | 日内 | 6.779% | 6.246% | 18.577 | 16.841 |
| W1 | 超短期 | 3.130% | 2.883% | 12.240 | 16.486 |
| W2 | 日前 | 14.909% | 14.415% | 19.307 | 9.125 |
| W2 | 日内 | 6.816% | 6.272% | 9.288 | 8.131 |
| W2 | 超短期 | 3.135% | 2.895% | 5.302 | 7.944 |
| PV1 | 日前 | 6.848% | 7.024% | 14.806 | 11.925 |
| PV1 | 日内 | 2.833% | 2.898% | 11.531 | 11.407 |
| PV1 | 超短期 | 1.417% | 1.449% | 10.933 | 11.282 |

W1实际平均15分钟变化从10.181变为16.388 MW；日前二阶差分RMS均值从62.792变为25.283 MW，减少59.7%。日前平均相邻变化减少48.8%，但预测误差仍为同一量级，没有靠令预测等于actual来“变平”。短阶段变化增大是新增实际侧波动的结果，不能宣称所有阶段都更平滑。

执行：

```bash
python scripts/audit_forecast_models.py --seeds 128 --output /path/to/NEW_audit_folder
python -m pytest -q tests/test_multiscale_forecast.py tests/test_forecast_settings.py
```

脚本只写新指定证据目录，包含每seed指标、汇总、两版本例子、同坐标尺度W1对比图和明确的实验范围，不改场景。新求解输出另写 `da/profile_generation.json`（仅日前输出则位于其输出目录），记录版本、参数、输入覆盖及信息限制；旧结果不会补写或推断成新版。
