# 电网运行分析人员操作边界复核

基线为 90d3771。本轮仅修改结果读取、呈现与对比的边界处理，没有调整模型、备用需求、报价、约束、罚系数或已封存的实际求解结果。使用固定依赖的 Linux Python 环境和 Streamlit AppTest，不是浏览器像素或 Windows/macOS 真机验收，也没有新增一次全天求解。

## 已复现并修复

1. **缺时段却仍称完整日。** 从真实96段档案的内存副本删掉RT第41段节点价格，原页仍显示“96 / 96 段”且没有错误。现在核对每个主体/节点的时段记录、跨表时段集合和保存摘要的声明范围，拒绝缺段、重复或不一致；旧档案只有 `periods` 时也核对它。合法DA96/RT8仍按8段显示，不与完整日混同。
2. **缺节点或整数值浮点时段导致崩溃。** 原页缺整节点16时抛出KeyError，时段写为0.0、1.0等整数值浮点时绘图TypeError。现在核对DA/RT节点集合及本次冻结节点全集，并将已验证的整数时段和数值字段转为明确数值类型，不补造缺行。
3. **丢RT价格文件被静默当成仅日前。** 现在以本次保存的全流程范围或运行类型保留全流程身份；必需实时文件缺失时中文提示损坏，保留选择器切换到正常结果。真实仅日前结果仍正常打开。
4. **真实短段结果被错误拒绝。** 已有真实DA96/RT8运行 `20261103-211945-688139_full` 的线路租金表只有合法表头。生成器只保留非零租金线路，空表不等于坏档。现在允许该表合法空表头，但缺文件、缺必要列及其他必需空表仍拒绝。没有把缺失租金补零。
5. **场景对比仍借用了当前网络。** 去掉缺历史输入时的当前网络路径回退；每次比较只使用各自保存的负荷权重或冻结节点。缺电量加权均价时保持未知，不用逐时均值替代。不同RT执行范围下，实时价格、总量及损益差值留空，结算总额不相减，并说明原因。
6. **修复文件后页面可能读旧缓存。** 缓存指纹现在覆盖本次结果CSV、DA子目录及冻结输入的文件身份、大小和修改时间；冻结线路限额与资源名称也不再只按目录长期缓存。验证了修改、删除及恢复后读取新记录，不需要篡改摘要来刷新。
7. **坏摘要、坏冻结节点或诊断CSV中断查看。** 必要摘要对象结构和冻结节点数据在读取保护范围内校验；坏 `spread`、坏节点CSV给中文错误，选择器仍能恢复。可选导出CSV解析失败时保留文件选择和原文件下载，允许切换其他表，不伪造可解析表格。抽蓄终态缺失显示“未记录”，不补为零。

## 集成追加：整主体记录丢失

集成独立复现发现，主体的96行全部消失时，单表矩形检查仍可通过：分别删去RT出力PV1、DA出力PV1或RT储能ES1，均未被旧检查发现。补充为：

- DA主体至少包含本次冻结配置明确启用且参与的资源。禁用资源不要求出现；联络线转换固定负荷时不要求TIE出力，缺冻结base时不猜测其历史模式。
- RT非TIE主体全集与保存DA主体核对。已支持的旧RT完全缺外生TIE记录仍保留警告路径，不补零、不借日前计划充当实时值。
- 已保存储能、水电、抽蓄状态表核对同类主体全集，避免某台状态整体消失。完整RT储能状态缺失仍拒绝；历史可选的水电/抽蓄/DA状态表未保存时保持原有未知行为，不新增伪状态。
- 仅用本次档案与冻结机组，不读取当前配置。没有可靠冻结主体目录的DA-only历史结果，无法单凭剩余行证明从未丢失整个主体，此限制仍需保留。
