# 程序精简边界（2026-11-09）

本说明记录入口与研究工具的精简，不是当前源码的全天数值验收报告。

## 已移除

- `scripts/demo_rebid.py`：硬编码 CCGT/ES2 改价、自动向项目报价目录新增版本并求解的旧演示。正式网页已具备报价校验、版本保存、单日运行与场景对比，无需维护第二套演示流程。连同只有该脚本调用的 `smm.plots.rebid_compare` 一并移除；普通日前、实时、结算与预测绘图保留。
- `scripts/benchmark_causal_v3.py`：无其他代码调用的硬编码单种子三日、121窗口性能计时脚本。不是物理或信息可得性验收工具；正式预测模型、审计脚本和回归测试保留。

历史开发文档中的旧命令、结果图名及 `PACKAGE_MANIFEST.json` 保留为历史记录，不表示这些入口仍受支持，也不是当前发布清单。场景、报价、曲线、历史结果、研究证据均未因本次精简删除或迁移。

## 保留并收紧

`bench_scuc.py` 保留求解参数对照用途，移除无输出用途的结果列表。导入模块不启动计算；帮助和所有参数先验证，再读取配置。准备算例改为只读，避免性能研究顺带重写曲线或创建默认报价。求解变体及其数值参数不变。

抽蓄对照 `compare_pumped.py` 删除不校验来源的 `--reuse` 捷径，避免混用不同参数/时段的旧结果。每次新建独立对比目录，或用 `--output` 指定未存在目录；两个方案在求解前冻结有效输入，准备阶段只读，不改写源曲线或报价。默认汇总放在独立对比目录，完整结果各自采用含批次标识的唯一顶层 `outputs/full_*_MKT_*` 目录，因此仍可通过网页结果和场景对比查看。显式 `--output` 时两份完整结果和汇总均放在指定研究目录内，不自动加入网页目录。失败留下现场，不覆盖既有结果。历史共享输出与旧报告原样保留。对照启动前记录配置、数据、报价及源码指纹，并在各次准备、求解和汇总前复核；发现外部修改即停止，保留已有部分证据，不把两种输入混作同一对照。

## 不作为冗余删除的内容

- `start.bat`、`start.command`、`start.sh`、`launch_app.py` 是普通用户跨平台入口；`run_app.sh`、`manage_app.py` 是独立开发环境的后台管理入口。两者环境与进程所有权不同，不混用停止命令。
- `main_da.py`、`main_full.py`、`run_scenario.py` 是正式命令行入口；`make_default_bids.py` 校验后新增报价版本，不覆盖 v1。
- `restore_tie_supply.py`、`repair_cost_archives.py` 是显式恢复工具；不因日常不用就删除历史恢复能力。
- `validate_runs.py`、`k_batch.py/.sh`、预测审计、抽蓄对照、光伏/储能布局研究、状态价值符号核对及网络导出脚本仍有独立验证或可复现用途。
- 运行依赖没有删除：绘图、网络图、模型求解、YAML保留式编辑和跨平台进程核验均仍在使用；`pandapower` 和 `pytest` 仅在开发依赖中。

进程检查仍采用主机/启动范围、创建时间和命令身份，不通过旧 PID 强杀进程。Linux测试不替代 Windows/macOS 实机或浏览器像素/下载验收；历史 Windows/cloud RT 差异也不因本次清理得到解决。

## 研究工具的剩余操作边界

`fd_value_sign.py` 按水文期写固定诊断文件，`audit_causal_v3.py` 默认写当前目录统计文件（也可指定路径）。两者在昂贵计算前检查所有输出，遇到已有文件即停止；最终采用排他新建，防止检查后又出现同名文件时覆盖。导入模块不运行计算，不新增覆盖或续跑开关。请保留旧诊断文件，另选工作目录或统计输出路径。因果审计仍使用历史 POSIX 内存统计接口，不代表 Windows 原生支持。`export_case39.py` 的用途就是重新导出并替换网络 CSV，不应当作只读核验命令运行。
