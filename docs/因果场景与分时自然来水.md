# 因果场景与分时自然来水（v3）

## 启用边界

模型标识为 `causal_physical_v3`，消费者契约为 `causal_inputs_qin_v3_1`。必须显式选择新模型并提供已冻结的来源包；旧 `legacy/v2`、单日手工曲线和原有常数来水假设沿旧入口保留。新模型不借用旧 `forecast_view`。本版网格为 96×15 分钟；内部每 5 分钟推进，再取三个子段均值。跨 DST 的 23/25 小时日拒绝运行。每次优化只有一条确定的输入轨迹，随机性只在合成输入及预测者分析偏差中。

消费者 ready 只表示输入接线已安装，不能代替系列状态引擎的独立准入、场景可行性或用户界面的验收。首版来源模式为冻结的合成 bundle；不提供把旧上传表自动解释为 v3 因果资料的功能。

## 单位、来源与优先级

- 风、光、系统负荷为每段平均 MW；自然来水为每段平均当地自然流量 m³/s，绝不包含受控上游出库。
- `ResourceSpec.scale` 是公开的正数尺度。风光取技术容量。`resources_from_config` 的负荷尺度沿用固定研究基准 6254.23 MW × `load_scale`，不是 buses CSV 的负荷之和；网络负荷决定节点分配权重。自定义 ResourceSpec 可以显式给不同的公共负荷尺度。
- 来源清单中的 `public_resources` 和 `public_load_scale_contract` 同时记录实际公开尺度、固定配置适配器公式和网络权重角色。
- 水站初始季节 `qin` 用作固定公开 Qref，必须大于零。初始为零时本适配器拒绝 v3；可以保留旧常数零模式，或另行显式声明正研究参考尺度。日卡可以有零目标，不代表把水文状态瞬间清零。
- 每日季节改变通过 `seasonal_inflow_spec(reference, day_qin, preset)` 把目标和脉冲幅值乘 `day_qin/Qref`；不重置流量状态，不改公开 Qref。组合参数超范围报错，不静默裁剪。
- 实际过程卡默认是模拟器私有信息。风大、暴雨等未来卡片不会自动成为预测器的已知天气。公开条件必须另有 PublicEvent 及 `released_at`。
- 报价每日独立。非空风光 `avail_pmax` 必须声明 `issued_forecast`、`public_bound` 或 `user_declared`。生成报价模板只可使用已经发布的 ForecastFrame 或显式公共/用户申报值，不读取未来 actual。

## 实际过程

固定公开 35 天预热，任何未来日卡均不能改变这段前史。前史是研究合成值，不是假称实测。潜状态跨午夜连续；修改预测质量不重抽 actual。实际参数及范围以 `causal_presets.capabilities().parameter_schema` 为机器可读唯一枚举。

风：慢、快两个变换域状态，各按 `a=exp(-Δt/τ)` 的均值回归过程推进；创新为 `sqrt(ρ)×组公共创新 + sqrt(1−ρ)×本机创新`。输出为 `容量×sigmoid(慢+快)`，严格容量内。慢尺度 2–24 h，快尺度 1/6–2 h；低、正常、高、爬坡、波动场景改变目标和时间尺度，而不是在功率上直接叠加独立白噪声。

光：公开合成晴空包络为日出/日落间 `容量×peak_ratio×sin(太阳时相)^gamma`，夜间严格零。持续晴/阴云态按驻留时间切换，云指数在 logit 域连续响应；同研究组共享切换及部分创新。云状态夜间仍演化，不能把夜间零出力当作云指数零。晴空时间是显式研究参数，不是 IEEE39 节点的真实地理太阳位置。

负荷：公开日形及日历乘慢/快相关的对数残差。周末/显式假日改变水平和峰时，日界后的两小时渐变只使用已知日历。私有峰移连续响应。对数残差限制在公开研究域 `±b_max`，记录裁剪次数；输出非负。高/低负荷目标、峰移与波动参数分别生效。

自然来水：非负背景补给、持续脉冲和相关缓变扰动驱动两级水文响应库。第一响应库上升与退水采用不同时间常数，第二库作滞后平滑；脉冲按事件时间和可配置滞后启动，不作用于未来事件之前。输出为当地自然流量。背景 12–168 h、增水 0.5–24 h、退水 2–168 h、汇流 0.5–48 h；脉冲可跨日。受控上游水另从真实/选定计划的总出库（发电加弃水）按滞时取值，不重复加入自然水。

分组相关性是声明的研究组，不把电气母线距离冒称地理距离。研究数值未经当地数据拟合，不提供发生概率、置信区间覆盖率或预报准确率保证。

## 发布时钟与信息边界

`PredictionRequest(issue_time_utc, target_start_utc, target_end_utc, stage, policy_id, policy_overrides)` 返回不可变 ForecastFrame。所有时间规范化为 UTC，目标区间不能早于 issue。阶段名称本身不改变随机数。

常规区间均值只在区间结束并经过声明的观测时延后可用。基准政策额外时延：风/光/负荷 15 分钟，自然水 60 分钟；responsive 为零额外时延，delayed 分别为 60/30/60/180 分钟。用户声明的设备观测时延另外累加。

预测器只收到可用观测前缀、公开尺度/日历和已经发布的公共条件，不收到未来 actual、私有日卡或模拟器水文潜状态。分别对风容量因子、光云指数、负荷/公开基线比、来水 `log1p(q/Qref)` 滤波。水平及阻尼趋势预测使用公开先验回归，并加独立、持续、随 lead 展开的分析偏差；这是假设的合成预测者，不冒称数值天气预报或严格条件均值。

持久滤波状态停在最后已接纳观测的有效时刻。发布时使用副本前推，不能把发布时钟当作已观测时钟。正常递增请求增量吸收观测；迟到观测、较早 issue 或不兼容前缀从当时合法前缀重放。相同信息集和请求必须得出同一发布哈希；以后到达的真实创新、未来实际卡片和后来的观测不能改写已发布结果。

日序仿真基准 DA 在日初发布，不称 24 小时提前。ID 与 RT 各使用自己的显式 issue。当前版本 RT 必须显式启用首段完美均值研究观测：仅当前执行首段可替换为 actual，来源标记 `current_interval_perfect_measurement`；真实在线系统通常要段末才知道这一均值，这不是常规预测 API 的权限。未来段仍全部使用该 issue 的发布预测。

## API 与冻结

- `compile_provider(ProcessPlan, forecast_policy_by_date=..., public_events=...) -> (ActualStore, CausalInputProvider)`：整个系列只生成一次。
- `save_bundle(new_directory, actual, ...) -> bundle_content_hash`：写 `manifest.json` 和 `actual.npz`，拒绝覆盖；`load_bundle(directory)` 校验后返回全新 provider，不重抽 actual。
- `provider.source_manifest()`、`day_summary(day_start_utc)`：来源/日界摘要。
- `provider.select_day(day_start_utc, issue_period, start_period, stage=..., end_period=96, current_interval=False, executed_through_period=...)`：返回覆盖剩余日的 SelectedInputs。缺站、缺段、错网格或执行边界矛盾均拒绝。
- `build_da_case(..., input_provider=provider, selected_inputs=..., day_start_utc=...)`：solver case 只带公开计划和已选预测，不携带未来 actual 表列。
- `provider.archive(day_start_utc)`：只导出该日选中记录和关联发布，避免把前日窗口重计为当日。无参数时显式返回累计注册表。

随机子流按模型版本、根种子、realization、角色、资源/研究组派生；Philox 计数器是绝对 5 分钟序号。改变资源顺序、加入无关资源或延长末日不改变已有前缀。模型/RNG/参数/输入哈希写入来源包。每日重新报价不触发重新生成。

## 来水消费者闭环及归档

所有新模式的自然水均通过同一 SelectedInputs 读取：SCUC/SCED 主水量、DA/ID/RT 窗口、水价值可达带、软末态前瞻、日电量物理后缀、辅助定价克隆、备用证据和独立审计。模型的旧标量 `qin` 在新模式为 None，禁止遗漏消费者静默退回季节常数。后缀覆盖该 issue 至当日末的剩余段，不读取未来实际，不虚造最后模拟日之后的预测。

`da_hydro.csv`、`rt_hydro.csv` 区分 Q_natural、Q_upstream、Q_in，附 issue、forecast_id 和首段来源。输出冻结 ForecastFrame 和 SelectedInputs，独立核对来源哈希及未来值；不能只相信诊断自己声称的 qin。`forecast_accuracy.csv` 在 v3 普通运行中为空且明确范围，不能为画误差图给 solver 注入未来实际。研究统计另外比较保存的发布预测与合成实际。

## 验收解释

因果测试包括未来私有卡片变化不影响已发布预测、扩展末日与资源顺序不变、乱序/重复 issue、迟到观测重放、观测时延、夜间零光伏、容量/非负、报价来源与冻结归档篡改拒绝。小型真实求解覆盖全日 DA、RT、ID、水后缀与辅助价。

64 种子×7 天统计使用每天 00/06/12/18 四个 issue、baseline/responsive 两政策，共 3584 个发布样本；不是每天全部滚动窗。按资源组和 lead 桶比较统计均值，不要求每条样本 DA 误差大于 ID 大于 RT。跨日状态及两日市场可行性需由同版系列引擎另行联合验收。

压力夹具若出现线路越限，必须保留并标记不可行；来水输入接线/审计通过不等于电网可行。哈希证明来源一致，不证明物理约束、市场收益或科学校准成立。

方法背景：NREL 风预测误差提前期与时空相关研究（https://docs.nlr.gov/docs/fy11osti/50614.pdf；https://www.osti.gov/servlets/purl/1471480），太阳持续性与晴空建模（https://docs.nrel.gov/docs/fy20osti/75755.pdf），负荷预测综述（https://doi.org/10.1016/j.ijforecast.2015.11.011），水文集合/后处理研究（https://doi.org/10.1029/2018WR022601；https://doi.org/10.1029/2020WR028392）。这些支持建模特征，不是本系统参数实测校准证据。
