# 典型场景覆盖与分层

## 定位

本项目是修改过的IEEE39合成现货研究系统，不是某个真实地区的统计典型日。当前边界恢复区外来电供给，不减少基础负荷、不额外增加装机、不提高线路限额。新默认使用 `multiscale_v2`；旧场景缺少模型键仍保持 `legacy_v1`，上传和已冻结曲线不静默重生成。

“丰/枯水”只切换真实进入模型的水文配置，不自动把7月曲线变成经实测验证的枯水季气象/负荷。风光、负荷幅值等级是透明的研究假设，没有概率权重。统计代表性需要真实或有来源的多日数据、季节关联和独立误差样本；不能用18或54个格子的数量代替这些证据。

## 覆盖矩阵

- 基础：丰/枯水 × 风光同时基准/1.2/0.8 × 负荷基准/1.1/0.9 = 18组合。
- 扩展：丰/枯水 × 风电基准/1.2/0.8 × 光伏基准/1.2/0.8 × 负荷基准/1.1/0.9 = 54组合。新增风大光小、风小光大和单一新能源变化，原18是其子集。
- 时序压力：可叠加傍晚持续低风。16–17时线性降至所选风电水平的25%，17–21时保持，21–22时线性恢复；使用15分钟时段中点。PV不受此事件影响。它是已预见的低风形状压力，不是日前漏报或预测误差尾部测试。
- 四阶段一起调整，保留源曲线的误差相关结构；倍率不会替用户独立改变误差方差或加入随机假设。重复组合以保存基准计算，不连乘；恢复基准时独立风/光倍率和时序事件一起取消。出力受原装机上限截断并显示截断点数。
- 供电模式的TIE固定计划不随区内负荷等级缩放；旧固定负荷兼容模式按原逻辑各缩放一次。负荷仍是外生需求，不报价、不做需求响应。

## 电量与功率必须分开

现有火电3223MW，H1水电508MW，电池400MW/800MWh，抽蓄600MW。风电1604MW；扩容前光伏652MW，新高比例默认光伏2152MW，布局及比例见《光伏扩容研究默认》。这些额定MW不能直接当全天可供电量。

H1同日末库容边界下，丰水来水560m³/s、耗水率1.2m³/s/MW，水量可支持的大发电量为560×24/1.2=11200MWh，低于配置的12000MWh日电量上限；枯水为220×24/1.2=4400MWh，低于配置5000MWh。预览取水量、日电量、装机三者上界的最小值。梯级来水无法由简单公式独立确定时，不把仅有本地来水误判为总来水，保守放弃该项上界。

电池与抽蓄日末库存等于初值时，净供日电量上界为0，实际还消耗充放损失。600MW抽蓄可以移峰、缓解约束，不能补长期一次能源缺口。预览分别列MW和可消耗初始库存折算净MWh；不会把全日满发储能当作可用一次电源。

## 三层证据

1. 输入必要条件预检：使用乐观的全部可调容量、可用风光、TIE及水量上界，展示每阶段日电量缺口下界、瞬时功率缺口下界和“电能量或上备用”联合容量缺口。若已失败，明确归为压力；未失败只能叫常规候选。
2. 严格零松弛LP筛选：使用正式SCUC所有物理/网络约束，把切负荷、过剩、线路、上下备用松弛固定0，仅放松整数。不可行可证实没有严格零松弛整数计划；可行不证明存在可执行整数计划。LP结果不参与结算。
3. 正式全天验收：DA SCUC/固定整数SCED、96段RT、两级结算，保存实际求解终止状态/gap、正式量与辅助算价、每种松弛、网架和库存校核。未完全天、时限内仅有较大gap、或任何物理不足均不能写“常规已通过”。有约束绑定或新能源弃电不等于线路越限，允许前者，不能隐瞒后者。

保留原惩罚、价格裁剪、2小时储能硬锚、抽蓄定速/互斥/启停/库容约束。不能靠裁剪价格或辅助算价的量值遮住正式调度松弛；上限价800本身不是物理正常的证据。

## 可复现检查

在项目根目录激活环境后：

```
python scripts/audit_typical_scenarios.py --output outputs/typical18_v2
python scripts/audit_typical_scenarios.py --output outputs/typical54_v2 --split-renewables
python scripts/audit_typical_scenarios.py --output outputs/typical18_lp --solve strict-relaxation
python scripts/audit_typical_scenarios.py --output outputs/dry_low_re_high_load --select dry_re0.8_load1.1 --solve full
python scripts/audit_typical_scenarios.py --output outputs/evening_lull --select dry_re0.8_load1.1 --wind-event evening_lull --solve full
```

输出目录必须不存在；所有读取源、有效配置/报价、完整曲线、组合覆盖CSV和每格求解证据另存，原场景不改。`--root`可指明确的源场景。`--time-limit`仅为诊断预算覆盖，会记录数值，不保存回场景；达到时限不能伪装成目标gap收敛。未指定时沿用场景600s/1%等真实设置。

优先常规验收基准、枯水小新能源高负荷、丰水大新能源低负荷；扩展至少增加风大光小/风小光大。低风事件独立列为压力，不混在常规“通过率”里。源码内的 `combination_matrix` 提供完整覆盖集合，不只抽取好看的结果。

## 2026-11-04 扩容前场景证据

`docs/evidence/typical_scenario_screening_20261104/` 保存机器可读摘要及覆盖矩阵：

- 扩容前光伏652MW、`multiscale_v2 + supply` 的54幅值组合全部完成四阶段必要条件预检；18基础组合、4个风光交叉角点、1个晚间低风压力组合，共23个正式约束零松弛LP均为optimal。保持原装机、线路、需求基准、备用和库存边界，未做可行性美化。此项不是整数或RT证书。
- 补充 `legacy_v1` 的枯水×新能源0.8×负荷1.1+晚间低风压力，完成96段RT及结算。DA/RT均零切负荷、零线路越限，电池/抽蓄硬锚未松弛；但DA上备用缺额0.107MW，RT实际首段最大上备用缺额275.801MW，不能标为全规则通过。
- 该补充压力使用90s诊断预算，SCUC达到时限，gap2.525%；结果明确与当前 `multiscale_v2/600s/1%` 常规验收分开。它说明“无切负荷、无线路越限”仍不等于所有运行要求满足，也说明输入预检/LP通过不能替代96段RT检查。
