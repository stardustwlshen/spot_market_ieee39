# 集中弃水根因与受限字典序修订方案

## 结论与需要批准的选择

建议先修复已经证实的“相同经济调度下任意多弃水”退化：原固定整数SCED求解后，保持全部整数、发电与充放电、备用、经济决策及已有松弛量不变，在原完整约束和原主目标等值条件内，仅对水量自由度做二级最小弃水。主目标不增加弃水费，价格与库存价值不得读取二级LP对偶。

这是新增的正式执行解选择规则，需要先记录并批准，再实施。它不改变同一窗口已选定的能量/备用安排，但改变实际水量和后续参考，因此不承诺后续出力、辅助价格、整日价格或收益不变。出库上限为空的工程缺口也不能靠去退化宣称解决。

不推荐本轮直接增加“很小”的弃水成本、改日末为等式或猜测坝闸上限，这些都含新的经济/物理假设。

## 1. 旧A日前：全部弃水并非水量必需

来源为冻结的`full_A_capacity_MKT_wet_id_on`，使用其完整精度水电证据，而非当前可变配置。

- 初始库容18000、下界8000、上界20000、日末下限18000，单位均万m³。日末是下限，不是必须回到18000的等式。
- 来水560m³/s，发电耗水率1.2m³/s每MW，生态总下泄下限80m³/s；未配置出库上限。
- 日前发电7234.377391MWh，全天来水4838.4万m³，发电耗水3125.251033万m³。
- 正式解弃水1713.148967万m³，全部集中第一个15分钟：弃水19034.988525m³/s、总出库19400.748525m³/s，库容一下降至16304.332633万m³，末库容恰好18000。
- 保持原日前出力与整数不变，把弃水全改为0，水量递推为18017.4816→19713.148967万m³，全天仍在物理库容范围内，末库容高于下限。最小发电下泄123.062479m³/s，也已经超过生态80。
- 独立水力LP确认该固定发电下的最小弃水为0。原主目标没有弃水成本，日前也没有为这部分末库存增加价值，因此新旧水量路径是同一经济解的不同水量选择。

所以此处不能解释为丰水期必然泄洪。没有出库上限允许任意大的瞬时出流；零弃水成本、没有末库存奖励且末态只有下限，使求解器可以把无价值但可保留的水任意提前丢弃。这两个问题叠加造成巨大峰值。

## 2. 实时不是简单把弃水清零：参考路径已受污染

A首个实时窗口采用`intraday@0`的水电参考，2小时末参考库容17012.139126万m³，硬偏差带16772.139126至17252.139126万m³。

保持该实时窗口原发电，零弃水会使窗口末库容达到18197.784791万m³。为了满足已经继承的偏差带上界，至少须弃945.645665万m³。实际弃1185.645665万m³，比该下限还多240万m³，最终停在参考中心。

因此：
1. 日前/日内退化水量可以经参考带传入实时，随后成为实时窗口的硬限制。
2. 在旧实时问题内部，部分弃水已被参考带强迫，不能直接删除而声称仍满足原约束。
3. 必须在日前、日内、实时每个正式SCED输出和参考快照形成前统一去退化，从源头更新水量参考；不能只修CSV、界面或最后一步实时记录。
4. 改变实际初态和参考后，下一窗口的可行域、调度及价格可能真正变化，应重新跑完整日对照。

## 3. 为什么不直接增加一个小弃水费

无论费用看起来多小，它都把水的边际机会成本加入原主目标，可能改变发电、库容价值及节点价。费用乘的是流量、体积还是等效发电量也有不同单位与含义，不能用“防退化”名义隐式引入经济优先级。

SCUC允许1%求解间隙也不是去退化可随意花费1%的成本预算。第二阶段必须面对本次固定整数SCED的最优值，而不是SCUC下界、报价总额或1%容差。

## 4. 推荐的受限两阶段规则

### 第一阶段：维持现有经济出清

照常完成SCUC及固定整数SCED，得到原主目标J*、完整原始变量值、主LP对偶、节点价与库存价值。保留原始SCUC间隙披露，不称整数全局精确最优。

### 第二阶段：仅选择水量路径

在独立克隆中：

- 固定第一阶段的所有整数、机组出力与报价段、电池/抽蓄充放电、备用、网络变量及经济/短缺/跟踪松弛量，不趁同价重排电能量或备用。
- 可变范围为常规水电库容、弃水及维持完整水量关系所必需的纯水力辅助变量；采用明确白名单。原生态下泄、出库上限、库存边界、梯级时滞、日末/参考带、水量备用等约束全部保留。
- 加原主目标等式J=J*。这是等值约束，不是允许额外成本的预算。
- 最小化Σ(0.36×调度小时×各站弃水m³/s)，单位万m³。该指标是各站过站弃水体积合计；梯级可能重复计入同一水流，不能报告成流域净耗水。
- 若原参考带、真实库容上限、生态要求或有价库存已经限制了水量，二级最小值可以仍大于0；不能为得到0而放松这些限制。

初始验收容差建议明确为：`|J_new−J*| ≤ max(0.00001元, 1e−10×max(|J*|,1元))`。A的目标约246.95万元，对应约0.000247元；绝不使用SCUC的1%间隙。该容差只容纳浮点误差，不授权增加原主成本。原约束、已固定变量和水量连续性分别用已有同单位物理验收阈值复核，并记录实际最大误差；不能用目标误差小替代物理检查。若当前求解器无法达到上述条件，记录失败与残差，先评估数值缩放，不静默放宽阈值。

验证通过后，仅把选定水量值复制回原模型，不复制二级模型的目标、对偶、额外等式或固定标记。原主LP结构和第一阶段对偶保留。操作应事务化：失败时不留下部分新水量配旧证据。

## 5. 定价与退化：可以保证什么，不能保证什么

在精确LP理论下，任何原问题的最优原始解与任何原问题的最优对偶解都满足互补性。因此二级解若仍在原主问题同一最优面，原主LP对偶仍是该原问题有效的经济对偶。必须以原约束可行、主目标等值及可取得的对偶可行/互补残差共同核实数值版本。

二级目标单位是弃水体积，其对偶不是元/MWh，不能替换节点价或水价值；也不能把二级目标等式的乘子解释为市场价格。更不能将二级选出的弃水固定在原经济LP再重算“主电价”，那会额外收缩原经济可行域。

当前辅助定价已有明确规则：固定正式弃水。因而辅助LP必须在去退化完成后，固定新正式弃水，保持其他已批准的辅助规则，再重新求解。其可行域可能与旧辅助问题不同，价格可能改变，应公开对照并做有限差分，不强行保留旧辅助价。

独立一时段反例已验证这种敏感性：同为水电40MW、原主成本1125元的两个原问题最优解，分别弃水0和71.111111m³/s。两者原主节点价均为10/100元每MWh。辅助LP固定各自弃水后，基点求解器恰好都选10/100，但负荷增加0.001MW的右侧有限差分分别为100和700元/MWh，后一问题扰动后节点价变为700。这是最优面/折点及辅助可行域差异，不能仅凭两个基点打印的价格相同就说没有影响。

验收需同时看正负负荷扰动：在可微区核对对偶与两侧差分；在折点允许有效次梯度范围并披露左右边际成本，不把某一方向差分不同一概误判为对偶符号错误，也不承诺选定对偶唯一。

## 6. 全流程与性能安排

- 日前：正式水量去退化后，再生成正式结果、DA水量参考与辅助定价输入；主库存价值仍来自原主LP对偶。
- 日内：每轮重新执行同一顺序，成功轮次的参考水量与证据来自新正式解。
- 实时：每窗口在当前真实初态和当前参考条件下去退化；仅新正式首时段进入真实状态与梯级历史，辅助量永不执行。
- 原始经济解与最终正式水量分别保存，输出原主成本前后差、各站弃水前后体积/峰值、主对偶来源、二级终止状态、约束残差及耗时。不把二级弃水目标写入“经济总成本”。
- 不重解SCUC，不重排整数。固定大部分变量后，新增问题主要是水量LP，预计比主问题小，但必须实测DA、ID、96个RT累计开销。
- 新增求解必须纳入现有实时总预算和辅助LP预留，不能偷偷扩大时限。若预算/数值证据不足，采用严格停止运行策略，标明hydro_water_tiebreak阶段；不回退旧弃水、不触发ID回退或RT软化。复制前完成全部核验，中途复制异常恢复原水量。

## 7. 仍需真实数据或另行选择的部分

两阶段最小总弃水在确需弃水时不保证瞬时峰值或闸门爬坡合理。真实出库上限、泄洪能力、最小不可减旁路流量及闸门响应应由设备/水文资料提供，不从额定发电流量直接猜测。

若只是研究情景，可以显式设置并标注假设上限，再做敏感性分析；这会改变物理可行域和价格，需要独立批准。

若不掌握设备上限，另一个可选三级规则是在保持主目标及最小弃水量的条件下最小化各站出库峰值，仍不把所得峰值当真实闸门能力。A的固定发电水力LP即使另行强制末库容恰好18000，必要弃水1713.148967万m³也可分配成峰值609.6m³/s，而非首段19400.748525m³/s。但“末态改等式”与“三级平滑”都不是本轮默认规则，本例仅用于区分总量必要性和峰值退化。

## 8. 实施前后的验证清单

1. 原A完整精度固定出力水力反例：DA弃水应可降至0，主成本不增、原物理约束不失效。
2. 必须弃水、生态强迫弃水、qout上限、梯级时滞及非零初态的反例不能被强行清零。
3. 原目标、整数、出力、备用、经济松弛量保持；主对偶来源不被二级解覆盖。不同价格折点进行双侧有限差分及区间解释。
4. DA→ID→RT参考、辅助弃水固定、真实首时段状态和历史全部一致；无新旧量混用。
5. 证明日内/实时受旧参考强迫的弃水不能仅在末尾清除；全日用新正式参考重跑。
6. 输出明确旧经济解、二级选择、未配置工程上限及计算失败状态；所有验收只针对实际完成范围。
7. 最终全套和代表完整日重新生成，不继承旧“通过”标记，不预先保证电价或出力不变。
