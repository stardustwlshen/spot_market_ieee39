# 水电上备用增量水量验收记录

本记录针对已批准的15分钟、时段末库存增量水量筛查，不把容量备用改成完整网络部署模型。约束及适用边界见《水电上备用增量水量修订方案》。

## 相同输入的新旧真实求解对照

两个代码版本分别读取完全相同的三组小系统输入。水耗率为1m³/s每MW，持续时间0.25h，因此每MW上备用需要0.09万m³。下面均为正式调度量与未经限价的固定整数SCED节点价。

| 输入情景 | 原容量规则 | 新水量规则 |
|---|---|---|
| 末库存等于最低库容，基准水电45MW | 上备用55MW，隐含额外水量缺口4.95万m³ | 上备用0MW，水量余量0 |
| 末库存高于下界0.9万m³，基准水电20MW | 上备用80MW，隐含额外水量缺口6.3万m³ | 上备用10MW，水量余量0 |
| 负荷90MW、要求上备用50MW、总可用初始水5.4万m³ | 水电50MW、当地火电0MW、两节点价10/10元每MWh，备用缺水3.6万m³ | 水电10MW、当地火电30MW、两节点价10/700元每MWh，备用水量恰好满足 |

最后一例说明修复可能改变调度与拥塞电价，不能只看“备用缺额为零”。新旧负荷、机组报价、线路参数及备用需求均相同。修复不应被解释为普遍提高电价；水量约束不紧时可能没有影响。

## 独立校验

- 水量专属与界面最终测试79项全部通过；此前包含储能备用、辅助定价、导出验收和界面的综合测试154项通过。两组存在重叠，不累计宣称233个独立测试。
- 真实求解覆盖日前、日内、实时，调度间隔0.25/0.5/1h，持续时间与耗水率的解析反比，零库存、零备用、功率上限及禁用参与。
- 覆盖径流零池容及有池容、弃水不回加、一级时滞到水与非零滚动实际初态。梯级案例固定基准弃水为零，隔离“在途未到”和“已到基准水”两种状态，不误把允许额外弃水转移库存当作模型错误。
- 正式及辅助定价LP对两个节点分别作0.001MW负荷右端有限差分，除以0.25h得到元/MWh，与10/700元/MWh对偶价一致，误差要求不超过0.0001元/MWh。辅助模型保留水量约束，正式执行量仍来自正式调度。
- 真实短日run_full写盘验证日前、日内、实时及辅助模型证据；检查summary版本标记、规则和ID覆盖。缺字段、非有限数、篡改水量、持续时间或冻结物理参数，以及新记录退回旧格式，均拒绝。
- 历史原容量证据可按历史规则复核，但新水量状态为“未核验”，不会冒称通过新规则。
