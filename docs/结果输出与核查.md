# 日前与实时结果输出和核查

## 如何找到结果

结果页保留原有图表和主体页面，并增加“完整结果文件：筛选、核对与下载”。可按机组、电站、节点、线路、结算主体、时段筛选已保存表格，下载筛选表或原文件；不改写结果。没有新索引的旧结果继续按原页面读取，不补造不存在的数据。

全流程另存 `solver_windows.csv`，逐轮记录真实终止状态、实际gap、最优界及配置目标gap是否达到。达到时间上限后的可行解可能未达目标；不能把“目标1%”说成“实际≤1%”。

日前和全流程均保存 `profiles.csv`（本次实际使用的内存曲线）、`forecast_accuracy.csv` 与 `profile_generation.json`。常规入口在求解前捕获生成元数据；直接构造算例而未捕获来源时明确标记未知，不通过导出时的当前覆盖文件猜测历史来源。

每次新输出包含 `output_manifest.json` 和 `结果文件索引.md`。索引列出本次生成的文件、数据行数、字段与 SHA-256。哈希不一致会提示存档可能被改动。未生成图时不把目录中残留的旧图片列成本次结果。索引是文件证据，不是物理安全认证。

## 日前和实时均覆盖

- 机组：净出力、在线状态/台数、启动数、可用出力、备用、弃风弃光、节点价格、净电量。区外来电供给按该次冻结的固定计划进入日前及实时机组表；旧固定负荷转换场景只进入负荷，不重复加入供给。
- 节点：需求负荷、固定负荷分量、缺额、扣缺额后供给负荷、净注入，正式调度原始价、选用原始价、能量/阻塞分量、限价后结算价。
- 线路：正式潮流、该次有效限额、负载率、线路松弛；正式潮流绑定与辅助定价对偶活跃分列，二者不等同于实际越限。
- 储能：充放电、工况、时段初末电量、SOC。抽蓄：发电/抽水、台数、工况、时段初末上库、下库及可用库存等价电量。
- 普通水电：出力、在线台数、时段初末库容、来水（含上游）、发电流量、弃水、总下泄；未声明下泄上限保留未知，不能当作零或无限约束已通过。
- 系统与备用：需求、缺额、过剩、弃风弃光，上下备用需求、供给、短缺及资源功率/库存余量。备用影子价格是约束诊断，无单独备用商品结算。
- 结算与利润：全流程按明细/主体/类型保存日前现金、实时偏差现金、对账与线路阻塞租金；实际执行范围另保存独立冻结成本与模拟运营利润。成本缺失为未知，不能把报价当成本或未知当零。

命令行全流程现在也完整保存日前线路、系统、节点价矩阵，不再依赖网页运行的 `da/` 子目录。仅日前运行也保存备用、三个求解阶段和辅助定价诊断。

## 必须区分的口径

1. **计划和执行**：日前保存完整计划。实时每轮只取相对索引0，表格中每个机组/节点/线路与时段只计一次；重复、乱序窗口或缺失/错配实际初态会拒绝导出。`*_windows`、水电目标和阶段诊断包含重叠前瞻，不允许合计为实际电量、启动次数或利润。
2. **信息可得性**：实时首段直接使用离线合成“实际”曲线，其余前瞻用预测视图。这是已知当段实际值的理想化假设，不是线上信息已可获得的证据。配置中的 `boundary_lead_min=30` 当前未落实为T−30分钟的真实发布或冻结约束，不能把该字段当作已实现的提前30分钟预测机制。
3. **数量和价格**：正式固定整数SCED决定执行数量。辅助LP数量不执行。正式原始LMP与选用辅助原始LMP分别保存；限价后结算价可能不再等于能量分量加阻塞分量。
4. **收入和利润**：日前 `revenue_yuan` 是计划中标收入；实时 `rt_price_valuation_yuan` 只是净实时电量乘实时价，**不是**两级结算。真实模拟现金结算见 `settlement_*`，运营利润见 `operating_profit_*`。仅日前不产生虚假的实时结算或运营利润。
5. **时刻与库存**：`period` 从0开始，`time` 标记时段起点。`E_mwh`、SOC、`V_up`、`V_1e4m3` 是该段结束状态；`E_start`、`V_start` 是该段开始状态。
6. **时段覆盖**：短时调试始终标 `debug_prefix` / `illustrative_prefix`；不能与完整日总额直接比较。保存CSV通常四位小数，矩阵两位小数，独立复算允许对应舍入误差。

## 图形输出

启用图形时，日前和实时各保存节点价热力图/曲线、全部类型出力（含抽蓄发电与抽水）、储能功率/SOC、线路负载率、上备用需求/供给/缺额、水电/抽蓄库存图。全流程另有日前实时价格对比、滚动计划和结算图。无该类资源时不产生空资源图；表格仍保留可读表头。

图形是辅助阅读。检查物理松弛、备用缺额、硬锚和模型假设时，应同时阅读 `summary.json`、冻结输入与完整诊断证据，不因文件齐全、测试通过或资金对账而宣称全部物理安全。
