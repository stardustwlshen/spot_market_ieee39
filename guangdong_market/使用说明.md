# 广东省内电力市场模拟：使用说明

## 本次交付内容
- `program`：程序、运行必需的静态输入；其中 `research_results`、`experimental_not_live` 和 `guangdong_short_*` 为历史研究参考，不是当前运行结果。
- `portable_results`：全天结果的便携图表数据及摘要清单。只能查看，不含原始求解和完整续算状态，不能当作恢复检查点。
- `DELIVERY_INVENTORY.json`：本包文件清单和摘要。

## 安装与启动
建议 Python 3.12。解压后进入 `guangdong_market/program`。

1. 创建环境：`python -m venv .venv`。
2. 激活环境：Windows PowerShell 执行 `.venv\Scripts\Activate.ps1`；macOS/Linux 执行 `source .venv/bin/activate`。如 PowerShell 阻止激活，可直接用 `.venv\Scripts\python.exe` 执行下面命令，不必调整系统安全策略。
3. 安装依赖：`python -m pip install -r requirements.txt`。
4. 启动：`python -m streamlit run app/主页.py --server.address 127.0.0.1`。
5. 打开命令行显示的本机网页地址。

这是普通 Python 的 tar.xz 包，可用 Python 标准库解压；支持安全过滤参数的 Python 可执行 `python -c "import tarfile; tarfile.open('程序包.tar.xz').extractall('.', filter='data')"`。

当前只完成指定 Linux 环境的局部界面与接线测试，未对本最终包进行 Windows/macOS 冷安装或全天求解验收；不能据此宣称跨平台全部验证通过。依赖安装失败时保留实际报错，不要强行混用已有环境。

## 查看随包全天结果
默认进入“市场工作台”。展开“运行位置与已有结果”，把“结果目录”设为解压后的 `guangdong_market/portable_results` **绝对路径**，再到“结果”页点击“刷新结果”。无需求解。

结果包括出力、储能SOC、风光可用/发电/弃电、独立电价和小时电能量核算。页面区分图表覆盖的完整小时与读取时计算/校验/外存进度；图表范围不等于计算总进度。空白或缺项不是零。

## 新建模拟流程
1. “场景与报价”：载入模板，修改必要场景及机组报价，另存并选择本次场景。
2. 同页“独立准备/求解日前”：核对实际计划，准备并启动日前。读取状态，待接受后点击“选此已接受DA”。
3. “计算与进度”：使用上一步明确绑定的日前来源，准备新的实时运行、核对计划并启动。结果目录不会自动冒充日前来源；旧固定日前组合启动入口已禁用，仅可查看历史。
4. “结果”：填写此次实际实时运行/接续代次目录并刷新。新格式读取绑定的已执行记录、独立定价和完整小时账目；不足完整小时的结果暂不进入这些图表。

新发起的混合整数求解的 MIP gap 为 **1%**，每次原生求解时限 **3600秒**；LP 不适用 MIP gap。3600秒不是全天任务总时限，达到时限也不代表结果通过校验。实际参数以该次计划和回执为准。复用的历史结果保留原参数，未冒称已按1%重新求解。

## 结果边界
- 本次算例保留原场景的400 MW正备用和400 MW事故备用；未为风光或未获资格资源凭空加入备用能力。
- 5分钟状态分辨率、每15分钟接续3格、4小时计划域及五台合格机组各10 MW调频规划均须按本研究分支的具体设定理解，不能冒充广东通用正式参数。
- 这是省内研究仿真，不是广东正式运营平台，也不是官方结算账单。规则研究解释、输入假设和未认证事项仍须保留。
- 交流安全未通过或未验证的结果不能称作安全调度方案。文件摘要一致不等于数学、安全或规则验收。
- 模拟利润仅按有明确来源的电能量/调频/备用收入减发电和实际启停成本；不含运维等费用。成本或服务净额缺失时标为部分结果，不拿报价冒充成本、不把AGC容量当里程收入、不虚填零。
- 本次原生全天结果来自此前冻结的计算源码，保持同一逻辑运行，通过多个接续代次完成，非一口气单进程。交付包新增UI、结果适配和局部性能改动另做局部测试，**没有声称这个新包已冷启动完成新的全天求解**。
- 接续入口分别列计算、校验、本机检查点、外存和源恢复验证。普通新live运行尚未自动启用同一外存门禁，不应把它当作已有独立备份保障。
