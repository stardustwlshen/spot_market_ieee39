# 广东省内单日市场研究模拟

当前程序在 `program`。原仓库根部程序、`guangdong_market_bundle` 和既有 `portable_results` 保留为历史版本，不能与新模型混用。旧 `DELIVERY_INVENTORY.json` 对应历史交付；当前文件身份见 `program/APPLICATION_MANIFEST.json`。

## 启动
推荐 Python 3.12，在 `guangdong_market/program` 创建并激活虚拟环境：
```
python -m pip install -r requirements-runtime.txt
python scripts/launch.py --check
python scripts/launch.py
```
Windows 可使用 `启动.cmd`，macOS 可使用 `启动.command`。详细操作及可编辑范围见 [QUICKSTART](program/QUICKSTART.md)。

## 本次功能
日前重新求解SCUC、固定整数SCED和独立节点定价；实时15分钟滚动、最多2小时窗口，仅执行首时段。采用HiGHS，gap为1%，单次求解上限3600秒；只考虑有功和直流网络。

界面支持风光负荷分别选择合成误差，已有资源参数修改，以及按原模板新增煤机、燃机、电池和抽蓄。新增资源不继承对模板另行保存的修改；新增后独立参数编辑及风光逐机新增尚未支持。

结果显示96时段进度、累计和分小时的收入、成本及模拟收益，另外列出实际线路越限和日末SOC目标偏差。

## 真实验证范围
冻结数学版本完成了含新增ES6、ES1与抽蓄参数修改、风光负荷非零合成误差的96时段联合计算和24小时结算。四类新增资源另外完成同场首小时验证，不能说本次联合全天同时新增四类。

该场景15个实际执行时段线路越限，最大约15.9152MW。ES1申报日末120MWh，实际24MWh，低于软目标下界91.2MWh；ES2超软上界约3.674MWh。按照约定保留软约束和罚值，界面明确告警，求解完成不等于安全运行或所有目标达成。

发布版随后仅新增异常展示及模板说明；这一部分使用真实全天结果回放验证，没有重新执行全天求解。Windows/macOS未完成本版本实机全流程验证。

收益包括研究备用补偿和调频估算，扣发电与实际启停成本，未计月度辅助服务分摊和考核，**不是正式净利润**。参数假设与完美当前时段信息假设见QUICKSTART。

普通界面只保存在本机，不自动独立备份。`verification_20261115`是审查摘要，不是完整恢复检查点；历史结果不冒充本轮结果。
