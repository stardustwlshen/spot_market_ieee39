# R54 广东有偿旋转备用核算

独立纯算术模块，无求解、拍卖或支付。只实现同一 R6 的完整火电/核电核算池，第 33、35 条的服务量及供应者收入比例分配；不是费用缴纳分摊。当前旧模型的 400 MW 正备用与 400 MW 事故备用均不能作为本模块补偿需求，更不能相加为 800。模型 reserve dual 不参与定价。

## 算法
每条输入仅覆盖一个共同时间区间，MW × 小时得到备用服务 MWh，非实际发电电量。
- 气/油：max(U−实际出力,0)×h。
- 煤/生物质：max(U−max(实际出力,.5×额定容量),0)×h。
- 核电：用协议正常调节下限代替煤电的 .5×额定容量。
- 非自身原因造成申报最高可调出力下降时取额定容量；自身原因当日未达申报最高可调出力，当日不补偿。未知原因或日状态为 missing，不默认为正常。
- 全池同价总补偿=R6×min(全池服务量,系统旋备下限×h)，再按各供应者服务量占比分配。零总量分配零。上限与完整池须外部有来源证明，不能由五机模型冒充全省。
- 第 34 条水电涉及峰谷差价，当前异价混池及其他类别不支持，显式 missing，不猜比例。
- 第 36/66 条 K4=.5 涉及月度成本缴费，不是供应者收入权重。完整月度上网/落地电量、用户电量分母及第 67 条执行衔接尚缺，monthly_allocation=None。此处不拼省级总账。

资格、指令、实际出力、U、日原因判定等共用每机 evidence 字段定位完整源包；Scope 指定 actual_inputs 或 synthetic_fixture。布尔值严格校验。实际数据输入路径仅计算可追溯分项，不等于真实性认证，formal_bill 始终 None、payable=false。未知仍能执行另一个明确合成 fixture，不阻断研究程序其他功能。金额未做分币取整，未编造尾差规则。

11 项纯测试通过，0 native。合成例：15 分钟，气 U100/P60 得服务量10；煤额定200/U180/P80 得20。系统下限80MW，服务上限20MWh，R6=30，池总额600元，气200/煤400。若下限160MW，池总额900元。不是实际账单。
