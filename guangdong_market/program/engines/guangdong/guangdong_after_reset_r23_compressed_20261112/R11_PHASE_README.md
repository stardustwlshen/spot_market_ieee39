# R11：有限候选轨迹的日前研究模型

本目录在已保存的 R10Fv2 程序上独立开发。旧阶段的说明与结果只代表旧阶段；本阶段最终验收状态以单独的 R11 验收记录为准。没有改动旧阶段档案，没有推送 Git，没有使用 COPT。

## 新增范围

- 真正的混合整数 SCUC 在预先列明的完整燃机轨迹之间选择，然后从该次活求解结果固定选择、重新求解 SCED。候选域有限，不是所有启停时刻的完整搜索。
- 五分钟物理模型保留机组、分段报价、网络、启停均值与端点、通知时间、最短开停时间及明确费用。日前交付报告为 96 个十五分钟均值；这不是正式 98 点模型。
- 采用明确标注的日前可用合成预测。没有把未来实际数据或旧 23:30 预测改名为日前已知数据。
- 保留正备用 400MW 和额外事故能力研究要求 400MW。电池与抽蓄仍固定 idle/off，煤机仍保持稳定在线。本阶段不支持相应自由度，不由名牌容量自动获得备用能力。
- 独立的求解身份与错误记录区分已解、不可行、输入拒绝。静态报告不获得计划签发、执行、观察或滚动权限。

## 两个不能掩盖的对照结果

以下是求解前可独立复算的必要条件，不冒充求解器结论：

1. 原 D00 初态保持不变：首格净负荷约 2595.787MW，五分钟可达上限 1718MW，缺口约 877.787MW。
2. 新建的 21:00 提前准备假设沿用同样低煤机出力、燃机停机数值，但来源身份与原 D00 分开。其首格净负荷约 2780.507MW，同样上限导致约 1062.507MW 缺口。因此仅移动时间不能解决问题。
3. 两个初态的合格煤机十分钟事故能力最多 336MW，小于保留的 400MW。不能把尚未完成启动的燃机名牌容量计入。
4. 在当前受限全天域内，净负荷最低约 820.542MW，小于煤机稳定最小出力 1005MW；最高约 3045.951MW，又超过总热机容量 3223MW 减去正备用 400MW 后的 2823MW。因此不同初态本身也不能证明全天可行。

新的物理准备实验必须作为另一份明确假设保存，不能覆盖这两个对照。全天链仍需忠实实现更多资源调节自由度，并验证其状态、库存、爬坡、资格及尾部约束。

依赖版本仍见 requirements.txt；运行纯测试先设置独立、足够空间的工作目录 TMPDIR。旧的 inputs/evidence 是依赖档案中的历史内容，可按 experiments/restore_rebuild_dependencies.py 恢复，不能称作本次新结果。

主要新增代码：repo/src/smm/gd_da_candidate.py、repo/src/smm/gd_da_ieee39.py。输入准备入口为 repo/experiments/prepare_ieee39_da_candidate.py。独立测试位于 reconstruction/r11_da_audit。实际原生运行必须单独开启明确测试开关，并保留 HiGHS 的真实版本、状态、设置和输入/矩阵身份；默认 gap 为 0.001。
