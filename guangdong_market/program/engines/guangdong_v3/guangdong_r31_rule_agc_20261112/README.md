## 实现与规则边界
已连续读印刷13–26页的§36–73、27–28页§74–76、38–39页生效条文、54–55页参数表。
- §47–49：全统一控制区 kmax 归一化，非储能报价/P；热机中标容量 min(max(申报比例×扣停运装机,Qu),max(区域需求20%/同厂中标台数,Qr))。广东附录7 Qu=Qr=0。每次加入机组均重新计算同厂容量，不能沿用原单台上限。
- §50/57：按排序价升序、P降序、k1降序整机选择，不是最小容量采购费的分数LP。R27永久保留研究负控，不能因其LP Optimal声称正式AGC出清。
- §57：区域需求下限内排序机组不定价；无边际使用前一小时原始边际价，最终封顶15。无历史保留None，短缺不产可用价。
- §60：每小时滚动3–6小时，仅首小时执行；后续为能量/备用参考。代码生成数据不授权实际调度。
- §74：实际里程×统一价×性能系数；指定性能测试不补偿。gross_mileage不是应付账单，不含扣罚和分摊。§75–76含跨省收入/费用分摊，本用户排除跨区市场，因此不假造省内完整结算或将全部总池强行本省分摊。

## 明确研究约定
只接广东热机；资格必须逐项显式输入，合成例用SYNTHETIC ONLY，不能生成正式资格。不为储能/风光自动授权。full_control_area_kmax必须显式提供，不能从本地资源求max。local_floor_mw、demand_mw为广东局部研究边界，不模拟省外交易，也不称为完整区域出清。70%只是附录初值，代码不自动按年递减或暗设当前比例。
跨越保留下限的最后整台排除定价是明确研究约定；规则未在已读段落细化跨越台处理。完全相同价/P/k1用resource_id稳定排序同样是研究约定，不冒充官方后续排序。报价目前只支持初始3–15；动态下限、第三方报价默认/储能Fm、水电振动约束未实现。模式formal一律拒绝，不能通过caller true解除。
安全检查仅接显式外部排除名单，非电网安全认证。SCED扣减接口检查固定计划上下余量且拒绝二次扣减；仍保留400MW正备用、400MW事故备用，绝不将其当作已满足。真实网络/响应/联合可行性需下游SCED校核。

## 最小可运行例
`python -B -m pytest -q -p no:cacheprovider test_r31.py`：35通过，0 native。
六个显式合成热机，各1000MW、比例5%、不同电厂、k=1、外部kmax=2、报价3至8；需求100MW、下限70MW。首5台每台20MW中标，总100；研究保留前4台，边际排序价14。同厂两台时各10MW并追加第6台满足需求。此例只证明算法执行与条文算式，不证真实广东需求、资格或市场价。

最终必要差分：qualified/stable_online 仅接受 is True；指定测试标志仅真实 bool；毛补偿价格≤15且乘积必须有限，负性能拒绝；首小时缺价或短缺拒绝构造 binding view。
