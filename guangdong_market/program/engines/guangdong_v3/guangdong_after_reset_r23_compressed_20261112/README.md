# 广东省内研究程序：R10F v2 原始IEEE39热机独立定价链

本版在原始IEEE39窗口62完成“新的真实24×5分钟SCED → 价格专用研究回执 → 独立8×15分钟价格LP”的最小链。它不是全天出清、实际执行、因果滚动、正式广东价格或结算。旧阶段保留；R10E说明见`docs/历史R10E_README.md`。F候选1因六项旧接口回归失败而未验收，其完整源码及失败证据已独立保存并取回复现；v2只修防护范围和检查顺序，未修改原输入、数值参数或旧测试。

## 已有验证与边界

- v2开发最终纯测试31项、原生测试10项，原生门2次真实HiGHS调用；可移植CLI另以新登记重新做ED和价格。原封不动的旧D纯29项、原生72项（91次调用），旧E原生16项（22次调用）通过。
- v2独立隔离审查112项测试及9个子测通过，无跳过；3次生产worker调用含预期不可行价格诊断，143次直接诊断LP含128次有限差分。纯门68项通过、44项原生门按设计跳过、0次求解。新旧入口的配对防护破坏测试也通过。
- 独立重建1276列、1371行，复核全部9984个ED原始量；保留39母线、46支路、5热机、5电池、2抽蓄机组及共库、风光、TIE和全部6个热机事件。
- 最终组装包的完整历史回归、备份和实际取回复验是另外的门。以`reconstruction/R10F_VALIDATION.json`及单独取回验收记录为准；不能把上传成功或上述开发/隔离结果当作已取回验证。

## 研究结果，不是收费或可执行调度

窗口为2026-11-11北京时间15:30至17:30。原ED成本1541535.6351018283元；ED季度均值点在价格模型中的成本1541428.7451881757元；实际独立价格最优目标1541223.6264747584元。时间聚合的106.8899136528元差异来自凸分段成本，不能据此声称实际节省费用。

参考母线39在8个季度的研究价（显示至两位小数）为321.30、321.30、323.73、330.75、338.58、359.10、405.00、413.10元/MWh。全部312个节点季度值及完整原始量/对偶量在每次实际运行的结果中。

本实验预先选择δ=1.0。这里δ是`(1±δ)×参考功率`的无量纲比率，即0至2倍参考功率后再与物理界取交集，**不是1%**。六类罚因子均1000元/MWh，线路及事故松弛上限0；这些是明确研究参数，不是已确认官方值。正备用400MW和事故400MW原研究压力值不变。罚因子不是价格上限。

GT两季启机出力18.75/56.25MW固定、不参与定价，绝对容量上下基量仍保留。Pmin基费和原增量段不丢失。季度均值ramp不是原5分钟可行域的精确投影，价格调度不可执行。原报价日期、资格、合成逻辑钟与实际运行钟等限制详见文档101、102、103。

## 恢复与运行

完整源码之外，需原阶段4两份历史依赖档案（892项）及单独的R10E IEEE39启停就绪档案（30项）。后者含固定的原始窗口62输入codec；不重新生成，不复活归档回执。

- `docs/103_R10F阶段验收与恢复说明.md`：精确档案、SHA、恢复及验证命令。
- `docs/101_R10F_IEEE39原始热机接独立价格链.md`：模型、先冻结后求解、费用/相位/数值证书及研究边界。
- `docs/102_R10F原始IEEE39热机定价独立审查.md`：独立矩阵、KKT、有限差分和反例。
- `docs/104_R10F之后日前因果链只读设计.md`：尚未实施的下一阶段设计，不是新DA/全天成功证据。
- `docs/105_R10F候选回归修复记录.md`：失败候选、v2防护修复、完整中间备份和未完成范围。

使用已安装HiGHS1.15.1的Python环境，从源码根目录运行：

```sh
export PYTHONDONTWRITEBYTECODE=1
export TMPDIR=/absolute/existing/external/tmp
python reconstruction/r10f_thermal_price_examples/run_native.py \
  --input-codec /absolute/restored_readiness/window62_input.codec.json \
  --output /absolute/external/new_result_directory
```

测试必须显式设置`GD_IEEE39_READINESS_DIR`，缺少或篡改原件会失败，不回退旧路径。结果及临时目录必须在源码树外。只恢复输入，新的研究回执和价格必须重新真实求解。没有安装/激活COPT、修改许可证、重试Windows受阻操作或推送Git。
