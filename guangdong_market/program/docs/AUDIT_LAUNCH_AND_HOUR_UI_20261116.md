# 启动异常与小时结果展示

基于 main 05b8d。只修改运行控制与展示，不改变市场模型或求解参数。

- 启动子进程前失败：明确记录未启动的失败结果并释放父进程锁。
- 子进程已经启动、但 PID 记录写入失败：保留输出目录及任务引用，不能伪造未启动或重复计算。
- Windows 启动握手未确认：保留未知状态、日志和任务句柄，不将其当成零次调用或自动重试。
- 小时结果数不再称为已完成结算数；按新口径，保留真实机组账户的异常小时仍计算模拟收入，虚拟电量不进入机组账户；旧缺失明细的异常小时不伪造金额。
- 异常小时按中文字段展示，可选择机组；正常小时的机组筛选也作用于电量和价格明细。

验证范围：模拟系统启动失败与回执失败、锁释放、任务句柄传播；真实页面 AppTest 的异常/正常小时切换、机组筛选以及来源篡改拒绝。Windows 分支通过测试替身验证，不等于 Windows 实机验证；未重新进行全天市场原生求解。

补充：收益表兼容显式输入算术与自动桥接两种字段命名，真实缺失值仍保留空值；回归验证收入1110、成本220、模拟收益890及备用0显示一致。
