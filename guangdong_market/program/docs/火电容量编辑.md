# 现有火电最大出力编辑

本节说明仅修改现有火电最大出力（MW）的行为；最小出力同步编辑另见《最小出力编辑》。不是全套设备重新设计。

- 仅修改最大出力时，最小出力不变，启停轨迹、启停出力限制不变。
- 报价段数量和各段在可调区间内的宽度占比不变；新宽度 = 原宽度 ×（新最大出力 − 最小出力）/（原最大出力 − 最小出力）。报价单价、最小出力基段报价不自动改变。改变段宽会改变各价格段所覆盖的出力范围，这是界面明确标注的研究假设。
- 调度模型的绝对爬坡能力、启停费用、空载费用、最小开停机时间、原始启停曲线费用不因容量修改而自动变化。原有报价倍率、爬坡倍率仍是另行明确输入。
- 不自动提高初始出力，也不自动截断初始出力；缩容后初始出力越界，拒绝保存，须用户一并修改。
- 分时容量限制暂不支持统一容量重写；固定出力、启停出力/曲线或调频预留与新容量冲突时拒绝。原始报价段必须完整覆盖原可调区间，否则拒绝自动缩放。
- 一次备用的容量比例不变，其按容量计算的限额由模型自然重算；全网备用需求、调频预留不自动缩减，也不承诺任意缩容后系统仍可行。
- 每次新计算使用新场景快照，日前98时段和后续实时从同一修改后输入衔接；不改正在执行的历史任务。
- 最小出力编辑另按《最小出力编辑》限定的线性研究模板处理，非线性或未知模板仍拒绝。不能把本改动解释为所有技术参数均已支持。

验证：容量扩大/缩小、依赖冲突、批量原子性、实际Streamlit保存与切换、正式快照及新日前模型系数。实际长求解不是容量编辑回归的必需步骤；模型可行性仍由每个用户场景的求解结果判断。

## 利润默认成本与报价分开
利润链 `gd_auto_economics.prepare` 从新场景最大出力取容量，由 `gd_default_costs.profile` 选取研究成本。煤机小于300MW为330、300至不足600MW为300、600MW及以上为280元/MWh；燃机小于100MW为600、100至不足300MW为550、300MW及以上为500元/MWh。这些均为假设值，不是报价或真实成本。容量跨档时默认发电成本会改变，界面显示修改前后费率；同档不变。

手填成本通过 `gd_economics_inputs` 按运行和完整账目摘要单独保存；容量编辑不修改旧记录，不把旧运行的手填成本自动套到新运行。新运行先使用新容量默认值，用户可在结果页重新修改成本。本次没有改变成本优先级、结算公式或任何已保存经济记录。
