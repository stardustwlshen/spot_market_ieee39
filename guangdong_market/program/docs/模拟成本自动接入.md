# 模拟成本自动接入

范围：仅补研究模拟成本，不修改市场出清、定价和正式结算规则。

之前结果页将发电成本、已执行启停成本全部置空，要求用户手填。这不符合默认可运行要求。按资源技术类型提供可修改假设值：煤电300元/MWh、燃气550元/MWh；风光和独立储能燃料成本为0。储能购电已经进入带符号电能量结算，不重复扣款；不计运维、折旧、容量电费。

有明确容量参数时，煤电≥600MW为280、<300MW为330元/MWh；燃气≥300MW为500、<100MW为600元/MWh。容量缺失时使用技术类型基础值，不根据ID或出力猜容量。

煤电/燃气单次启动成本分别假设100000/30000元；停机成本假设为0。仅同运行、同小时、来源摘要匹配且完整的已执行start/stop事件可用于计数。未来计划不计；缺记录仍置空。风光/独立储能不配置燃料启停成本。以上均为研究假设，不是报价、真实财务数据或广东官方参数。

已有手工成本保留。备用、调频收入仍要求已核算组件，不得把容量直接当收入，也不把缺失默认为0。辅助服务未齐时显示电能量收益减发电/启停成本，完整现货利润仍明确未齐。

## 调频估算接线

从已执行小时绑定的AGC_BINDING文件追踪当小时研究中标回执，核对摘要、分支和时段。使用回执已产生的中标容量、统一价格和研究性能系数；仅里程采用可修改假设“每小时每MW中标容量产生10MW里程”。公式：估算里程=容量×小时×倍率；估算毛收入=里程×统一价×性能。

该倍率不是实测，不代表调频指令的实现过程；不把SCED基点变化当里程。未提供考核/分摊时仅展示估算毛收入，以及电能量利润加估算调频毛收入，不称正式净利润。原实际里程缺失和正式结算缺项标记保留。备用行政补偿与竞价市场不擅自切换；有同小时已计算备用组件则由既有绑定接口读入，否则未知。
