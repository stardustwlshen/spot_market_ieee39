# 抽蓄跨时段约束与恢复状态

依据：《广东电力市场现货电能量交易实施细则（2026年修订）》印刷第14–15页的运行参数、第55–58页(20)、(23)–(25)。原文要求连续发电、抽水、停机的最小时长，并规定优化单元单向爬坡。未把这些参数设成对称火电式爬坡。

新增参数（数值均为研究假设，不是监管规定）：
- `min_gen_time_h`：最小连续发电小时数，默认0.5；
- `min_pump_time_h`：最小连续抽水小时数，默认0.5；
- `min_off_time_h`：最小连续停机小时数，默认0.25；
- `gen_up_step_mw`：每15分钟优化单元发电最大增加量，默认min(2,机组数)×单机最大发电容量。发电下降不另加限制；
- `pump_release_step_mw`：每15分钟允许减少的抽水消耗功率，固定速同容量机组默认一台额定抽水功率，对应相邻离散段。增加抽水功率不另加此方向的限制。

当前同容量电站按一个优化单元解释；异容量机组、多优化单元需显式扩展，不能套用该默认。原有每机互斥、切换间隔、启动次数、库容边界继续生效。

滚动边界逐机保存`mode_age_steps`、`gen_mw`、`pump_mw`，并继承最小持续时间尚欠的步数。仅用首个实际执行15分钟时段更新，不使用窗口末计划。新模拟日的停机年龄默认满足最小停机时间，明确是初态假设。旧检查点没有年龄或功率时拒绝继续，不能用0或猜测值迁移冒充原始状态。

针对性验证覆盖发电/抽水抖动拒绝、初始停机/开机时间欠额、首步与窗口尾年龄区别、跨进程续算剩余时间、首步发电爬坡、抽水减载方向、满足最小时长后的正常停机。无需改动市场结算口径。
