# 定价质量检查读取去重

基于 main b798ade。仅修改 gd_price_quality，不改变优化模型、价格或求解流程。

同一次调用内复用已读文件的内容和SHA256，避免读取后又为计算哈希重读；别名路径映射只建立一次。每次刷新仍重新读取所有要求的文件并重新计算SHA256，没有跨刷新缓存，不依赖修改时间跳过验证。

验证：完整合成绑定4项单元测试（含四类raw文件篡改子测试）、下一次刷新读取计数、别名冲突拒绝、缺原始结果为unknown。另以真实历史Q03重复核验做7轮微基准，输出与原实现完全一致；96次检查读取约164.8MB降至66.6MB，中位耗时约0.735秒降至0.546秒。此结果仅对应价格质量子链，不代表整个页面、全天计算或优化求解提速。
