# 日前98点的建模口径

依据广东省级2026现货电能量实施细则5.8.2，D日96个15分钟时段，D+1高峰、低谷2个代表点。用户指定D+1代表输入复用当日对应高低峰输入。本实现按总负荷最小/最大值选取，重复极值取首个，按对应钟表时刻排序；这是输入生成假设，不是规则指定的选点算法。

- 0至95是D日实际时段；96、97是代表点，不参加D日电量、结算和实时边界继承。
- 代表点目标函数权重0.25小时，遵循本实现的统一元/MWh报价单位。
- 规则印刷50–51页爬坡、最小开停、次数未排除代表点；53页SOC递推、54页循环总和到T，55页Δt为15分钟；57–58页抽蓄库容和启停约束同样按索引给出。实现保留这些98索引约束，不能独立删除成静态快照。
- 这两次索引递推是压缩代表点近似，不是实际D+1相邻半小时的运行轨迹，不证明两个实际峰谷时刻之间的全过程可达性。
- 54页日末储能约束明确定在T−2，即本实现索引95。抽蓄申报日末也在95，不移到97；这是沿用本项目申报硬目标的研究选择，抽蓄原文要求调度机构设置日末库容上下限，不等同于储能T−2等式。
- 小时内方向约束按55页n=1…24作用于D日；代表点各自独立方向，不错误合并为次日同一实际小时。
- 原始求解仍包含98点；physical_cells仅导出D日96点，代表点另列。原96点试验保留，不能冒称新98模型输出。

验证包含输入极值复用、元/MWh目标时长、日末索引与代表点不结算、真实SCUC和固定整数SCED，以及与旧96点结果对比。尚未完成的规则范围不能凭98点数量声称全部合规。
