完整保留原矩阵的抽蓄最短时间、爬坡、上下库水量和储能 SOC 约束。抽蓄一次调频仍受在线发电容量余量、上库可用水量、下库剩余容量与在线容量 10% 共同限制。本算例最优解可以由其他资源满足一次调频，抽蓄一次调频量为零，不代表其资格被删除。电池不加入原文一次调频资源公式；其事故备用能力仍在物理调度模型中计算。
