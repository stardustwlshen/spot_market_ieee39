# 修正循环尾约束的研究开发入口

主页保留原场景/报价编辑及日前来源。在新的统一入口中，可以默认使用上方日前目录，或解除勾选后选择其他已接受日前；新运行名自动生成实时、日声明、定价和小时结果目录。

当前源码加入日末 SOC 与剩余循环吞吐的必要可达约束。它不是全网未来可达性的充分证明，正式安全、正式结算和付款仍不放行。保守日前保护会保留本算例热机在线，不能冒称通用实时热机启停已经覆盖。近/远各24个五分钟联合优化、原48小时计划假设发布及次日储能目标均明确标为研究假设。

首小时证据来自旧 v2 的12次实际求解。经 v3 新增约束、原解和补零对偶的兼容检查后，可以明确沿用，但不是 v3 新原生求解。旧上下文不能直接充当 v3 运行，新入口会拒绝；报告以只读方式单独展示原源/新矩阵身份。

默认不求解。准备、显式确认求解、严格接受、研究交接、独立价格和小时核算分开。缺价格/执行回执不补零，未知尝试不自动重试；首小时需要 seed、W0、W1、W2 四季度价格及 W3 交接后的12格执行。价格与小时重复读取会核对原始证据，而不是直接信显示金额。

旧短域没有新增循环尾约束，旧48小时/三态/PRICE2.2也不是当前统一链，主页不再提供这些旧分支的启动按钮；源码和原结果均保留，历史图表和报告只读。上方旧4/96窗按钮仍明确为日前固定组合来源流程，不等于当前短域新全天。

此次安装只有来源核验与0-native界面测试，不重复原四窗，不推送远端，也不宣称最终合规产品或全天完成。
