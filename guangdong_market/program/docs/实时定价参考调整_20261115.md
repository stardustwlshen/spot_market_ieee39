# 实时定价改用同一时段实时 SCED 参考

## 用户选择
2026-11-15明确：实时定价以对应实时SCED出力为参考，不用日前参考。新结果采用该方案；旧结果不重签、不覆盖。

## 实现
- 热机参考为对应季度三个5分钟SCED平均MW，定价界取当前物理界与 `(1±δ)×实时参考` 的交集。
- 稳定机组留可调范围，不将全部出力锁成SCED值，保留边际定价空间。
- 停机为0，启停轨迹等不可定价状态仍固定原SCED；整数状态分类来自原始SCED，不重选。
- 保留当前传入状态的首爬坡，不再用日前前季度平均值替换实际状态。
- 备用参数按已验证的`delivery_tick`选取相同三个5分钟格，而不是由窗口编号隐式偏移。
- q0必须有真正的t0实时SCED才能进入定价；日前种子不能冒充实时结果。启动链另行同步修改与验证。

## 与规则/模型的区别
此前核查的区域细则3.4.4.5原文参考写“日前SCED”。本改动是用户选择的自有仿真方案，不包装成官方勘误。δ默认10%仍为研究假设。

PRICE仍是15分钟聚合的独立模型，不是直接取5分钟SCED对偶。负荷、热机、风光取同三个格均值；储能季度内同方向时按效率线性转能量，混合充放方向拒绝；线路取三格最严界。该模型没有完整保留每个5分钟内部自由度，不应宣称与SCED逐条相同；此次只保证不放宽已有网络/储能/备用约束与报价，不恢复无功/交流。
