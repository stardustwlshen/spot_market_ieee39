# 输入准备性能优化与验证

2026-11-16；基于 main `002c6c12a2afd1a0d71c7e3de68de7225eab32a2`。

## 改了什么

- 5分钟输入转15分钟时，按机组一次分组，不再反复扫描整张时序表；删除深拷贝后再次重建整个输入的重复遍历，保留可变数据隔离。
- 同一进程内，以每次重新读取的**完整当前输入字节**为键，仅缓存一份不可变的预测基线摘要。不是路径或修改时间缓存，输入内容变化仍重新计算、校验。
- 未修改市场模型、资源约束、求解次数、1% MIP gap、3600秒上限、检查点频率或独立备份要求。源码完整性仍由原来源校验负责，摘要缓存不替代源码校验。

## 完整一小时对比

同一已验证日前结果与输入，重新计算实时Q00–Q03。每版12次求解，完成H0结算，每个15分钟执行步均上传检查点并独立下载逐文件校验后继续。

| 计算环节（4格合计） | 原版/秒 | 优化版/秒 |
|---|---:|---:|
| 调度构模 | 14.94 | 8.88 |
| 调度求解、接收及其内部校验 | 12.64 | 13.51 |
| 调度后检查 | 2.60 | 2.78 |
| 定价准备、构模 | 37.53 | 21.94 |

本样本计算阶段减少约30.2%，主要来自输入准备，不是放松求解精度。分段计时不包括初始化、检查点打包、上传下载及协调等待。

实际端到端原版142.23秒、优化版86.99秒，但原版Q0等待备份协调器启动多约29秒，因此**不能把该端到端差额或39%作为程序加速率**。网络及机器负载也会变化；本次不是全天96格速度保证。

## 同次定价参数投影去重

在上述版本 e4b5d25 基础上，定价准备直接将本次已核验的输入投影为参数文件，避免为同一参数文件再次解码、转换和应用预测。公共独立入口仍完整读取输入，独立定价模型仍重新构建，来源和最终完整性校验保留。未新增跨调用缓存，未改变求解、约束或备份。

同进程同输入7轮交替计时，参数投影子阶段中位数由0.722秒降至0.0098秒，稳定节省约0.71秒/格。完整定价准备样本受机器负载影响明显，不据此宣称全流程或全天加速比例。

验证：Q0、Q3各两组完整定价矩阵及变量名完全相同；Q0、Q3真实求解电价完全一致、KKT通过；Q0/Q3/Q95参数回归通过。参数投影后篡改输入或预测文件（即使维持长度和修改时间）仍被拒绝。独立复核确认无全局缓存或跳过独立校验。


## 单次请求内的基础输入快照

基于 main f7fdb2a。只将同一PRICE准备阶段对全天case的三次完整解码转换合为一次，消费者仍取独立深拷贝；每个原读取边界仍完整读取当前字节并比较，独立定价模型重新构建。预测包、已接受SCED、日前资料及AGC读取校验不省略；不引入全局或跨请求快照，不缓存求解结果。

同一小时Q0–Q3各12次原生调用、H0结算、每格真实上传及独立下载校验的对比：

| 环节，4格合计 | 原版/秒 | 快照版/秒 |
|---|---:|---:|
| PRICE准备 | 19.14 | 14.36 |
| 全部计算阶段合计 | 56.79 | 51.23 |
| 含初始化、逐格备份的端到端 | 89.46 | 81.60 |

本次PRICE准备减少4.78秒；其余环节和备份存在负载与网络波动。端到端差额7.85秒仅是本次观察，不承诺全天96格固定加速幅度。先前测试的长期准备worker因为收益与复杂性不成比例，未部署。

4格SCUC/SCED原始解、目标与对偶，PRICE全部矩阵及原始价格，执行状态/SOC和H0电量金额一致；两版8份逐格备份均已读回校验。41项相关回归通过，并经独立审查。

修改报价、容量、初始出力或SOC后，新实例会读取新字节，A-B-A合成输入与fresh转换对照通过；运行中修改本次绑定文件会被拒绝，不能混用。预测包更新仍重新读取，并要求与本时段已接受SCED预测一致。此验证覆盖阶段输入，不把它声称为全部界面新运行路径均已验收。

捕获后同长度同mtime输入变更、既有代码摘要冲突、转换期间代码变化均拒绝；快照模板不受调用者副本修改影响。实际prepare的case/预测篡改及人为异常均无READY/RESULT/accept，原失败目录禁止覆盖。两个读取点之间改变后又恢复的瞬时修改不一定能被观察到，不作过度安全承诺；模型只消费已固定原始字节转换的模板副本。

两版隔离路径首次尝试因输入原程序路径绑定而在求解前拒绝。保留失败现场，核验所有不变源码字节后建立独立新输入副本；零求解初始化通过，源码和输入分别外存读回后执行上述v2对照。没有删除路径保护或冒用旧结果。
