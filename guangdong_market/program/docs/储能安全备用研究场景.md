# 储能安全备用研究场景

本功能是纯现货电能量优化中的安全备用约束，不是新增备用交易、调频或容量市场，没有新增备用费用结算。研究场景单独启用 `reserve.storage_reserve: true` 、显式 `reserve.T_dur_h: 1.0` 及 `reserve.down_enabled: false`；默认配置不自动修改。

## 需求与供给

上备用需求仍为 `rho_L*负荷 + rho_RE*风光可用预测 + max(n1_loss, 最大单机)`；本次研究场景只采购上备用，下备用需求、所有资源下备用和下备用短缺均固定为0；历史兼容场景未关闭下备用时保留旧规则。可用预测不是已出清功率，因此弃风弃光不自动减少需求，弃水也不直接进入需求式。原煤电、燃气、水电提供者和相关参数不变。

## 电池

净基准出力 `P=Pd-Pc`，正数放电、负数充电。基准计划仍保持充放互斥；备用激活采用逆变器可跨充放零点的理想响应假设，停充停放状态也可提供备用。这不是实际设备响应速度认证。

上备用 `ru` 不超过 `Pmax-P`，实际激活净出力 `Pu=P+ru`。每资源每时段引入共同参与资格二进制 `z`，满足 `ru <= 2*Pmax*z`。只有选择资格时，才校验1小时恒定激活能力；对段初实际/计划能量与段末计划能量分别检查：

```
E - Emin >= H*(P+ru)/eta_d - (H*Pmax/eta_d)*(1-z)
Emax - E >= -H*eta_c*(P+ru) - (H*eta_c*Pmax)*(1-z)
```

`H` 的单位是小时。正负净激活方向分别采用放电、充电效率；负的右端不构成额外限制。条件约束的常数由物理功率界推导，不使用任意巨大数值。

## 抽水蓄能

第一版仅已进入发电工况的机组提供连续备用。上备用不超过 `unit_max*ngen-Pg`，本次不采购下备用。资格 `z` 不超过发电工况变量，上备用不超过 `N*(unit_max-unit_min)*z`。定速抽水和停机不计备用；未建模整台切泵、停机启动或工况切换响应。

上下库合并为有效上库界限：`Vlo=max(vup_min,Vtotal-vdn_max)`、`Vhi=min(vup_max,Vtotal-vdn_min)`。参与时，对段初和段末分别检验最大发电激活：

```
V - H*(Pg+ru)/e_gen >= Vlo - (H*N*unit_max/e_gen)*(1-z)
```

库容为万m³，`e_gen` 为 MWh/万m³。上备用激活仍为非负发电，因此不会增加上库水量；既有有效上下库物理界保留。

## 资格、价格与适用边界

- `z=0` 强制备用为零并关闭持续能力守卫，允许原有能量轨迹；关闭整个功能时没有新增资格整数项。
- `z=1` 但备用为零可能是优化退化，不能称已经供应备用。界面与导出分别展示资格和实际备用MW。
- 资格属于SCUC整数；SCED固定全部整数并使用同一目标与约束，不重算资格、不额外重定价。LMP是在固定备用参与决策下形成的边际价格。
- 1小时规则是恒定激活水平能力测试，不是未来完整基线轨迹、反复激活、恢复能力或事故后网络可送达证明。上下SOC/库容物理界不是下备用；上调后仍充电时尤其必须检验上SOC界。
- 原火电/常规水电备用的响应与持续能力缺口未在本功能中全面重构；不能仅因总备用足够就宣布全部安全要求得到满足。

## 新能源扩容场景

按追加授权串行验证五组完整96段：原装机/储能备用关、原装机/开、新能源1.5倍/开、新能源2倍/开、新能源1.5倍且负荷1.1倍/开；全部仅上备用。先完成1.5倍组再依次补齐对照和压力场景。旧main全天结果含下备用，不能充当本次仅上备用基准。各组独立SCUC，实际gap与不满足约束均须披露，不把近优求解路径差异全部归因某个物理参数。

独立场景可将W1/W2/PV1从1040/564/652 MW扩至1560/846/978 MW。报价段量、实际及各预测可用曲线同步缩放，原报价价格和seed不变，另存报价版本；不覆盖历史场景。预测沿用原0.001 MW舍入，因此与“已舍入旧预测×1.5”可能相差0.001 MW。新能源扩容也增加现有 `rho_RE` 项备用需求，结果须同时检查消纳、备用和价格，不预先承诺效果改善。

## 水电下泄工程边界

本轮保持H1原有 `qout_max=None`，即未给总下泄/弃水短时上限。集中弃水可能在数学上满足水量平衡与末库容，但不代表泄洪、下游或水力瞬态已验证。不得以硬库容目标检查通过替代这些工程能力校核；后续应采用明确设备参数，而非为了让结果平滑任意设值。
