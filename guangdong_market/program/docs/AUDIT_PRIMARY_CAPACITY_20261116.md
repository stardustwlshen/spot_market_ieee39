# 实时定价一次调频比例基数一致性修复

候选基于 b798ade，集成基于 main c171ad8b2058b4552a339ef3a695747784daeab5。

## 依据及边界
2026 广东现货电能量细则印刷页62、105、116的一次调频公式均写 min(Pmax-P, 6%×Pmax)。p138可调出力上限扣除AGC，但符号重用，不能断言百分比基数必须/不得扣AGC。此修改是用户要求调度与定价一致下的明确建模选择，不声称官方唯一规定。

程序区分：
- 时段技术可用出力上限：输入 max_mw[t]，允许降额，不等于固定额定容量；SCED用其计算一次调频比例上限。
- AGC预留后的能量出力上限：max_mw[t]-AGC_up[t]，仍约束能量+一次调频+事故备用共享容量。
- 定价参考范围上界：围绕实时SCED出力计算的带宽，只约束定价功率变量，不代替前两者。

原PRICE把第二个量同时用于百分比基数，导致比SCED额外收紧。修复只将定价百分比基数与SCED对齐，保留联合headroom、功率参考带、其它物理和成本约束。停机/启停轨迹保持原口径。

## 验证
单机技术上限100、AGC_up20、功率50、一次调频6%和需求6：真实生产build_free_scuc后固定整数SCED最优；原生产PRICE约束不可行；修复后可行。7项测试通过，包括同场景差异、真实对偶与有限差分电价10元/MWh一致、联合headroom未放松（负荷74可行、74.001不可行）、AGC零时不变、降额可用上限90不是额定100也不是定价带55、非稳定状态不变、调用处保持联合约束。

局限：这是生产函数微型求解及调用点静态绑定测试，不是完整生产实时定价文件链或全天重跑。
