# 实时首时段闭环

用户决定实时定价参考同一时段实时 SCED，而不是日前 SCED。

新运行采用 `rt_clock_mode=same_period_execution`：

1. 仿真 t=0 从申报的机组初始出力、开停机持续时间、储能电量和累计循环量开始；不执行日前计划的前三个五分钟格。
2. 每个窗口在 t 时刻使用已发布输入及预测，执行 SCUC、固定整数后的 SCED；未来预测不等于已执行值。
3. 用该次 SCED 中对应的三个五分钟格构成当前十五分钟定价参考。定价模型仍独立，时间聚合约束不冒称与五分钟 SCED 完全相同。
4. 仿真只执行首三个五分钟格，状态取这三个格末状态，下一窗口从 t+15 分钟继续。
5. 当前季度价格和执行结果保存后再写可靠检查点；每小时四个季度只结算一次。

旧档案仍保留旧模式标识，不允许把日前种子价格重标为已求解的实时价格。

启停提前通知不被删除：已知计划中的未来通知按实际到期五分钟时刻模拟发布，不允许下一窗口回填过去通知。

本修复不是声称广东规则对“日前 SCED”文字已被官方澄清。它是用户选择的调度定价一致性解释；δ 仍是显式研究参数。
