# 新能源报价同源修复

本补丁仅修复省级单日正式入口新能源报价贯通，不更改市场规则、参考范围、预测上限、弃电罚项或结算公式。

原问题：日前读取输入报价，实时调度目标和实时定价参数却硬编码 -50 元/MWh。修改输入报价后两阶段可能不同源。

修复：
- 用户界面按节点填写全天新能源单价。当前物理模型为节点聚合，不能称为同节点多个电厂各自分段申报。
- 日前继续使用 case.energy_inputs.renewable_bid_yuan_per_mwh。
- 实时 compiler 使用同一报价序列切片后的 [bus,local_tick]，不再写死 -50。
- 实时 PRICE 参数保存明确的同窗口逐格报价数组，并与输入 case 的绝对时段逐项核对；PRICE目标使用每一格的实际报价。首格旧标量仅用于兼容校验，不代替未来报价。
- 日前 LMP 沿用固定整数 SCED 的报价目标。
- 目标仍为 duration*(bid*output+Mc*curtailment)，Mc默认0；结算仍以出清电量和节点结算价计算，不直接按申报价支付，不把弃电罚算作真实现金费用。
- 实时 PRICE 现有SCED参考带仍保留。因此报价行为的小模型对照不能冒称完整生产参考带模型的响应。

验证：报价时序35..42/末格95映射、错时段拒绝、原生HiGHS三组报价与弃电罚机制测试已通过。完整生产短链须另行验收。本补丁不修改历史结果或恢复档案。

旧tail_parameters属于非省级历史路径，未将本补丁伪装为所有遗留引擎已统一。省级math_prepare仅导入branch_parameters。
