# 抽蓄同节点优化单元互斥

依据：《广东电力市场现货电能量交易实施细则（2026年修订）》日前目标函数定义：同一电厂、上网节点相同的机组组成一个优化单元；印刷第56页(21)约束该优化单元抽水与发电模式之和不超过1。

PS1两台机组均接母线2。原模型仅对每台机组实施抽发互斥，遗漏整个同节点优化单元的互斥，因此一台抽水、另一台发电曾被求解器接受。这不是不同电站/不同储能设备之间必须统一方向的要求。

修复采用现有模式变量两两约束：任何机组的发电模式加同单元其他机组的抽水模式不超过1，不增加二进制变量。日前、实时与定价共用此物理模块，因此共同生效。定价固定SCED整数状态后仍保留此约束。旧混合模式检查点不能直接接入新模型。

验证7项：日前/实时混合抽发不可行、固定整数定价不能接受混合见证、同单元多台同时发电可行、同单元多台同时抽水可行、真实定价接口拒绝旧混合见证、不同电站同节点可分别抽水和发电。

旧全天H7的15分钟原始结果证实：07:30–07:45为一台发200MW另一台抽300MW；07:45–08:00为发300MW、抽300MW。小时累计本身不足以认定同刻抽发，必须核到时段。水量账原来守恒，但守恒不等于市场模式约束完整；旧结果不能作为修复后的验证结果。需从新日前结果重新计算实时和结算，不可只删报表记录。
