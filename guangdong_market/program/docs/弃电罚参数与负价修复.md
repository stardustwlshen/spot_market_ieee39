# 弃电罚参数
广东省级2026实时LMP6.6.2.2（印刷114页）保留报价成本与Mc·SLc项，弃电定义见印刷122页。未核得统一Mc=1000官方参数。
本程序按用户“报价参与，不新增统一弃电罚”选择研究默认Mc=0；保留完整弃电变量、约束与目标项。可通过case顶层`research_curtailment_penalty_yuan_per_mwh`显式设置非负数，DA、RT和RT PRICE共同读取，不改变其他罚项。此设置不是广东官方数值认证。
原RT/PRICE统一Mc1000配VRE报价−50，造成少发弃电边际成本1050高于负荷过剩松弛1000；模型宁可吸收虚拟过剩。对原q33/q42全网LP只改Mc，过剩分别56.7378/51.5092MW降至0，原始价格从−1000到−50，KKT通过；q72拥塞价格425.25至1425.25不变。该试验保留旧PS结构作独立因果对照，不能替代新厂级互斥的全流程验收。
限价后小时结算与原始LMP分开保留；不能以裁剪价格掩盖原始模型问题。
