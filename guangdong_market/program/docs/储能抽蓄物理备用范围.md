# 储能与抽蓄物理备用

物理可提供量不等于备用市场中标量，更不等于可以获得补偿。经济资格和收入另算。

## 参与集合
- 一次调频：按广东省级现货电能量细则印刷104–105、116页的火电、抽蓄、水电公式。当前模型不含水电；电池不自动加入该公式。
- 事故/上备用：按用户“除风光和区外来电外默认参加”的选择，加入电池和抽蓄。参数并不宣称设备已经通过真实市场资格认证。
- 10分钟响应、15分钟持续和时段末能量口径是当前研究设置，不能当作上述一次调频公式给出的官方持续时间。

## 不重复承诺
火电一次调频和事故备用之和不能超过同一出力裕度。抽蓄二者之和同时受在线发电裕度、上库剩余可发水量和下库接收空间限制。两类容量不得各自独立用满同一份水量。

电池只计当前放电模式下的发电裕度，或减少当前充电功率。减充不允许转成超过零的放电，从而遵守当前小时充放方向。还受响应爬坡和时段末可用电量限制。电池一次调频在本规则公式中为零。

抽蓄只计已经发电的机组，不把停机快速启动、泵跳闸或强制切换模式当作无条件可用的备用。一次调频不超过在线发电容量的10%。当前备用量由原始模型变量导出，不能用净注入功率代替。

正备用容量约束是系统容量充分性检查，非另一项独立出售的容量，不应与其内的事故备用再次相加结算。

抽蓄响应可在站点parameters调整：`gen_up_step_mw`是已申报的15分钟发电上调步幅；`contingency_response_mw_10min`可另给10分钟响应上限，但不能超过前者按10/15折算。`contingency_response_enabled=false`禁用抽蓄事故备用。未给步幅时用容量估算的默认值明确标为研究假设、未经设备认证，不得展示为实际保证响应。
