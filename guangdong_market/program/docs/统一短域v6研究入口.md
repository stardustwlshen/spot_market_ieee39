# 统一短域 v6 研究入口使用说明

## 启动

安装项目 `requirements.txt`，运行 `python -m streamlit run app/主页.py`。使用现有场景/报价编辑与日前入口，再打开研究开发入口。默认操作是纯准备或读取，不会自行启动原生求解。

## 查看随包完整历史研究日

展开“本次修正研究日：24小时历史结果与研究结算”，勾选“仅查看固定历史原案例（不使用当前选择或编辑场景）”，点击“核验并读取固定研究日”。可查看小时研究金额、节点15分钟价格并下载执行格、结算行和来源索引。

此模式通过固定清单哈希和原案例身份校验读取 `research_results/corrected_day_v6/`。搬到其他目录或电脑不要求原云端DA路径存在，也不重求解。结果属于原CLI11修正分支及其明确沿用/恢复链，不属于v6新native或用户刚编辑的场景。

关闭固定历史模式后，所选日前必须与历史结果匹配，否则拒绝读取并清除旧显示。切换场景不能悄悄沿用历史结果。

随包必要文件：`app/gd_corrected_day_bundle.py`、`app/gd_corrected_day_panel.py`、`app/CORRECTED_DAY.json`及`research_results/corrected_day_v6/`全部文件，默认相对路径注册。约1.5 MB结果包是物化只读视图，不是全量优化原始证据备份；原始证据按 `SOURCE_INDEX.json` 与独立备份追溯。

## 新场景研究运行

选择已接受日前，设置新运行名，明确保守日前保护、合成次日声明和初态后准备。按页面逐窗构模/预检、显式启动SCUC和固定新整数SCED、严格接受、明确无偏差研究交接，再独立准备PRICE与核算完整小时。缺失项拒绝，不补零。未知或失败记录保留，不自动重试。旧版本或其他安装目录上下文有绝对源码pin，不能修改身份来冒充本安装的新运行。

v6保留原400 MW备用、SOC/循环限制、HiGHS相对gap0.001，移植同数学数值稳健性处理；本版本已做fresh纯用户流程与结果读取测试，没有为了换版本重跑全天。

## 如何解释本次结果

实际修正日：96实时窗口、288已执行格、96独立PRICE见证（25沿用、71新算）、24小时、1296研究结算行。研究电能量金额不是利润、实测账单或支付金额。研究结算模型已实现；真实账单与支付不在本仿真任务范围。

23季度有 `PRICE_load_surplus`，最大159.7242396955367 MW。官方§3.4.4及附录19/21允许相关松弛，两罚因子默认1000，非零本身不是违规判断；当前VRE分类及研究参数适用性仍待核查，不能背书实际运营。页面按实际非零类型列示，不把缺电、备用、网络松弛也说成非零。PRICE松弛不改写RT硬平衡轨迹。

保守全在线算例不等于通用重新组合；通用thermal/AGC仍实验隔离。原交流失败、研究边界及未取得正式安全发布的限制继续保留。省内范围不变，不把跨区市场纳入求解。

## v6参数与安全提示

PRICE网络罚因子默认改为1000，来源为南方区域2026 V1.0细则附录参数表项18（印180/PDF183），并保留显式参数override。此为区域默认，非已认证广东当前覆盖值。独立96季解析对照证明所有内部网络松弛精确0，旧primal/row dual/LMP仍完整KKT通过；不声明对偶唯一，也不把历史raw的100改写成1000。v6无新增全天native，原历史价格/金额不变。

默认红色安全gate：原W45的12–13时AGC0固定整数对照，弃电41.525664→13.834469 MWh，全4小时约少50 MWh；原400、UC与SOC限制不变。研究安全未放行，逐机归因未建立，移除列表为空。不能由此自动剔除机组或宣称全天AGC安全；还需AC、AGC状态与安全断面。

PRICE虚拟过剩并非已证物理缺口：最大季度存在满足原LP全部行/界限的零松弛实际SCED投影；当前VRE报价−50与两1000罚系数组合使优化选择更多VRE/少弃电与虚拟吸收。VRE资格、聚合参考及δ仍为研究限制，不背书实际运营。

搬家时另带 `app/gd_agc_safety_panel.py`、`app/AGC_SAFETY.json` 和 `research_results/AGC_safety_v6/` 全部文件。只读安全结果用固定清单校验；来源原始文件的独立备份仍须保留。

## 一次授权的批次编排（v6界面增量，不是新数学引擎）

先按页面准备新的研究运行，再展开“批次运行”。选择4窗或96窗，填墙钟预算和唯一批次名，先生成并查看完整计划，再勾选一次授权并后台启动。完全新算上限分别12或288次底层原生求解，已严格接受回执复用。时限合计不是完成时间预测。当前仅Linux锁已验证。

刷新只读进度不会推进求解。阶段间停止不强杀当前求解；后台确认到安全边界退出后，可明确继续同一计划及同等预算。失败、未知或不确定启动状态不能自动重试；双击不重复创建/启动。变更来源、范围或预算必须重新查看计划并授权。页面关闭不停止后台，日志与每阶段记录保存在页面显示的批次目录。

调频失败工作流仅显示原案例BLOCKED_SYSTEM_SAFETY、原奖项与缺资料清单；没有导入任意外部JSON、自动剔除或实际调度入口。仍缺同需求约束的方案、逐机证据、实际AGC状态、AC/安全断面等，不能宣称通用安全重新出清已完成。

新增编排界面通过动作AppTest、控制互斥、篡改拒绝与真实后台阶段前暂停测试。最终安装批入口另外在独立编辑场景实际完成首小时13阶段：4 SCUC + 4 SCED + 4 PRICE，共12次HiGHS，12个执行格与4季度价格，全程严格接受，最大SCUC gap约0.02255%。完成后再次进入只读复用，0新求解。96窗控制流程只做mock故障测试；原CLI11的真实全天不能冒称为经新批按钮重新运行的全天。
