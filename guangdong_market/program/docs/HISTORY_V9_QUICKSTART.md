# v9快速开始（Linux可复现）

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m streamlit run app/主页.py
```

Linux/Python3.12已测；批处理依赖POSIX fcntl，Windows批功能暂不支持。Mac未实机验收。不要把无鉴权应用直接公开到互联网。

## 先看新版研究日（0求解）

进入统一研究入口，主动勾选“查看已注册新版原案例，不代表当前编辑场景”，点击核验读取。默认历史开关关闭；若不勾选，必须选择匹配的原DA。搬到其他目录时明确历史模式不要求云端旧路径存在。新版24小时、96价格、288原RT格、1296核算行；可下载账户比较。旧版折叠显示仅供对比。

## 自己的研究场景

原场景/报价编辑→接受日前→准备新RT。PRICE默认thermal DA+DA前季首锚研究profile；储能current、δ研究不变。首锚未获官方解释认证。更换profile会清确认；已有异profile价格不覆盖，不能失败回退。新研究必须真求解才能显示为新场景结果，历史表不能代替。

## 批运行

选择4或96窗、本次墙钟预算、固定PRICE profile；先生成完整计划，再一次授权后台执行。刷新只读取进度。阶段间停止不强杀native，确认已退出后可明确继续同一计划。未知/失败不自动重试。Windows批功能暂不支持。

## 小时调频

同一运行下展开小时调频面板，确认合成报价/资格/发布时间后，可生成回执并纯构建未来freeSCUC输入。显示“尚未求解”不是故障，也不是旧SCED已经消费新AGC。当前不支持改报价后冒用旧证据，不能人为赋予储能或风光资格；安全红色不放行。通用thermal事件仍实验，未从本页自动启停。

## 边界

省内研究；双400 MW、HiGHS0.1%不改。规则允许定价松弛，不等于执行物理失衡。新总额近似不变不代表所有账户不变，14账户分量改变；不是利润/实账。原AC失败、AGC安全阻断保留。实际支付不是仿真交付范围。

v9仅新增一个seedPRICE native连接验证，不声称新版已跑整天。详细来源见README及research_results下的SOURCE_INDEX/manifest。
