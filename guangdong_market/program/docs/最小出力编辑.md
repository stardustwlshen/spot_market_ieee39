# 最小出力编辑：已验证线性研究模板

仅支持当前原始输入能验证的线性启停模板，不把合成规则当真实电厂能力。

1. 新最小出力须大于0且小于新最大出力。原始最小/最大出力和基段报价须全时段恒定。
2. 原始0至Pmin基段仅有总报价，没有更细子段。本功能明确假设其单位报价不变：新基段总报价 = 原基段总报价 / 原Pmin × 新Pmin。不是推断真实低负荷效率。
3. 最小出力以上各报价段按新可调区间同比分配MW宽度，保留各段价格及数量。明确另设报价倍率时，只调整报价，不修改物理轨迹成本。
4. 原启停轨迹必须线性、单调并完整衔接0与Pmin，成本必须逐点满足“原空载费 + 原基段单位报价 × 平均功率”。不满足则拒绝，不拟合。
5. 保持启停时长和通知时间；轨迹端点/均值功率按新旧Pmin比例缩放，逐点重新计算上述轨迹费用。固定启停费用和绝对爬坡能力不自动改。新轨迹斜率超出声明爬坡时拒绝。
6. 原启停输出限值必须等于原Pmin，才同步更新为新Pmin；特殊限值不推断。重新检查初态、固定出力、AGC预留及新上下界。运行中结果不重写。
7. 利润侧默认发电成本仍仅按类型与最大容量档位决定，不因Pmin改变；旧运行手填成本保持独立保存。本修改不宣称建立真实热耗曲线。

验证限定为模板重参数化、UI快照和模型构建，不承诺任意新参数场景必可行。非线性或未知成本轨迹、分时基段拒绝自动编辑。
