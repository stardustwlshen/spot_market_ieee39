# 统一短域 v5 研究入口使用说明

## 启动

安装项目 `requirements.txt`，运行 `python -m streamlit run app/主页.py`。使用现有场景/报价编辑与日前入口，再打开研究开发入口。默认操作是纯准备或读取，不会自行启动原生求解。

## 查看随包完整历史研究日

展开“本次修正研究日：24小时历史结果与研究结算”，勾选“仅查看固定历史原案例（不使用当前选择或编辑场景）”，点击“核验并读取固定研究日”。可查看小时研究金额、节点15分钟价格并下载执行格、结算行和来源索引。

此模式通过固定清单哈希和原案例身份校验读取 `research_results/corrected_day_v5/`。搬到其他目录或电脑不要求原云端DA路径存在，也不重求解。结果属于原CLI11修正分支及其明确沿用/恢复链，不属于v5新native或用户刚编辑的场景。

关闭固定历史模式后，所选日前必须与历史结果匹配，否则拒绝读取并清除旧显示。切换场景不能悄悄沿用历史结果。

随包必要文件：`app/gd_corrected_day_bundle.py`、`app/gd_corrected_day_panel.py`、`app/CORRECTED_DAY.json`及`research_results/corrected_day_v5/`全部文件，默认相对路径注册。约1.5 MB结果包是物化只读视图，不是全量优化原始证据备份；原始证据按 `SOURCE_INDEX.json` 与独立备份追溯。

## 新场景研究运行

选择已接受日前，设置新运行名，明确保守日前保护、合成次日声明和初态后准备。按页面逐窗构模/预检、显式启动SCUC和固定新整数SCED、严格接受、明确无偏差研究交接，再独立准备PRICE与核算完整小时。缺失项拒绝，不补零。未知或失败记录保留，不自动重试。旧版本或其他安装目录上下文有绝对源码pin，不能修改身份来冒充本安装的新运行。

v5保留原400 MW备用、SOC/循环限制、HiGHS相对gap0.001，移植同数学数值稳健性处理；本版本已做fresh纯用户流程与结果读取测试，没有为了换版本重跑全天。
