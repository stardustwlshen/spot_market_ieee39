# 广东省内电力市场研究程序 v13

本版把用户所选、已接受的日前来源接到同一新分支的首小时流程：**实时 SCUC → 固定整数 SCED → 小时调频衔接 → 四季度独立 PRICE → 54 行研究核算**。小时调频在实时构模前按可用时刻衔接，不是事后冒用旧结果。省间市场不参与优化；原正备用/事故备用各400 MW保持；HiGHS相对gap 0.001（0.1%）。未初始化COPT、未推送。

这是可使用的研究源码，不是广东正式运营合规产品。场景/报价编辑和日前运行入口保留。详细操作见[快速开始](快速开始.md)。

## 安装启动

Linux/Python 3.12为本轮测试环境。在源码根目录：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m streamlit run app/主页.py --server.address 127.0.0.1
```

浏览器打开终端显示的本地地址。不要把无登录鉴权的应用直接公开到互联网。Mac未实机验证；旧批处理依赖POSIX fcntl，Windows批功能不支持，新live入口也未作Windows验收。

## 新首小时入口

选定已接受日前来源并用本安装准备新的RT研究运行，打开“同一新分支：4窗实时 + 小时调频 + 4季度定价 + 首小时核算”。先查看完整计划，再明确启动。

- 默认0求解；新会话最多12次原生调用：4次SCUC、4次SCED、4次PRICE。SCED固定simplex，无自动fallback。
- SCUC/SCED/PRICE每次原生预算分别300/120/60秒，单线程；这些是上限，不是预计完成时间。
- seedPRICE后推进W0–W3；H1使用新W1已接受结果，在T−30分钟发布并用于后续窗口。
- H0执行量为DA已下发首3格 + 新W0/W1/W2各首3格；W3交接证明12格已执行，额外已下发的12/13/14格不计入H0。
- 四个季度价格必须分别来自同源seed/W0/W1/W2，缺价拒绝，不补0；各季仅接受已注册同源profile并逐季列明，不借旧base价格。
- 新分支的进度、价格和核算在同一运行卡显示。更换DA/run/名称会清除旧确认；重复、失败或未知状态不能重新启动。关闭网页不停止后台；不支持持久会话恢复。

## 已验证什么

**真实底层结果，上一冻结阶段：** 新事件/小时调频链连续四窗接受，W0的首份SCED曾超时，保留原失败后以独立simplex恢复；加上后续三窗，RT累计9次调用（含失败1次），形成4份接受pair。随后4次新的独立PRICE全部Optimal且39节点完整KKT通过。H0核算54行，研究电能量额984,919.757350483912元，独立80位Decimal对账通过。这是12个成功的底层求解结果，另保留1个失败调用，不是“只有12次总调用”。

**v11通用API/界面，本阶段0新增native：** 通过显式历史registry逐原始pair/数学/carry重验，再用通用live API纯构模，W0模型与真实已验矩阵相同；只读同源四价并重算H0。另对两套不同合法DA/run在新安装分别完成纯准备/seedPRICE构模。UI默认0、来源切换、重复/未知拒绝均通过；完整12调用顺序用mock检查。**没有声称从v11按钮再次真实跑过12次。** 摘要在`validation/v11/`，完整原始证据另存已验证阶段备份。

## 仍有的边界

- 新live流水线只接首小时，未完成其通用96窗/H24验证。旧v9单独96入口与历史完整研究日保留为独立证据，不能拼成新通用全天已完成。
- 五台热机各10 MW、合计50 MW调频及资格为当前明确研究输入，不凭空给储能/风光资格。通用IEEE39非零启停尚未实际验证。
- live typed API通用化不等于通用启停已完成。当前只接受稳定运行/离线初态及已声明的固定研究曲线；初始active event及已下发事件的导入尚未支持，不推造冷/温/热启动分类。真实IEEE39非零启停未验证。
- 启停指令已接默认worker路径，但只有独立勾选研究启停模拟后才发行模拟回执。构模前锁定旧可用计划的中间5分钟通知，禁止新解追溯通知；纯R68组件与安装交接测试不等于IEEE39非零启停实际求解。
- AC与AGC系统安全未完整通过。固定已验新分支W0的00:15单点原方式AC潮流已收敛但未通过限额（C1超过上限、8个母线电压越限）；这是该点失败证据，不外推其他用户新场景或整个小时/全天。数学可行、SOC/备用行通过不等于系统安全放行；不发布实际调度。
- 默认PRICE为thermal DA区间 + DA上一完整季度首锚；首锚、δ及储能current域仍是明确研究解释，不冒充正式参数。
- 核算是合成无偏差执行、明确合约假设下的研究电能量，不是实测计量、利润、正式账单或支付。

v9及旧引擎历史文档原样保存在`docs/HISTORY_V9_README.md`、`docs/HISTORY_V9_QUICKSTART.md`，不作为新live流水线的完成声明。

## v13 新增操作与准确验证边界

四个选项互相独立且默认关闭：研究启停指令模拟、未通过安全仍继续反事实计算、W0首5分钟点1次AC诊断、固定曲线非定价PRICE研究映射。改变选项会清除旧确认。数学KKT通过不代表安全通过；正式发布始终为false。

PRICE默认保留thermal DA + 前一完整DA季度首锚。若真实源出现曲线/离线等非全稳定状态而未单独选择事件研究profile，明确拒绝，不强行算价。选用`fixed_curve_5min_source_mixed_quarter_fixed_RESEARCH_v1`后，按实际5分钟曲线核验；混合季度固定原三格均值、相关资源保留逐格物理约束。稳定腿/既有DA首锚仍适用。这是明确研究映射，不声称广东正式实施参数。全稳定来源即使勾选仍沿用原profile；小时结果逐季列明profile。

安全未放行且未允许反事实继续时，保存当前证据并在同一worker保留live host最多10分钟。此期间可在同一运行卡：
1. 填选下一未来窗首5分钟格的热机功率基点上限及研究来源。身份、时间、上限合法范围由当前已接受源取得，不要求手写hash。
2. 发送声明，刷新进度，阅读真实登记计划后另行确认。登记及完整SCUC构模均为0求解。
3. 再次刷新，核对新增候选预算；只有第二次明确授权才调用1次SCUC + 1次固定整数SCED，300/120秒、单线程、gap0.1%，不自动重试，无额外AC或PRICE。

该候选只收紧未来功率基点，不改变技术容量、资格、原50 MW调频及400/400 MW备用，不能修复历史W0失败。候选接受后仍做同源安全检查并保留旧失败；不会自动接回完整小时、重新定价或发布。进程退出、过期或未知不可恢复，未知调用数不能当0。总预算为主计划最多12次，另外的未来候选仅经单独确认最多2次；默认都不执行。

**v13验证均为0新增HiGHS/AC：** 安装版完整普通PRICE矩阵与前一真实来源的已验模型变量/行/目标/options/names一致；事件模块引用已冻结R68真实raw组件与混合季研究fixture证据，R68不具完整IEEE39 PRICE网络，因此没有虚构新网络或宣称事件PRICE实际LP通过。同worker声明→登记→完整模型新增cap行已实测，原生执行调用仅mock验证；UI独立确认/重复/过期/退出门禁已测。前述12个真实成功底层结果+1失败仍属先前阶段，**不是v13按钮新跑过12次**。

现有场景编辑和日前入口保留；仍未完成通用96窗/H24、IEEE39非零启停PRICE实际联合求解、完整AC/调频安全及正式结算。本版本不是最终广东运营合规系统。
