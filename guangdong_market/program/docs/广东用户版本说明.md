# 广东省内研究程序：短时域开发版使用说明

这是正在整合的研究版本，不是完整合规产品或已完成全天的新安全闭环。已验证内容与在研分支分开列出，不以旧流程结果替代新流程验收。

## 启动

建议 Python 3.12：

```bash
python -m pip install -r requirements.txt
python -m streamlit run app/主页.py
```

支持 Bash 的环境也可运行 `bash scripts/run_guangdong.sh`。Linux 冷安装及原主页 AppTest 已通过；没有据此声称 Mac/Windows、实际浏览器像素或外部部署已通过。只监听本机，不提供公开站点认证。默认广东主页，旧川甘参考引擎、CSV 和历史文档独立保留，不能自动当作广东输入。

所有研究保持省内范围、原场景、400 MW 正备用和 400 MW 事故备用。求解器 HiGHS，SCUC gap=0.001，绝对 gap=0，单线程；不初始化 COPT。

## 当前主页可用流程

1. **选择日前来源。** 编辑场景并另存，或填写已有已接受的日前运行。新编辑真实进入模型，不偷偷退回基准。上方一键 4/96 窗仍是旧日前固定组合流程，不是新实时重新组合全天；它可提供已接受日前来源。
2. **短域实时组合。** 打开“短时域实时组合：准备、求解与接续（新研究入口）”。选择同一日前，给全新实时目录，明确首 15 分钟已经下发的反事实研究假设。准备和构建均为 0 次求解。当前已安装 CLI1 使用近/远各 24 个五分钟联合优化，只支持稳定初态、统一启停曲线；未支持的 active 边界、非零新通知及次日扩展拒绝，不重置 SOC。
3. **预检后明确求解。** 预检通过后启动后台 SCUC（300 秒原生预算）及固定新整数 SCED（120 秒）。构模、读取与验收用时另计。重新刷新不重算已接受窗口；未知/未完成的尝试不会自动重试，不因 PID 不可见或页面关闭推断它已死亡。当前没有安全取消按钮。
4. **严格接受再接续。** 整数、约束和 SCED 全 KKT 检查通过后，明确选择无偏差反事实跟踪，生成下一边界。已执行、已下发未执行与未来优化域分别保留；不是调度许可、计量回执或 AGC/AC 安全通过。
5. **独立 PRICE。** 使用“短域独立定价与已齐小时（新研究入口）”。选择同一日前、短域运行及已接受窗口，生成命名参数或填写完整 JSON。δ、参考域、风光报价、罚值、资格、负备用、一次调频和机组组限制均显式进入模型。样例 δ=.1、风光价 −50、负荷/事故/网络/弃电罚 1000/200/100/1000、原 case 中为 0 的部分需求等是研究输入，不是广东正式参数。明确选择 `current_sced_research` 或 `DA_reference_R61_compatible_research`；规则文本的日前参考域不能静默改名。准备不求解，真实 PRICE 为单独一次 60 秒 HiGHS。只将首个 15 分钟发布为研究结果，其余 7 季是预测域，不拿 SCED 对偶替代。
6. **完整小时核算。** 提供按时序的 4 个独立季度价格以及该小时完整 12 格执行。最初季度的 seed 价格也必须同源，不借其他场景价格。缺执行、缺价、时间不符或串源均拒绝，不补零。金额保留精确数字字符串，只表示显式合成参与/空合同下的能量分项，不是利润或正式账单。
7. **交流安全拒绝。** “短域基准安全校核”读取冻结基准证据，不启动计算。基准 00:15 首点实际不安全，明确显示红色拒绝；它不替代当前编辑场景的安全检查。另一个 17–18 点通过分支单独标识，不能套用其状态或未来控制量。

跨安装副本的 PRICE 小时读取冲突已在 UI 适配层修复：固定注册的可信 RT 读取器完整重放原回执，不修改原票据或冻结引擎。真实编辑例先通过来源检查，再明确因仅 3 格执行而拒绝完整小时；错误日前、未知来源、篡改价格和未接受窗有拒绝测试。

当前安装的短域 RT/PRICE 均为 CLI1。开发中的 CLI2–5 全天、恢复边界和次日合同不能直接填入这个入口冒充兼容。历史 48 小时链及 PRICE2.2 有单独入口，不可交换票据。三态和调频候选也有独立边界，不自动拼成完整安全链。

## 规则依据与研究选择

广东规则每次模型 T=24、5 分钟，并区分近/远各 2 小时。新版本去掉旧 48 小时自由组合的大范围未来整数与事件费，将两段各 24 格联合求解。这是明确的联接研究解释，不把文本未唯一规定的算法说成正式实现。旧 48 小时研究结果仍保留，不能覆盖新短域票据。

储能传递实际研究前缀的 SOC、模式、循环账和剩余义务，不按日前未来曲线重置。跨午夜的次日已发布计划与储能期末申报必须有来源/可用时刻，未齐则拒绝；独立开发分支的假设次日计划不冒充实际市场申报。

调频研究保持原资格和 50 MW 需求，不自动给新能源/储能资格。新 01–02 点研究分配在后续模型只替换未来重叠段，不重复扣减调频裕度。其他小时沿用明确原研究分配，不冒充逐小时新清算。官方修订公告不单独作为数学机制或储能正式资格依据。

## 失败、恢复与备份

原始解、失败日志和每次原生调用记录均保留。数值验收失败也不标成通过；在相同数学、固定整数下改用高精度 HiGHS IPM 时使用明确新修订，并保留失败与恢复的对应关系，不降低 KKT 阈值。仅对已固定禁用方向的微小浮点符号作有界、记录在案的接口规范化，不改原解、SOC 或能量账。

恢复读取已接受结果，不重跑旧求解；未知尝试先核结果。独立档案既保留压缩件，也实际下载验证；不拿只有哈希或配方当作已恢复。v6 已独立保存并下载验证，但它不包含后来新增的短域开发阶段，后者在下一个有意义的组合节点做一次独立归档。未推送远端。
