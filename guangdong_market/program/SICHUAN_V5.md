# 四川 V5.0 征求意见稿 · IEEE39 研究模拟

## 机组申报工作台

首页只选水期（丰水期、枯水期）和预测误差（正常、极端）。分别采用 8 月、1 月代表日的合成来水、负荷、光伏和气电计划参数。每个水期使用种子 39 对应的同一份企业申报，切换误差时可复用已冻结申报。正常、极端两档分别以系统负荷峰值的 1%、3% 作为日前净负荷预测误差标准差，按单侧 95% 分位向上取整至 10 MW，形成可通过网络送达的向上裕度。两档均为事前仿真假设。四种组合独立保存结果；原先的三个历史场景可经原结果链接回放。

在「机组申报」核对各站的 96 点计划、区间来水和机组能力，再检查四库初末库存、生态及旁泄要求、18 段时滞和期初在途水量。参考计划用于比较；进入市场的是按厂站冻结的日分段申报和经校验的耦合条件。市场使用独立来水预测和核准水力参数。选择耦合并获准是本项目的模拟前提。

「确认并冻结 19 站申报」保存可校验的事前申报。点击「运行日前预出清」后，系统核对 96 点申报上下限与市场技术能力的交集，按独立来水建立梯级水账，再执行 SCUC、固定组合 SCED 和同价分配。可导入外部调频与备用中标占位，默认无占位。当前入口止于日前发布。每次计算的组合、节点参考价、线路、19 站水账与日末在途水量独立保存到 `dadu19_da`。页面可查看历史日前结果、同时比较多个站并下载 CSV 与完整输入输出。以下实时与结算说明对应独立历史研究流程。


## 大渡河 19 站

[六个完整日的结果与对照图](examples/dadu19/README.md) · [预测偏差日逐站、逐节点、逐支路账表](examples/dadu19/full-day/README.md)

首次打开可以直接查看随库的完整日。要重算，请展开「运行设置与新算例」，选择场景、报价策略和实时执行范围，点击「生成公司报价并运行市场」。进度条给出当前环节、已完成项数和耗时。公司优化、日前 SCUC 等单次求解期间显示正在等待的步骤。首小时试算也会先完成全日公司报价和日前计划。

| 岗位 | 第一眼看什么 | 如何复核 |
|---|---|---|
| 水电企业报价员 | 「公司报量报价」的组合内部计划、19 站冻结段数及价格范围 | 选择瀑布沟和时段，查事前来水、预期价、机会成本、可发区间与分段报价。切换到「日前预出清」查看同站中标。 |
| 电网市场及调度人员 | 「日前预出清」先看煤机组合，再看固定组合后的各类出力及节点参考价 | 「实时出清与执行」核对滚动窗的首段、气电计划、节点价、断面和缺口。有失负荷时可跳到缺口最大的一段。 |
| 流域调度人员 | 「全流域水情」先读 19 站合计、四库库存和 18 段在途水量 | 逐站查看区间来水、过机、生态旁路和弃水，再按河段核对上游放水何时到达。 |
| 结算或复核人员 | 「收入与对照」核对已核价现金和待核电量 | 同场景、同边界、同预测签发的两种报价可成对核对；压力时段保留原始物理结果及停价原因。 |

**水电公司如何报量报价。** 公司先用事前签发的 96 点来水和节点价预测，联合优化各站内部发电计划。目标包含预期售电收入和期末水资产变化，库内水按所在地估值，在途水按接收站估值。工程约束包括期初库存、期末区间、生态下泄、爬坡、时滞与水量守恒。公司还在这些约束下单独求各站的报量边界；单站上限不能直接相加作为全流域同时可发能力。

水价值策略从联合优化的出力约化成本提取每站各时段的边际水机会成本。排序后，按报价段数分组取中点样本，再拟合合规整数段价。朴素策略使用 0、20、40… 元/MWh 的模板。两种策略共用同一套事前内部计划。四座库站各 10 段，十五座径流式站各 5 段，共 115 段；量轴按设计装机分段，实际可出力仍受设备、来水和库存边界限制。市场使用独立预测和已冻结曲线，市场力缓解发生时另列市场采用价。报价优化的算法、估值与参数是本项目仿真假设。

**如何看全流域水账。** 按同一时间范围，把期初库内和在途存水加上头水及各站区间天然入水，减去末站出口、期末库内和在途存水，得出流域残差。站间到水属于内部传递。弃水或生态旁路一旦进入下游河道，仍会在后续时段到达下一站。逐站发电量可以加总，同一股水经过多座厂站时可分别发电。

在本目录双击 Windows 的「启动四川.cmd」或 macOS 的「启动四川.command」。Windows 启动器优先使用项目 .venv，其次使用本机已登记的同名 Conda 环境 spot_market_ieee39。首次安装方法见下文。

首页提供三类预置申报，使用方式见「机组申报工作台」。

19 个水电站的设计容量合计 22,056 MW，另有 3,200 MW 煤电、1,200 MW 气电和 8,820 MW 普通集中式光伏。四库可跨期蓄水，其余十五站按径流式模拟。统一策略属于模拟组合；项目业主、设计装机、当日可用容量分列。电网接线、来水预测、传播时滞、交易能力和市场力缓解成本参数属于合成工况。日前预出清不结算，实时电能量估值按已执行时段覆盖，含库存价值的比较不等于实际企业利润。

旧四川研究场景和旧归档仍可从页面切换。大渡河单次运行存放于 runs_sichuan_v5_consultation/dadu19/，内含公司冻结申报、结果与完整性校验记录。

这是 **四川 V5.0 征求意见稿的 IEEE39 合成研究模拟**。可用于学习报价、出清、节点电价和研究金额；不是已生效的四川规则，不用于实际调度或正式结算。

需要私有 Linux 容器托管时，参见[私有云托管与验收](SICHUAN_HOSTING.md)；这不是已部署的链接。

## 第一次使用

1. 从项目的 [`sichuan-v5` 分支](https://github.com/stardustwlshen/spot_market_ieee39/tree/sichuan-v5) 下载完整源码 ZIP。若试用说明给出固定提交的 ZIP，优先用该链接，而不是会更新的分支 ZIP。不要只下载单个启动文件。macOS/Linux 可解压到可写目录，再进入 **`guangdong_market/program`**；Windows 建议按下方步骤直接解到短路径。

   **Windows 不需要 Git 或管理员操作：** 完整 ZIP 含历史引擎的深层目录。直接在「下载」里用资源管理器解包，或保留 GitHub 的长外层目录，即使靠近盘符也可能报路径过长。只对上面可信的项目源码 ZIP 使用以下步骤。打开 PowerShell，把示例 ZIP 路径换成实际下载文件的完整路径；`C:\sc` 必须不存在且其父目录可写，也可用同样短的 `D:\sc`。若目标已存在（包括上次解包未完成），换一个短的新目录，不覆盖旧程序或结果。

   ```powershell
   & {
       $zip = (Resolve-Path -LiteralPath 'C:\Users\你的用户名\Downloads\实际下载文件名.zip' -ErrorAction Stop).Path
       $dest = 'C:\sc'
       $tar = Join-Path $env:SystemRoot 'System32\tar.exe'
       if (-not (Test-Path -LiteralPath $tar)) { throw '未找到 Windows 自带 tar.exe，请使用下方 Git 方案。' }
       if (Test-Path -LiteralPath $dest) { throw '目标已存在，请换一个短的新目录。' }
       New-Item -ItemType Directory -Path $dest -ErrorAction Stop | Out-Null
       & $tar -xkf $zip -C $dest --strip-components 1
       if ($LASTEXITCODE -ne 0) { throw '解压未完成，不要继续安装；核对 ZIP 后用新的短目录重试。' }
       Set-Location -LiteralPath (Join-Path $dest 'guangdong_market\program') -ErrorAction Stop
   }
   ```

   `--strip-components 1` 只取掉 GitHub 的一层外目录。已有 Git 且不指定提交时，也可运行 `git clone --depth 1 --single-branch --branch sichuan-v5 https://github.com/stardustwlshen/spot_market_ieee39.git C:\sc`（目标同样要新建），再进入 `C:\sc\guangdong_market\program`；固定提交请以给定 ZIP 为准。不要为此更改 Windows 全局长路径设置。
2. 安装 [CPython 3.12](https://www.python.org/downloads/)。以下命令在 `guangdong_market/program` 里执行。不必激活环境，也不必提供邮箱、账号或电网数据。

**Windows（PowerShell 或 CMD）：**

```text
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-runtime.txt
.\.venv\Scripts\python.exe scripts\launch_sichuan.py --check
.\.venv\Scripts\python.exe scripts\launch_sichuan.py
```

**macOS / Linux（终端）：**

Apple Silicon 请使用 macOS 12 或更新版本：当前 SciPy 的 Python 3.12 预编译包要求至少 macOS 12。

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-runtime.txt
.venv/bin/python scripts/launch_sichuan.py --check
.venv/bin/python scripts/launch_sichuan.py
```

3. 浏览器打开终端显示的本机地址，默认 `http://127.0.0.1:8501`。保留终端运行，结束后按 Ctrl+C。以后可重用同一个环境：Windows 双击当前目录的 `启动四川.cmd`，macOS 可运行 `./启动四川.command`。根目录 `start.bat` 是旧程序。此启动器仅监听本机；不要把本机地址发给别人当作公开网站。
4. 在默认的「大渡河 19 站」页面展开「运行设置与新算例」。快速体验可选择「首小时（4 段）」，点击「生成公司报价并运行市场」。需要复查已有结果时，用「打开匹配的已有结果」或在运行记录中选择档案。运行完成后，选择厂站和时段，依次打开「公司报价」「市场中标」「实时实发」「梯级水量」「收入与对照」。完整日运行会保存 96 个实时执行段。

切到旧四川研究场景时，点「计算日前并运行实时」，等「运行已保存」。检查结果有 `00:00–01:00（4/96 个实时段）`，再选时段和机组，展开「实时量价对账与导出」下载研究 JSON。关闭页面后重开可从顶部找回。两个 JSON 用于查看实时量价对账或估值，均覆盖已执行段，不等于完整原始档案。即使文件改名，也可用其 `provenance` 中的运行编号、规则标识、执行范围和原始实时执行文件 SHA-256 核对本地档案。价格复核时段另列，不表示原始执行数据被改写。若需留存复核资料，在本机备份相应的单个运行目录；对外分享前先确认其中输入与结果可公开。不要共享本地 .venv。需要检查完整的本次输入和物理量时，展开「专家复核：原始档案 ZIP」，点击「准备原始档案 ZIP」再下载。ZIP 仅含这一次已核验的原始数据和凭证；保留运行目录名，不含程序或依赖。需要离线复核时，将该运行目录放到同名四川结果目录再只读打开；不覆盖同名原档。

### 常见问题

- 找不到 `py` / `python3.12`：确认装的是 Python 3.12，并从能找到该解释器的终端执行。Windows 若只提供 `python`，先用 `python --version` 确认是 3.12，再用它创建环境。
- 缺依赖或 HiGHS 无法加载：先确认在正确目录，重跑同一虚拟环境的 pip 安装和 `--check`。首次安装需要能访问 Python 软件包源。保留第一条具体报错便于排查。
- 启动器会在默认端口已占用时尝试 8502–8510；显式指定 `--port` 后只尝试该端口。打开新终端显示的地址，用页脚「结果视图版本」与启动输出核对。
- 不能保存：检查解压目录或其中 `runs_sichuan_v5_consultation` 的写权限。先备份已有结果，再换到可写目录。失败任务不会覆盖之前的成功结果。
- 广东旧入口是独立程序，必要时运行 `python scripts/launch_sichuan.py --profile guangdong`。新旧结果不混用；原广东记录涉及绝对路径和指纹，保留原 checkout 与结果目录。

## 普通操作

1. 选月份和负荷/光伏倍率，直接输入 C1 首段报价。报价和场景由一次表单提交，不必先按回车；默认可直接试算。需要时再修改下方可选设置。四川启动器不显示旧广东菜单或首次邮件订阅提示。默认负荷、预测、机组和报价由 IEEE39 拓扑及明示合成假设生成，不读取广东出清、价格、配置或结算值。月度选择对竞价光伏参与方式生效，不改变现货限价。
2. 默认首小时试算。也可以选择完整单日 96 段。均计算 96 点日前预出清（只有参考计划和价格），然后滚动 8×15 分钟、每窗只执行首格；结算展示只使用实时归档。末窗截到日末。有效节点价根据研究限价处理，并另列原始 LP 对偶；线路硬限，有失负荷、过剩松弛或备用短缺即暂停该段研究电费，不假装有正常结算。
3. 实时用户采用合资格机组出清电量加权的统一结算点电价，储能放电用节点价、充电用统一价，只把放电量计入权重。模拟电费采用合成出清量，不是计量电量、正式账单或净利润，无日前价差费用。
4. 已选的四川档案只读，在 `runs_sichuan_v5_consultation/` 单独保存，带规则版本、用户选择、源文件摘要、结果哈希和计算范围。档案面板按北京时间与状态显示记录，不将归档参数回填到新任务，也不会恢复或启动任务。失败档案显示已保存的原因和设置，未完成的重试不覆盖此前成功结果。请勿手工修改原档案；可从页面下载研究 JSON。页面先显示实际执行范围和所选时段，再按机组展示日前参考与实时量价；展示舍入不改原始导出。程序不含云备份。

- 不启用顺序备用研究时，程序以日前预出清组合代替单独的正式日前组合；如仅声明 C1 辅助服务，锁定该组合、检验容量占位并将其传入实时物理界限。不会计算调频、备用中标或收入，不虚构储能辅助服务的持续时长和 SOC 资格，不复用广东顺序或收入。
- 日前/实时只完成固定负荷的供给成本优化示范，未模拟价格响应型需求、日内正式生产报送、完整准入与报价例外、市场力监测/替换、特殊补偿、跨省长协、结算分摊、零售合同、生产级异常价格修订。代码的参与类型与报价范围校验不等于物理模型已支持其中所有品种。

## 可选：日内调整、顺序辅助服务和梯级水库

- 日内调整需要显式声明生效时段和非零负荷预测变化。只有运行走到该时点才采用更新；此前实时窗口不读取它。首小时没到生效时段时不会虚构计划。日内重新优化到24:00，从上一实际执行段接续开停机时长、出力、储能状态及已用水量。若计划出现失负荷、过剩松弛或可靠性备用缺额，就不采用、保存失败记录；日内计划不算价格或费用。只实现合成负荷变化，并不表示覆盖第8节的所有生产报送边界。
- 顺序辅助服务可选“研究备用需求”，使用独立正式组合研究代理、外部声明调频证据（示例将 C1 上调量用于需求抵扣）、H1/H2 全天单段合成报价、占位后 SCED 和实时约束。备用阶段只给研究容量及单价，无实际调用与账单；手工声明模式不出清调频；可选两段调频研究见下节。尚未复现实际分段、电网分区、安全约束、资质审查或储能/虚拟电厂中标流程。
- 梯级水库可选 H1→H2 30 分钟整数延迟、H3 独立、明确日初在途水量、区间来水、库容、发电用水、弃水与最低出流；每个实时窗只提交首段并逐段独立核对库存及到达水量，日内起点继承到达队列。采用固定耗水系数与合成弃水罚值，未实现变水头、分流、禁振区或生产安全校核。


### 分段调频与备用衔接

启用「运行顺序备用预出清研究」后可再勾选「先做分段调频研究出清」；不勾选仍保留已声明调频的单段流程。演示按 00:00–12:00、12:00–24:00 两段分别采用 40、60 MW 调频目标，使用四台合成煤机/水电资源的准入声明、历史 Kh 和报价；按各类型最低报价量向上取整到 MW，调频的中标容量可为非整数。持有两方向的容量只向备用抵扣一份，调频、备用的阶段凭证分别保存并校核到日前/实时能量占位。若任一段实际缺额（差值超过 1e-8 MW），保留阶段记录并停止后续实时，不用默认值顶替。

调频为单区单段规则研究，历史 Kh 不是准入性能 K；调频里程参考价（元/MW）不同于备用参考价（元/MW·h）和电能量价（元/MWh）。这里不使用实测参数，不模拟实际 AGC 调用、里程、现金结算、区域约束或安全核验，也不声称所设两段是四川正式分段。


## 日前同价分配、异常电价复核与量价对账

- **日前同价分配**：页面默认开启，可关闭对比。只在日前预出清的固定机组组合上执行。保留原物理约束、可靠性松弛水平和原经济目标；对支持的同价申报段优先清洁能源，再按对应段容量分配，并在网络或跨时段约束下最小化比例偏差。节点参考价来自未增添同价约束的原定价模型。该研究策略不声明覆盖煤机同成本启停排序、受阻份额的生产算法或实时同价分配。启用后，若实时沿用这一日前参考计划，实时物理结果可能随参考变化。
- **实时异常价复核**：选已实际执行且无可靠性松弛的时段，在「复核本时段实时电价」填写异常编号并附完整的同段实时重算凭证；重算凭证用下载模板，包含运行号、时段（从零计数）、原实时执行文件摘要、记录号与全部节点价格。程序只核验研究凭证绑定与格式，不自动发现异常、运行外部重算或证明凭证来自生产系统。仅在明确记载无法重算时，用同档案同段日前参考价作为实时代理，不产生日前应收应付。复核另存，原始执行、原始研究价和结果凭证保持不变；保存后不可覆盖该时段的首个复核记录。
- **实时量价对账**：按已执行区间从功率与用电核算 MWh，列出日前参考量、实时实际量、原始/采用价和记录来源；可下载 JSON。储能买卖两条腿分别核算，缺价保留电量、不补零，所列净额不是正式账单或收益保证。未加入合同、偏差费用、辅助服务结算或费用分摊。


### 同一场景复跑

模型构建使用固定的资源、线路、报价段索引顺序，避免因不同进程的哈希顺序选择不同的等价最优水电计划，导致实时滚动水量边界和电价变化。没有修改原始经济目标、定价规则或历史档案。跨进程回归覆盖相同依赖与输入，不承诺跨平台、跨求解器版本逐位一致，也不表示最优解唯一。

新生成的研究记录可在归档列表按月份、负荷倍率、C1 报价和首小时/全天范围辨认；停用储能会单列。打开后再核对完整输入和凭证，列表摘要不替代校验，也不填入新任务表单。旧记录没有摘要时仍可按时间或完整任务编号查找。下拉列表只显示当前结果目录最近 200 条（含未完成项）；更早的任务可粘贴完整编号后点击「按编号打开」，检查结果不需要重新求解。若换了安装目录，该版本默认使用自己的结果目录，先核对原档案与目录，不要把旧记录未列出当成删除。
