# 四川 V5.0 征求意见稿 · IEEE39 研究模拟

在本目录执行 `python scripts/launch_sichuan.py --check` 检查依赖，再执行 `python scripts/launch_sichuan.py`。Windows 和 macOS 可以双击这里的 `启动四川.cmd` / `启动四川.command`。默认是四川；旧广东页面使用 `python scripts/launch_sichuan.py --profile guangdong`。此分支不把旧程序做就地改名，也不重写广东结果。旧广东工程自带核验是原路径/指纹绑定，不承诺搬迁后的原始档案可恢复；建议保留原 checkout 和结果目录。

## 普通操作

1. 选月份和负荷/光伏倍率，调整 C1 首段报价。默认负荷、预测、机组和报价由 IEEE39 拓扑及明示合成假设生成，不读取广东出清、价格、配置或结算值。月度选择对竞价光伏参与方式生效，不改变现货限价。
2. 默认首小时试算。也可以选择完整单日 96 段。均计算 96 点日前预出清（只有参考计划和价格），然后滚动 8×15 分钟、每窗只执行首格；结算展示只使用实时归档。末窗截到日末。有效节点价根据研究限价处理，并另列原始 LP 对偶；线路硬限，有失负荷、过剩松弛或备用短缺即暂停该段研究电费，不假装有正常结算。
3. 实时用户采用合资格机组出清电量加权的统一结算点电价，储能放电用节点价、充电用统一价，只把放电量计入权重。模拟电费采用合成出清量，不是计量电量、正式账单或净利润，无日前价差费用。
4. 已选的四川档案只读，在 `runs_sichuan_v5_consultation/` 单独保存，带规则版本、用户选择、源文件摘要、结果哈希和计算范围。档案面板不会恢复或启动任务。请勿手工修改原档案；可从页面下载研究 JSON。程序不含云备份。

## 覆盖范围

- 规则所据为《四川电力现货交易实施细则（V5.0 征求意见稿）》，不是已生效文件。参见 [条款追踪与缺项](../../docs/四川现货V5征求稿条款追踪.md)。
- 有功无损 DC；不作交流、电压、N−1 或生产合规核验。火电短时约束、最低出力成本、爬坡和非市场固定计划为合成假设；不开启可选梯级时，水电仅演示日电量与日前尾段水量参考；储能采用已申报充放电计划和物理 SOC，不自由按价套利。限价处理只作用于展示研究价，不回写原始对偶；本实现不自动套用 §9.6 的异常实时重算及条件性日前代理价格。
- 不启用顺序备用研究时，程序以日前预出清组合代替单独的正式日前组合；如仅声明 C1 辅助服务，锁定该组合、检验容量占位并将其传入实时物理界限。不会计算调频、备用中标或收入，不虚构储能辅助服务的持续时长和 SOC 资格，不复用广东顺序或收入。
- 日前/实时只完成固定负荷的供给成本优化示范，未模拟价格响应型需求、日内正式生产报送、完整准入与报价例外、市场力监测/替换、特殊补偿、跨省长协、结算分摊、零售合同、生产级异常价格修订。代码的参与类型与报价范围校验不等于物理模型已支持其中所有品种。

## 可选：日内调整、顺序辅助服务和梯级水库

- 日内调整需要显式声明生效时段和非零负荷预测变化。只有运行走到该时点才采用更新；此前实时窗口不读取它。首小时没到生效时段时不会虚构计划。日内重新优化到24:00，从上一实际执行段接续开停机时长、出力、储能状态及已用水量。若计划出现失负荷、过剩松弛或可靠性备用缺额，就不采用、保存失败记录；日内计划不算价格或费用。只实现合成负荷变化，并不表示覆盖第8节的所有生产报送边界。
- 顺序辅助服务可选“研究备用需求”，使用独立正式组合研究代理、外部声明调频证据（示例将 C1 上调量用于需求抵扣）、H1/H2 全天单段合成报价、占位后 SCED 和实时约束。备用阶段只给研究容量及单价，无实际调用与账单；未出清调频、未复现实际分段、电网分区、安全约束、资质审查或储能/虚拟电厂中标流程。
- 梯级水库可选 H1→H2 30 分钟整数延迟、H3 独立、明确日初在途水量、区间来水、库容、发电用水、弃水与最低出流；每个实时窗只提交首段并逐段独立核对库存及到达水量，日内起点继承到达队列。采用固定耗水系数与合成弃水罚值，未实现变水头、分流、禁振区或生产安全校核。
- §9.6 价格异常补救保留为独立证据规则及单测，普通运行不自动读取日前备用价。没有重算和同段已核验参考来源时，不替换或补零。

### 分段调频与备用衔接

启用「运行顺序备用预出清研究」后可再勾选「先做分段调频研究出清」；不勾选仍保留已声明调频的单段流程。演示按 00:00–12:00、12:00–24:00 两段分别采用 40、60 MW 调频目标，使用四台合成煤机/水电资源的准入声明、历史 Kh 和报价；按各类型最低报价量向上取整到 MW，调频的中标容量可为非整数。持有两方向的容量只向备用抵扣一份，调频、备用的阶段凭证分别保存并校核到日前/实时能量占位。若任一段实际缺额（差值超过 1e-8 MW），保留阶段记录并停止后续实时，不用默认值顶替。

调频为单区单段规则研究，历史 Kh 不是准入性能 K；调频里程参考价（元/MW）不同于备用参考价（元/MW·h）和电能量价（元/MWh）。这里不使用实测参数，不模拟实际 AGC 调用、里程、现金结算、区域约束或安全核验，也不声称所设两段是四川正式分段。
