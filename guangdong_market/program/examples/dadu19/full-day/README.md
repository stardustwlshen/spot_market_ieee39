## 算例与口径

- 这是 IEEE39 合成研究日，种子 39。19 站统一报价是研究组合；台账业主与合成市场资格见[电站参数目录](../../../data/dadu19)。本例设计装机为水电 22,056 MW、煤电 3,200 MW、气电 1,200 MW、普通集中式光伏 8,820 MW。气电按外生保供计划注入，分时表中的所在节点价供查阅，气电不取得竞价主体收入。
- 每个时段为 15 分钟，表内功率乘 0.25 得 MWh，流量乘 900 得 m³。日前预出清用于运行参照。表内有效价格已按规则情景限价，原始对偶保留原值。表中 0 是计算结果；空白表示该字段不适用、没有上网电量可算均价，或可靠性检查触发了暂停估值，可按“参与方式”和“估值状态”区分。
- 发电侧以模拟实时执行量作为上网计量，按各自节点价格计算电能量毛收入。某时段触发暂停时保留该段电量、原始对偶和异常记录，相关小时和全天金额留空，其他完整小时仍可查询。这里没有厂级实测成本、中长期合同差价、辅助服务补偿或气电计划费用，因此不能从表中得出企业净利润。
- 库内水价值用各站共同的事前元/m³参数计算；河道在途水按接收站的参数计算。两项均以期末减期初计量。上述合成水价值用于经济比较，不能作为市场结算收入。
