IEEE39 电力现货市场仿真程序｜先读我
版本：1b30d48（2026-11-04）

这是完整源代码程序包，不是免安装 exe。可将整个 ZIP 转发给接收者，无需 Git 或 GitHub 权限。
包含网页应用、模型源代码、固定依赖清单、启动脚本、IEEE39 样例网络/曲线/报价、测试和技术文档。
不包含 Python/虚拟环境、私人场景和运行历史。首次运行后会在自己的项目文件夹保存新场景与结果。

一、首次运行
1. 安装官方 CPython 3.12 或 3.13：https://www.python.org/downloads/
   Windows 安装时勾选 Add Python to PATH。Python 3.11 不适用。Python 须含 venv 和 ensurepip。
2. 将整个 ZIP 解压到自己的普通文件夹，例如 D:\IEEE39 或用户文档目录。
   不要在压缩包预览窗口里直接运行，不要只复制 app 文件夹。
3. 进入 IEEE39_1b30d48 文件夹：
   Windows：双击 start.bat。
   macOS：双击 start.command；如果不能双击，终端进入该文件夹后运行 bash start.sh。
   Linux：终端进入该文件夹后运行 bash start.sh。
4. 第一次需联网下载依赖，等待启动窗口完成检查。程序在 .local-app 内创建独立环境，不修改系统 Python。
   成功后打开 http://127.0.0.1:8501 。浏览器没有自动打开时手动输入这个地址。
   后续仍运行相同入口；依赖不变时会复用并检查已有环境。

二、使用与退出
- 在网页选择场景、机组与报价，选择“仅日前”或“全天：日前→实时→结算”，点击“开始运行”。
- “短时试跑”仍先计算完整日前计划，只截短实时部分，不等于完整日结算。
- 日前求解默认最多 600 秒，全天流程还需要实时计算时间，实际耗时取决于电脑和场景。
- 本程序用于研究仿真。求解完成不代表备用需求全部满足或方案安全可运行；请看结果质量、缺额和求解精度提示。
- 用完先等待后台求解结束，或在网页请求取消并等待结束，再在启动窗口按 Ctrl+C。
  直接关闭网页不会强行结束后台求解。不要同时启动多个副本来处理同一份运行记录。

三、求解器与依赖
默认使用 HiGHS，经固定版本 highspy 自动安装；不需要另装 Gurobi、CPLEX 或商业求解器许可证。
启动器按 requirements-app.txt 安装运行依赖，并做依赖导入及极小 Pyomo/HiGHS 求解检查。
requirements.txt 另外包含 pytest 和重新导出网络数据用的 pandapower，普通网页使用不需要手工安装它。
如所在网络无法访问依赖源，请按本地网络要求配置代理/软件源，不要关闭证书或系统安全保护。

四、常见问题
- 未找到 Python：确认安装 3.12/3.13，并重新打开终端；Windows 检查 PATH。
- 8501 端口占用：Windows 在终端运行 start.bat --port 8502；macOS/Linux 运行 bash start.sh --port 8502。
- 依赖安装失败：保留窗口提示及 .local-app/logs 中日志，先检查网络与磁盘空间；修复后再启动。
- 不要删除场景或整个项目来修复安装问题。分享日志前检查是否含个人路径、代理信息。
- 网页仅监听本机且没有登录鉴权，不要直接暴露到公网。
详细说明见 docs/本地启动.md，模型与操作见 README.md。
